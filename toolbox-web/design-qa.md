# UI 与功能验收记录

日期：2026-10-02。验收对象为 `toolbox-web` 本地交互原型，未发布到公网。设计依据为 [详细设计](../docs/design/2026-10-02-public-toolbox/design.md) 与 [字帖和打印规范](../docs/design/2026-10-02-public-toolbox/worksheet-and-print-spec.md)。

## 视觉对照方法与结果

把设计概念图与实际浏览器截图按相同显示宽度等比缩放，并排合成为一张图片，再逐张查看。左侧为设计，右侧为实现；没有裁去不一致区域，也没有把概念图当作真实页面截图。概念图本身是视觉示意，字帖纸面由实际 PDF 排版器生成。

| 页面与证据 | 检查结果 |
| --- | --- |
| [首页并排对照](verification/comparison-home.png)；实际视口 1440 × 1024 | 保留固定左侧目录、顶部工具栏、四个指标卡、趋势图与排行并排、三项快捷入口。标题、数字、图表、入口有清晰的阅读顺序。当前项使用浅蓝紫色背景，站名完整显示。 |
| [字帖桌面并排对照](verification/comparison-copybook-desktop.png)；实际视口 1440 × 1024 | 保留左目录、设置与纸张双栏、白色 A4 纸张。设置区可独立滚动，打印预览和导出固定在设置卡片底部。答案入口位于纸张工具区，主输出默认为学生卷。 |
| [字帖手机并排对照](verification/comparison-copybook-mobile.png)；实际视口 390 × 844 | 左上角菜单、站名、设置／词条／预览标签、缩放与翻页、独立答案入口均可见。底部导出／打印预览可达，宽度适合手机。纸张在页面内向下滚动，显示缩放不修改 PDF 的 A4 尺寸。 |

字体采用系统中文 UI 字体，按钮、表单和菜单来自 Naive UI；主色沿用 `#646cff`。实际界面比概念图的文字与图标更紧凑，纸面字体为嵌入的 Noto Sans CJK。此次浅色模式并排对照与修复后的深色截图复核未发现阻断操作或达到 P0—P2 的视觉问题；截图检查不替代完整的可访问性审计。

## 已明确的设计差异

- 首页新增“示例数据／本机使用”切换和演示标识，避免把概念图数字呈现为真实全站统计。图表新增工具筛选与数据表入口。
- 字帖与单词增加醒目的“排版示例，非教材词库”提示。手机上这段说明占用额外高度，因此完整纸张与下方说明需要滚动查看。
- 语文当前默认是两字词语，因此真实纸面使用两列词语格；概念图展示单字四列。实际引擎仍按单字四列、词语两列、长题整行排版。
- “识字表”等教材专属分类、教材版次和课文树尚未接入。当前使用原创的生字／词语／短语示例、三个示例单元与手动导入；年级和册次选择不代表已具备对应教材词库。
- PDF 本轮采用浏览器本机处理，显示本机隐私说明，未接公开后端适配层。Markdown 是基础文字排版；其处理范围与配额在 [README](README.md) 中单独列明。
- 这是一轮可操作原型验证，不代表正式教材覆盖、全站匿名统计、生产部署、所有浏览器兼容性或真实打印机验收已经完成。

## 浏览器交互验证

以下操作由主执行代理在应用内浏览器完成，截图与文件证据保存在 `verification/`。

| 场景 | 结果 |
| --- | --- |
| 1440 × 1024 首页 | 指标卡、工具导航、7／30 天切换、本机统计与数据表可操作。 |
| 390 × 844 手机导航 | 左侧抽屉可以打开、切换工具并关闭。 |
| 320 × 740 英语页 | `scrollWidth = clientWidth = 320`，没有页面整体水平溢出。截图为当次浏览器捕获区域。 |
| 768 × 1024 平板预览 | `scrollWidth = clientWidth = 768`，没有页面整体水平溢出；深色界面可读，白色纸张不反转。 |
| 平板图标导航 | 隐藏菜单文字时仍保留可访问名称；DOM 的 `menuitem` 可识别“首页／PDF／字帖／单词”，点击单词入口可以导航。 |
| 顶部工具搜索 | 可使用键盘选中结果并导航到单词页。 |
| 浏览器控制台 | 最后一轮检查 `error`、`warn` 均为空。 |
| 清空后导入自定义词条 | 导入 `book\|书` 后只选择 1 项，原来的 8 个示例未重新勾选。 |
| PDF 合并 | 两份各 2 页的示例合并为 4 页 `merged.pdf`，结果预览正常。 |
| PDF 提取文字 | 示例 PDF 返回实际文字内容。 |
| 字帖与单词模式 | 语文两种模式、英语两种模式切换及真实 PDF 预览渲染正常。 |
| PDF 导出入口 | 点击行为正常；应用内浏览器下载事件等待工具超时，不能据此声称最终下载文件已在磁盘完成落盘。生成文件本身另有独立验证。 |

## 文件与逻辑验证

- 实现代理记录：Node.js 24.19.0 下 `npm run typecheck`、25 项自动化测试、`npm run build` 通过；字体、中文 CMap、缺失字形、分页、答案隔离及 PDF 输入限制有对应回归。预览答案入口与深色样式调整后，最终再次运行含类型检查的构建，退出码为 0、无告警。
- 四种学生卷文件已归档，并经过生成字节、A4 尺寸、文字提取与页面渲染验证：[看拼音写汉字](verification/pdf/chinese-dictation-student.pdf)、[看汉字写拼音](verification/pdf/chinese-pinyin-student.pdf)、[看中文写英文](verification/pdf/english-dictation-student.pdf)、[看英文写中文](verification/pdf/english-meaning-student.pdf)。
- 只读代码审阅发现的中文 PDF 缺少 CMap、自定义导入复活示例、文本 PDF 缺失字形静默输出等问题已修复；自定义导入在浏览器复核，其余由针对性回归覆盖。

## 未完成的验收

系统打印对话框、真实打印机出纸和各手机系统的打印服务尚未完成实纸验收。浏览器下载事件工具的超时也意味着最终下载落盘流程未被完整观察；此限制不等同于文件生成失败。正式上线前仍需补充真实教材校对、目标移动浏览器、辅助技术与生产环境验证。
