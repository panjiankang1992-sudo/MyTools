## 风格依据与设计取舍

以下为 8B 模型标为 `observed` 的检测结果，不是人工逐项确认的客观事实。每书先计算“命中块数 / 该书全部块数”，再对 74 本等权取均值；不使用长书的块数作为书籍权重。标签可同时出现，比例不能相加。未检出也不代表原文绝无该特征。

| 特征 | 有直接观察标注的书数 | 等书权平均命中块占比 | 模板取舍 |
|---|---:|---:|---|
| 连续动作 | 72/74 | 43.6% | 展开已有行动过程，不添加新行动结果 |
| 因果衔接 | 72/74 | 38.1% | 写清已有刺激、判断和后果，不补造动机 |
| 环境感官 | 71/74 | 34.7% | 用空间和环境参与场面，避免装饰性堆砌 |
| 心理反应 | 70/74 | 25.0% | 增强即时反应，保持角色知识和性格边界 |
| 带引号对话 | 70/74 | 24.4% | 增加表达层次，不增加信息或承诺；无引号对话不在此口径内 |
| 重复表达 | 72/74 | 22.3% | 作为去重提醒，不把频繁出现等同于优秀技巧 |
| 场景转换 | 65/74 | 7.2% | 顺畅处理原有转场，不增加新场景 |
| 显式对比 | 59/74 | 4.9% | 可选手法，不强行增加反差或悬念 |

因此，这次模板的重点是 **动作—因果—环境—心理—对话的场景层次**，而不是笼统地“写长一点”。这是将观察转化为写作规则的设计判断，不是模型实验证明了这些规则一定改善阅读效果。

没有可靠依据把“所有句子都短”“切换第一/第三人称”“制造新悬念”作为通用风格。视角和信息隐瞒标签继续隔离；保留原文视角是产品一致性规则，不是从语料推断得出的统一视角。

## 与 GitHub 方法的结合

- [ReNovel-AI](https://github.com/BiranSama/ReNovel-AI)：参考表达生成与一致性复核分离的思路，在提示词中增加交付前对照检查。不声称仅靠提示词就实现独立审稿代理或全书记忆系统。
- [ai-novel-rewriter](https://github.com/hollis-openlab/ai-novel-rewriter/blob/dev/README_zh.md)：参考场景分析、上下文衔接与剧情超跑检查，要求围绕当前场景职责加料，不能提前演出邻章。

第三方方法与语料检测是不同来源，不把项目宣传视为本项目已经实测的能力。没有复制其代码、原书段落或色情扩写提示词。

## 验证与限制

- 独立汇总脚本从 SQLite 分块记录重算连续覆盖、完整书数量及观察/推测计数，并与现有整书汇总核对。
- 总结果保留 222,471 条引用，剔除过 1,880 条与可计算条件矛盾的引用；该总数含部分书、推测及隔离标签，不能作为模板“已验证证据数”。本轮只检查结构和汇总一致性，没有重新逐条阅读这些引用。
- 既往两书语义抽查不能外推为全部 74 本的语义准确率；按 ID 顺序处理并提前停止产生选择偏差，结果不代表未处理书籍或所有小说。
- 14 项既有解析/证据测试与候选 JSON 字段验证用于结构验收，不等于真实章节改编效果验收。
- `expectedLatestVersion=0` 仅为新增候选占位。发布前需按 `add-adaptation-template` 技能读取实际目录，确认新增还是升级，再固定发布版本与幂等请求；本轮未调用管理发布接口。
