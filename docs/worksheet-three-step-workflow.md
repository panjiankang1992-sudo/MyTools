# 字帖与单词：最新版三步流程（简化版）

更新日期：2026-10-04。适用于 `/#/copybook`（语文字帖）与 `/#/words`（单词练习）。

**当前 UI 保留「数据来源 → 数据确认 → 数据预览」三个独立步骤，页面使用短名称「1 选内容 → 2 确认内容 → 3 预览打印」。** 常用路径为选择或输入正文、下一步、生成预览、打印或下载；需要时再展开校对、设置和参考答案。本说明优先于旧设计中与其冲突的“一屏三栏”“输入、处理、预览同时展开”、必须先手选题型及手机来源卡片单列等描述；未冲突的数据、字体和打印约束仍适用。本文描述当前实现与复验要求；简化版已部署，证据及未完成的浏览器验收见 [发布记录](verification/worksheet-simple-2026-10-04/RELEASE.md)，不代表所有验收已经通过或教材完整覆盖。

## 1. 选内容：先选一张卡片

首次进入停在第一步，显示 **选教材、自己输入、上传图片** 三张卡片，默认不选来源、不填示例、不显示确认表单或 PDF 预览。点击卡片后显示对应输入区；切换来源保留已有统一原文。已有内容时显示项数与“继续编辑 →”，可直接返回确认页。

| 来源 | 常用操作 | 按需展开的内容与状态 |
| --- | --- | --- |
| 选教材 | 选年级、上/下册，再主动勾选练习范围，点击“下一步”；已有正文时按钮为“下一步（追加）” | 单一版本直接显示教材名称，多版本才显示选择器。范围旁直接提供“全选”“清除选择”。覆盖状态保持可见，缺口在“查看缺少的内容”内。“更多筛选”提供识字表、写字表、词语/单词表等类别及替换已有内容 |
| 自己输入 | 输入或粘贴，以空白分项，点击“下一步”；英语短语可写为 `"ice cream"` | “更多输入选项”提供“每行一项（保留短语）”和替换已有内容。已有正文时主按钮追加，并显示追加提示；候选通过校验前不覆盖统一原文 |
| 上传图片 | “选择图片”→“识别文字”→核对和编辑候选→“下一步” | “调整图片与查看进度”提供队列、预览、旋转 90°、框选、移除全部和置信度；识别中的取消与当前张数保持可见。已有正文时“更多操作”提供替换，需二次确认。支持 PNG/JPEG/WebP，单张不超过 10 MiB、最多 5 张；图片不上传，首次识别按需读取本站资源 |

教材列表及覆盖状态以实际加载的已发布目录为准，展示教材系列、年级册次、版本名称、所选项数及可展开的内容缺口。教材与单元使用可读名称，内部身份用于关联数据。没有版本、只有部分内容、加载失败时应显示相应状态，不把其他册次或示例当作所选教材。语文提供 1—6 年级选择、英语提供 3—6 年级选择，不等于这些槽位都已有内容。

语文和英语教材首次加载均不勾选单元或课文，切换年级、册次或版本也清空范围，已选 0 项时“下一步”禁用。用户可手选、全选当前教材范围或清除选择；全选和清除保留字表筛选，不改动已导入的统一原文。只返回前一步不会重置用户已选的范围。

英语教材固定使用原书单词表，不提供语文字表筛选，也不把课文标题当作词表内容。按单元或附录选择后，直接显示所选英文、中文释义和原书注记。当前译林三年级上册按书后 Word lists I 收录 8 个单元共 129 项，III 的 11 项专有名词独立为附录；II 为字母序重排，不重复导入。原表自带的重要句型仍属于单词表，不能按标点另行剔除；专名不得按推定页码并入单元。全选包括页面列出的单元与附录，仍需用户主动操作。

此项已部署，349 项回归及线上资源校验结果见 [教材选择发布记录](verification/curriculum-selection-2026-10-04/RELEASE.md)。

图片可以直接按整图识别，裁剪和旋转不是必经步骤。折叠调整区不会清除已选方向与选区；旋转后需重新框选。识别仅提供待校对文字；离开图片来源会取消在途识别，保留当前页面中的图片、选区和候选供返回编辑。“移除全部图片”清空图片队列与资源，允许重新选图。图片本体不写入草稿。

## 2. 确认内容：默认可生成，需要时再校对

只有非空、解析有效的内容才能进入第二步。三种来源最终汇入同一份原文；首要内容是可直接编辑的正文、项数、字帖样式和“生成预览”。原文编辑区的“更多输入选项”收纳分项方式、两列词条表导入、显式标点清理与撤销、清空，以及来源摘要和 UTF-8 字节数；两列词条表提交后替换统一原文，并非追加。可以返回第一步补充来源。

**有效内容首次进入确认且尚未选择题型时，语文默认“拼音字帖”（`chinese-pinyin`），英语默认“中文释义练习”（`english-meaning`）。** 两者的学生卷只需要正文，不强制先补拼音或释义，也不自动生成答案；空白或解析错误不会触发默认选择。已有手选题型或草稿题型保持不变，返回、再导入和再次确认不会重置。

题型仍可在“选择字帖样式”中切换，与来源、年级、册次和字表类型解耦。同一题型覆盖本次全部有效内容；识字表、写字表、词语表可以混选后使用任一种中文题型。

| 学科与题型 | 学生卷 | 学生卷生成条件 | 独立答案生成条件 |
| --- | --- | --- | --- |
| 语文 · 拼音字帖 | 给汉字，留拼音书写区 | 有汉字文本 | 每项有完整、逐字对齐且已确认的读音 |
| 语文 · 汉字字帖 | 给拼音，留汉字格 | 每项有完整、逐字对齐且已确认的读音 | 有汉字文本 |
| 英语 · 中文释义练习 | 给英文，留中文书写线 | 有英文文本 | 每项有已确认的中文释义 |
| 英语 · 英语默写 | 给中文，留英文四线三格 | 每项有已确认的中文释义 | 有英文文本 |

“检查拼音”或“填写中文释义”在默认题型下标记为可选，首次保持折叠。切换到需要这些字段的题型且有缺项，或必需字段从完整变为有缺项时，校对区自动展开并显示待处理项数；尝试生成仍有缺项时定位校对区。用户可手动收起，收起不销毁校对组件或未提交编辑缓冲。

切换到需要拼音的学生题型或生成该题型时，会为缺少读音的条目补候选，不覆盖已有校对、不自动确认。自动补音只是建议；单项确认仅影响该项，批量确认不跳过多音字或不完整读音。默认题型不会因不需要的拼音或释义缺失而阻断学生卷。答案条件按所需字段独立校验，答案缺失不应破坏已经有效的学生卷。

“更多设置”默认折叠，收纳标题、10/12/14 mm 格距、每项重复 1—5 次、中文整词/逐字练习、合并等价重复项/保留每次出现，以及全部选入、随机抽取、按教材单元均衡抽取和本机草稿。单元均衡需要可信的单元来源，不能据此声称自定义内容具有教材归属。选入最多 200 项，重复展开后最多 500 题；正文超过 200 项时展开设置提示选题，不能静默截断。生成失败有错误时也展开设置，便于修正相关参数。

原文项数与最终题数保留在常用区域，来源和字节数移入更多输入选项。草稿由用户主动保存；恢复应保留分项方式、短语、读音/释义、处理选项和版式，创建没有旧产物的新会话。旧草稿不能确定对应位置的同形项需重新复核；只存了教材 ID 的旧选择需要重新取回真实内容。

## 3. 预览打印：打印和下载优先，答案可选

点击“生成预览”后，只有真实生成成功且产物仍对应当前内容才进入第三步；失败停留确认页并提示。顶部主要操作为“上一步”“打印”“下载 PDF”，其后是纸张预览；多页文件显示翻页按钮，单页显示“共 1 页”，缩放按钮为“放大查看/适应窗口”。学生预览和学生导出使用同一份产物。

“需要参考答案？”默认折叠，展开后才显示独立答案的生成、下载及返回校对入口。提示随题型说明是否需要确认拼音或填写释义；答案另外生成、另外下载，不自动混入学生卷。不完整的必需答案字段会阻止答案生成，正在编辑而未完成的必需拼音还会禁用答案操作；不能据此声称所有缺字段情形都提前禁用按钮。

预览页“上一步”保留原文、校对、题型、标题、格距等；再次返回“选内容”保留当前会话以及本页尚在内存中的来源选择。后退本身不清空内容、不重新追加、不生成新文件。步骤栏只允许返回已到达的前序步骤，不能跳过输入校验或生成直接进入预览。

改变实际题目内容、分项结果、题型、选题或版式后，旧预览须标记过期，不能继续导出或打印；重新生成后才恢复。纯等价空白调整可沿用同一有效学生产物。生成期间编辑、清空或离开页面会作废旧请求，迟到结果不得覆盖新内容。答案也必须对应当前内容与设置，失效后重新生成。

“打印”打开独立打印预览窗口；无法打开时提示改用 PDF 导出。系统打印及实体打印效果需要单独验证，不能用浏览器画布预览代替。

## 追加、替换和移动端规则

- 各来源主按钮缩短为“下一步”，已有正文时以按钮文字或邻近提示说明追加；替换移入更多选项。图片替换已有原文需要再次确认；教材和自定义文本的显式替换不额外弹出确认。输入无效或导入失败时保留原内容。
- 每种来源记录最近一次成功应用的候选：返回后对未变候选再次点继续，只前进到确认，不重复追加。候选防重复与最终题单的重复项策略分别生效；并非任意历史批次的全局去重。
- 显式替换、清空统一原文或恢复另一份草稿时重置候选应用记录。追加文本沿用现有原文的分项规则，对传入短语做必要序列化，避免拆散短语。
- 桌面保留站点左侧目录；手机通过左侧抽屉导航，制作流程仍按三步进行。来源卡片保持紧凑三列，≤480 px 缩小内边距、居中短标题并隐藏卡片副文案；题型选项保持两列，教材和版式表单改为单列。操作按钮随页面滚动、可换行，触控主要按钮至少 44 px 高。手机缩放只改变显示，不改变纸张尺寸和分页；无横向溢出和实际按钮可达性仍需现场验证。
- 返回步骤保留的是当前页面内存状态；关闭或刷新页面后的恢复依赖主动保存的草稿，不承诺恢复图片与旧 PDF。

## 简化版验收清单

本轮已报告 347 项自动化测试通过，不能替代下列 UI 操作验收。当前 CUA 可以读取页面截图，但点击后没有可观察的页面变化，尚不能完成交互验收；该工具现象本身不证明页面功能失败。以下各项仍需记录真实操作结果，不标为已通过；部署结果单独以发布记录为准。

- 新会话输入中文或英语正文，点击“下一步”后已有对应默认题型；不展开校对和更多设置，能完成学生卷生成。
- 切换到汉字字帖或英语默写，缺读音/释义时自动展开校对并阻止不完整输出；修正后可生成。收起再展开不丢未提交编辑，已有题型经返回与再确认后仍保留。
- 常用界面只保留主要步骤；更多输入选项、教材筛选、图片调整、更多设置和参考答案能展开且原能力仍可操作；超过 200 项时自动显示数量处理入口。
- 预览顶部打印、下载 PDF 可用，下载的是当前学生产物；参考答案需主动展开并独立生成，缺少必需答案字段时不能产出错误答案。
- 在 320/390 px 视口检查三列短来源卡片、三步导航、两列题型和主按钮；无横向溢出，返回保留状态，相同候选不重复追加。截图只作为外观证据，点击与实际下载结果另记。

## 手动回归：逐项记录结果与证据

依赖已就绪时，在仓库根目录启动本地页面：

```bash
cd toolbox-web
npm run dev -- --host 127.0.0.1 --port 4173 --strictPort
```

分别打开 `http://127.0.0.1:4173/#/copybook` 与 `http://127.0.0.1:4173/#/words`。以下是待执行的步骤与预期，不是通过记录；第 2—4 项连续执行，其余各项可使用独立新草稿：

| 步骤 | 操作与必须观察的结果 |
| --- | --- |
| 1. 首屏与导航 | 新开页面，确认只有来源卡片及当前步骤；未选内容时不能跳到确认/预览。桌面与 320/390 px 手机视口分别检查导航和横向溢出 |
| 2. 自定义短语 | 英语在“更多输入选项”选择“每行一项”，输入两行 `ice cream`、`Good morning`；下一步后恰好 2 项且已默认“中文释义练习”，不先补释义也可生成学生卷 |
| 3. 返回与状态 | 在确认页展开“更多设置”，填写标题、设 14 mm 和重复 2 次；生成后返回确认、再返回来源。检查文本、短语边界、题型和版式均保留；同一候选再次下一步仍为 2 项，最终题数为 4 |
| 4. 追加与替换 | 新增候选 `apple` 并点下一步，现有短语不拆散；再次继续不重复追加。在更多输入选项显式替换为 `banana` 后仅剩新内容。清空候选时下一步禁用；输入未闭合双引号后继续，应留在来源并保留已有内容 |
| 5. 教材来源 | 选实际可用册次与版本，检查单版本名称/多版本选择器，展开缺口与更多筛选，记录字表与范围；导入后切换两种中文题型，原文不变。返回相同选择再次下一步不增加项数。缺失册次应如实提示；目录不可用时记录阻塞，不填“通过” |
| 6. 图片来源 | 上传带方向标记的图片，先检查调整区折叠时可整图识别；再展开调整区旋转、框选后识别，核对候选与实际选区；编辑候选再下一步。测试更多操作内替换二次确认、返回图片页、识别中离开、移除全部后重新选择 5 张，旧任务不得追加旧结果 |
| 7. 校对与答案 | 中文输入“行 重”并切换“汉字字帖”，检查自动展开和补音建议；仅确认“行”，“重”仍待复核。英语新草稿输入 `apple banana`，默认学生卷可生成，展开“需要参考答案？”后缺释义的答案受阻；返回补齐两项释义后独立生成并下载答案，核对学生卷没有答案泄漏 |
| 8. 失效与竞争 | 生成后把“春 天”改为“秋 冬”，或修改分项方式/标题/格距；旧文件不可输出。生成中编辑或清空，等待旧请求返回，确认不会恢复旧内容；修正解析错误后才能重新生成 |
| 9. 草稿与长列表 | 在更多设置中保存含短语、同形异音、标题和格距的草稿，新会话恢复后逐字段核对；损坏草稿不能清空现有编辑。输入超过 200 项时设置自动展开，合理抽题后可生成；展开校对应能定位第 61、200 项 |
| 10. 实际输出 | 通过正式按钮下载学生/答案文件，记录文件名、页数、内容及文件 hash；核对翻页、打印预览与下载内容。手机上检查按钮可达、虚拟键盘不遮关键操作；未做系统/实体打印的部分标记“未执行” |

每项记录环境、实际操作、截图或文件路径及 `通过 / 失败 / 未执行 / 阻塞`；有未执行子项时不能把整项记为通过。教材覆盖以本次加载数据为证据，不沿用旧报告的数量或完整性结论。
