# MyTools DSH 手机端深化设计

目标：手机用户能完成“进入 DSH → 登录/配置模型 → 修改设置 → 返回会话”，每个入口都能到达可操作的页面。保留 DSH 原有设置和认证语义，延续其现有视觉体系。

## 现状与决定

| 实测问题 | 设计决定 | 实现位置 |
| --- | --- | --- |
| 设置保留 188px 桌面左栏，390px 屏幕上正文被挤成竖排 | 手机全屏设置，顶部标题和关闭固定，设置分类采用两列入口（登录后增加账号分类），正文单独滚动 | mobile.css |
| 登录先预开空白窗口，再异步跳转；App 没有新窗口处理 | 主 DSH 保持连接，空白子窗口只作中转，HTTPS 登录交系统浏览器完成 | DshPopupRelay / Index |
| 登录状态按钮较小，说明和操作分散 | 底部登录面板，主操作在上、辅助操作在下，单列排列 | mobile.css |
| 窄屏表单、字号步进按钮、长说明和软键盘争抢空间 | 输入字号 16px，主要操作 44–48px，说明自然换行，表单滚动，模型操作栏贴底 | mobile.css / mobile.js |
| 侧栏选择插件后仍遮挡正文，固定菜单遮挡全局页标题 | 选择具体页面/会话后收起抽屉；插件、自动化及详情预留顶部空间 | mobile.js / mobile.css |

## 页面与交互

1. **会话首页**：侧栏为抽屉，保留当前会话内容；展开工作区只展开分组，选择具体会话后收起。模型、权限、附件等继续使用原有操作协议。
2. **账号登录**：开始使用、等待授权、取消、超时重试保留原有状态机。App 只接管用户触发的新窗口；不会在 MyTools 自己创建密码表单。系统浏览器打开失败时显示说明，并保留复制登录链接的退路。真实成功回流待设备验收。
3. **通用设置**：固定“设置”标题、关闭和配置文件入口，下方为通用/模型/内置插件/Agent 预设；登录后显示账号与余额分类。标签和解释左对齐，空间不足时控件换至下一行，不逐字竖排。
4. **模型与 API Key**：提供商列表、第三方提供商、自定义 API 表单均在全宽正文区。密钥仍由上游原表单处理；适配层不读取、存储或复制密钥。取消/保存区域保持可达。
5. **插件与 Agent 预设**：长内容独立滚动，现有开关和风险说明完整保留；不自动启用插件或改变权限。
6. **全局插件与自动化**：菜单入口与页面标题不重叠；返回插件列表按钮保持可见。自动化“新建”沿用上游会话式创建流程。

## 尺寸与状态规则

- 竖屏宽度 ≤767px，与上游 768px 断点衔接；横屏宽度 ≤900px 且高度 ≤500px 使用手机布局。
- 常规设置：顶部分类入口两列展示，数量随登录态变化。横屏或键盘压缩高度时改为可横向滚动的一行，优先留出正文空间。
- 设置全屏；登录面板距屏幕边缘 12px、圆角 22px；正文左右留白约 20px。
- 主要按钮至少 44px 高，表单主操作 48px；输入字号 16px。
- 使用 visualViewport 更新高度，降低软键盘遮挡；浏览器缩小视口只是近似验证，不能代替 ArkWeb 真机。
- 所有关闭按钮保留上游行为；系统返回先关闭菜单、弹窗、文件面板与抽屉，插件详情返回列表，DSH 根页面返回进入前的 MyTools 标签。复杂编辑器与终端命令行为保持上游实现。

## 上线与维护

- 网页样式/脚本从 Nginx 巨型内联配置拆成独立资源，使用版本查询参数和 no-cache。
- 保留 MyTools 网页票据、授权子请求、DSH 上游 Cookie 隔离、跨站限制和 gzip。
- 优先使用 role、data-shortcut-modal 等语义选择器；上游没有稳定标记的区域仍依赖 0.2.1-rc.2 构建类名。升级 DSH 后必须按下面的验收清单重新检查。
- App 登录中转需要安装本轮 HAP 才生效；网页适配可以独立更新。

## 验收

见 [实际页面证据](../../verification/2026-11-02-dsh-mobile/README.md)。最低验收：390px/320px 设置无横向溢出、账号和常用设置分类可达、模型表单可滚动、登录各状态可关闭、外部浏览器能打开并返回、桌面布局仍为双栏。登录成功闭环及真实软键盘必须由连接的手机验证。

## 第二轮深入优化

- **信息可见**：输入区为模型单独留一行，显示模型名称与推理等级；320px 实测选择按钮 265×44px，名称不再被替换成图标。
- **返回层级**：模型子菜单 → 父菜单 → 会话；快捷键弹窗 → 主设置 → 抽屉。文件面板回到会话。原生层不再后退到已经消费的连接票据页。
- **登录生命周期**：窗口绑定前离页显式拒绝请求；重复挂载、重复转交、旧回调不影响新尝试；30 秒未到达授权地址则释放并提示。关闭、重连、退出账号和组件销毁统一清理。错误说明有独立关闭按钮。
- **触控**：文件标签栏、返回和关闭按钮 44px；菜单单选项、账号操作等也纳入触控尺寸。
- **维护成本**：合并响应断点，清理缩小字号和隐藏模型文字的旧覆盖；DOM 观察只用于首次侧栏挂载，随后断开，不随聊天流式更新反复扫描。

第二轮的浏览器返回验证通过同源测试框架调用实际的移动返回函数，保留子页面焦点。它验证网页层级行为，不能替代 HarmonyOS 系统按键与登录回流验收。详见 [第二轮验证记录](../../verification/2026-11-02-dsh-mobile/round2/README.md)。

## 第三轮页面与原生能力

- **文件与终端**：取消按禁用状态隐藏分栏控件，解除上游宽度测量循环；竖屏标签与工具分行，横屏工作面板占满宽度。
- **触屏入口**：会话和工作区更多菜单常驻，保留完整操作项；新建会话后抽屉自动关闭。
- **插件与弹窗**：组件说明、状态与开关分行，短屏弹窗整体滚动，安装输入和底部操作不再被挤出。
- **下载与录音**：ArkWeb 下载沿用网页会话，保存到私有临时文件后由系统保存器交付；仅可信 HTTPS 页面的音频请求可触发系统麦克风权限。
- **连接选择**：DSH 独立优先 HTTPS；失败时提供已验证的局域网备用，MyTools 业务 API 仍使用既有连接策略。
- **覆盖边界**：当前记录 47 项页面与能力。服务器编辑器、桌面 DevTools 尚未适配；语音模型和大肥鱼 Host 连接存在服务前置；手机权限、保存、键盘与真实登录回流待设备验收。

详见 [第三轮覆盖清单和截图](../../verification/2026-11-02-dsh-mobile/round3/README.md)。本轮仅代码和预览，未上线或安装。

## 第四轮终端与文件阅读

- 终端以一条可横向滚动的 44px 快捷键栏补齐手机键盘缺少的 Tab、Esc、Ctrl、方向、Home/End 操作。按键只发送到所属且可用的终端，浮层打开时不向后台发送，桌面尺寸不显示。
- 图片、PDF、DOCX 共用稳定宽度的缩放条，比例保持一行。正文留出底部空间，最后一页可以完整滚动到达。
- HTML 短屏取消最小高度，沿用原沙箱。真实交互通过 Chrome 验证；内置预览工具的 Blob iframe 限制与产品缺陷分别记录。
- 新增合成样本验证：PNG、两页 PDF、HTML 计数器与 DOCX。MP4/WAV 的上游不支持状态被明确列出。

见 [第四轮记录](../../verification/2026-11-03-dsh-mobile/round4/README.md)。当前清单 49 项中，33 项完成对应页面预览；真机及其他状态边界仍未视为通过。
