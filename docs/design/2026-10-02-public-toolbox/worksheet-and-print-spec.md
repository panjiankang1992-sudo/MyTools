# 字帖、单词与打印功能详设

> 2026-10-03：字帖工作流与排版以[最新修改方案](../2026-10-03-worksheet-workflow-revision/modification-plan.md)及其契约为准。先输入后选题型、统一可编辑原文、图片 OCR、调整回填、紧凑布局和米字格覆盖本文冲突部分；本文保留为早期设计记录。

本文件是“禹宇天的工具箱”的设计补充，供 UI、前端、内容整理与验收共同使用，不代表已经接入教材词库。除 A4 标准尺寸外，下列尺寸、默认值、阈值与数量限制均为建议值，可在真实打印打样后调整。文内词语和单词均为功能示例，非教材摘录。

## 1. 页面与操作路径

- 桌面端保留全站左侧目录。主工作区从左到右为“练习设置 / 词条选择”面板与“纸张预览”面板；建议主区宽度不足 1000 px 时改为“设置 / 词条 / 预览”标签，不把目录、表单和纸张同时压入窄屏。
- 顶部使用 `NPageHeader` 展示“语文字帖”或“英语单词”，副标题说明当前练习方式；`NTabs` 切换两种模式。切换保留内容选择，只调整题面与书写区域。
- 设置区使用 `NForm`、`NSelect`、`NTree`、`NCheckbox`、`NInputNumber`、`NInput`、`NSwitch`；选择结果用 `NDataTable` 显示，可按问题筛选、编辑、删除与移动顺序。
- 预览工具条固定显示“共 X 题 · X 张学生卷”“上一页 / 下一页”“适合宽度 / 100%”“学生卷 / 答案页”。编辑阶段“打印预览”为主按钮、“导出 PDF”为次按钮；预览内另有“打印学生卷”，答案页打印为独立操作。
- 基本流程：选择模式与教材范围 → 勾选或自动抽题 → 校对 → 设置版式 → 打印预览 → 打印或导出 PDF。空内容时仅显示空纸示意及“请先选择词条”，不生成假题数；应用内预览不依赖浏览器是否支持系统打印。
- 未校对的问题显示在设置区顶部，可一键跳到对应行。阻断项清零后才开放正式生成和输出；内容及版式改动后自动重新分页，旧预览标记“正在更新”，期间禁用打印和导出，完成后自动恢复。

## 2. 语文模式与编辑器字段

| 字段 | 控件与建议默认值 | 规则 |
|---|---|---|
| 练习模式 | 分段选项，默认“看拼音写汉字” | 默写字帖仅露出拼音与必要的消歧语境，答案汉字为空；“看汉字写拼音”露出汉字，拼音区域为空。 |
| 地区 / 学科 / 年级 | 地区默认江苏；语文固定；年级默认未选择，范围 1—6 年级 | 地区用于推荐适用教材，不能代替出版社、版本与学年确认。 |
| 教材版本 / 学年 / 册次 | 下拉框；学年和版本必须明确选择或沿用本机已确认选择；册次默认上册 | 显示版本名、适用年级、来源、修订信息和内容完整度；没有已核验内容时引导手动录入。 |
| 内容类别 | 多选，默认“生字” | 生字、词语、识字表分别保留教材中的类别，不把识字要求自动解释为书写要求。 |
| 选择范围 | 册—单元—课文树，默认不勾选 | 支持全册、部分单元、部分课文及关键词搜索；显示可用条目数与已选条目数。 |
| 内容选择方式 | “按范围全选 / 自动抽取 / 手动录入”，默认按范围选择 | 自动抽取默认 20 条，建议 1—200 条；可按单元均衡抽取或全范围随机抽取。 |
| 题目顺序 | 默认教材顺序 | 另提供手动排序、随机排序；随机排序使用可重现的种子。 |
| 字格 | 默认田字格；1—2 年级建议 14 mm，3—6 年级建议 12 mm | 可选田字格、方格；尺寸建议 10 / 12 / 14 mm；每字一格，不能按 UTF-16 长度计算汉字数；手动改尺寸后不再因其他选项改变而覆盖。 |
| 拼音书写区 | 看汉字写拼音时显示，默认空四线三格 | 可切为空横线；一个字对应一组写音节区域，词语保持为一题。 |
| 重复练习 | 默认每条 1 次，建议 1—5 次 | 重复次数表示学生卷出现次数，与词条去重开关独立；预览显示实际题数。 |
| 标题 / 姓名栏 / 日期栏 | 标题由模式与选择范围生成，姓名栏开、日期栏开 | 自定义标题建议最多 40 字；不要求输入真实姓名；填写栏在纸上留空。 |

语文词条编辑行包含“选择框、字词、带声调拼音、词条类别、来源课文、消歧语境、校对状态、操作”。手动粘贴建议每行一条，支持 `字词<TAB>拼音`；仅输入汉字时可建议拼音，但必须允许逐字修改，并将自动建议标记为待校对。示例：`春风<TAB>chūn fēng`。

## 3. 英语模式与编辑器字段

| 字段 | 控件与建议默认值 | 规则 |
|---|---|---|
| 练习模式 | 默认“看中文写单词” | 中文版题面是中文释义，后接空四线三格；英文版题面是英文，后接写汉语意思的空横线。 |
| 年级 / 教材 / 学年 / 册次 | 年级 3—6，默认未选择；地区默认江苏；版本与学年明确确认 | 年级范围仅决定筛选范围，不声称当前已提供对应教材内容。 |
| 单元 / 内容类型 | 树选择，默认未勾选；类型默认单词 | 短语作为可选项，必须支持空格、连字符、撇号；句子练习暂不混入单词题。 |
| 单词 / 词义 / 词性 | 可编辑表格 | 中文释义按当前单元语境选择；一词多义不默认合并成过长题面。 |
| 大小写 | 保留来源写法 | 人名、星期、月份等不能统一转小写；比较去重时也不得擅自合并大小写不同的答案。 |
| 四线三格 | 建议格高 9 mm，内部三格各 3 mm | 四条线连续，基线适当加深；书写区域默认空白，不显示描红英文或首字母。 |
| 汉义横线 | 建议长度 50 mm | 可选短 / 中 / 长；题面中文长度与英文字符数不能直接作为实际排版宽度。 |
| 题目数量 / 排序 / 重复 | 与语文共用机制，抽取默认 20 条、重复默认 1 次 | 自动抽取范围不足时显示不足数量，允许“使用全部”，不可悄悄重复凑题。 |

英语手动粘贴建议使用 `单词<TAB>中文释义`，可逐行修正词性、短语与语境。示例：`apple<TAB>苹果`、`good morning<TAB>早上好`。当中文提示可能对应多个英文答案时，允许添加词性、语境或用户选择的候选答案；不自动加首字母提示改变默写难度。

## 4. 内容选择、校对与题目一致性

- 全册选择适用于当前“版本 + 学年 + 年级 + 册次 + 内容类别”的可用集合；切换版本、年级或册次前提示现有选择将重置，并保留手动条目到独立待合并区，避免悄悄混用教材。
- 选中集合先做规范化再去重，再抽取，再排序，最后展开重复次数。默认只合并“规范化字词 / 单词 + 读音或词义 + 语境”均相同的词条，保留全部来源定位。
- 规范化仅去首尾空白、统一 Unicode 组合形式及多余分隔空格；不同读音、释义和大小写不得自动合并。可切换“保留各课重复条目”，切换后重新计算数量。
- 随机操作记录并显示种子；“换一组”生成新种子，“恢复上一组”还原上次题目快照。相同候选集合、内容版本、设置和种子应得到相同结果。
- 对均衡抽取先按非空单元分配名额，余数按确定性顺序分配；某单元不足时将剩余名额分配到仍有余量的单元，并在抽取摘要说明实际数量。
- 多音字校对以词语及课文语境为单位；单字缺少语境时要求选定读音或加入短语。拼音需核对声调、轻声、ü、音节分隔和必要的隔音符号，不能只靠拼音库默认首读音。
- “看拼音写汉字”存在同音歧义时显示警告并建议改为词语或添加不包含答案的语境。语境包含答案原文时应阻断学生卷生成并要求挖空或改写，不能泄漏答案。
- “看汉字写拼音”以当前语境的读音为答案；多音字无语境且未明确读音时阻断。“看中文写单词”的多义问题由选定教材语境和词条校对解决，不将某个同义词武断标为唯一正确。
- 生成时冻结 `worksheetId`、题目 ID、源词条版本、题面、答案、顺序、种子、重复序号、版式与字体版本。学生卷和答案页从同一快照派生，答案按题号对应，任何数据更新不改动已生成快照。
- 同一题单纯调整格子、字号、边距时只增加输出 `revision`，保留 `worksheetId/operationId`；更改题目、练习模式或换一组后成功生成新的题单才分配新 ID。预览、下载、打印、自动重分页和失败重试不重复增加成功使用次数。
- 快照只保存在当前浏览器，默认不上传字词、学生姓名或手动内容。可提供“保存到本机 / 清除本机记录”，本机存储失败不影响当前预览与打印；刷新后未保存数据不承诺恢复。

## 5. A4 版式与分页

- A4 纸标准尺寸为 210 × 297 mm；建议默认纵向，四边安全边距各 15 mm，可用内容区 180 × 267 mm。页眉建议 14 mm、页脚 7 mm，并计入可用区，不能额外溢出。
- 默认黑白打印，浅灰格线也须在普通打印机上清晰可见。标题建议 16 pt、题面 12—14 pt、页码 9 pt；左侧目录、工具条、阴影、彩色状态和广告区域不进入打印内容。
- 语文默写：拼音置于空田字格上方，每个汉字对应一个字格；词语整题不可跨页。建议每题最小高度 24 mm、题间距 4 mm，由实测字体和最长拼音决定最终高度。
- 语文拼音：汉字为题面，下面留足空音节书写区域；答案拼音不进入学生卷。带声调显示示例仅出现在编辑帮助中，不出现在答题区。
- 英语中文模式：中文题面可自然换行，四线三格始终完整；按实际字体测量题面宽度和预计手写长度分配区域。建议书写宽度不小于 45 mm，短词可两列，长词或短语自动独占一行。
- 英语英文模式：英文题面完整显示，汉义空横线保留建议至少 50 mm；较长英文占单独一行，书写区可另起一行。不能通过无限缩小字号来强行保持两列。
- 过长词语优先改为整行，再扩大单题高度；单题仍超过单页时提示“请缩短条目或拆分练习”，保留原始输入，不静默裁切。题干与书写区、四线三格、单个田字格均不得跨页拆分。
- 分页必须等待指定字体加载并测量实际布局，按毫米对应的页面高度逐题装箱；`break-inside: avoid` 仅作为兜底。统一排版结果同时驱动页面预览、PDF 预览、PDF 导出和打印；屏幕缩放不改变纸内字号或分页。
- 配置变更建议短暂防抖后自动生成新快照并重新分页；取消尚未完成的旧任务，仅最新修订可更新预览。分页期间禁用打印与导出，保留旧页并明确标记“正在更新”，避免空白闪烁或输出旧设置。
- 页脚显示“第 X / Y 页”及简短练习标识；页眉题目过长自动省略或换行后重算页面。题号全卷连续，重复题保持独立编号，答案页沿用编号。
- 首期建议仅承诺 A4 纵向；横向、A5、自定义纸型如后续加入，需要独立模板与验收，不直接套用纵向缩放。建议单次最多 200 条、展开后最多 500 题，超限提供拆成多份练习。

## 6. 预览、PDF 导出、打印与字体

- 预览提供“学生卷”和“答案页”显式切换，默认学生卷。答案页打印须独立点击，不与学生卷默认混排；复印用学生卷保持纯黑白、无答案、水印和浏览器界面。
- 建议采用独立打印窗口或隔离 iframe，只将学生题面与空白书写结构传入学生卷渲染器；答案内容、`data-*` 属性、隐藏文本、辅助说明、无障碍标签及脚本变量均不传入该打印文档。学生 PDF 同样只接收学生卷投影，不在文本层、附件或元数据内隐藏答案。
- 学生卷安全性不能只依赖 `display: none`、`@media print` 隐藏答案。答案打印使用独立数据投影与独立 DOM，切换模式需销毁并重新构建打印文档，避免旧答案节点残留。
- 字体在当前页面及打印文档全部加载成功后才允许调用打印；字体下载或加载失败时明确提示选择已验证备用字体，并重新分页。字形检测需结合字体字符覆盖表与实际试排，不能把 `document.fonts.check` 当成缺字检测。
- 中文正文可用经过许可核验的常规字体；练习题面如需楷体，应选择允许 Web 嵌入、PDF 嵌入和再分发、且符合简体字形要求的字体包，保存许可证与版本。系统自带字体不能默认打包发布；PDF 使用同版字体并按许可嵌入必要字形。
- 拼音字体必须覆盖带声调元音、ü 及组合符号；英文必须覆盖大小写、连字符和撇号。缺字、缺声调或字形不确定时阻断相关页打印，并定位词条，而非悄悄显示方框或无声调文本。
- 打印帮助简述：纸张选 A4、比例建议 100%、关闭浏览器页眉页脚，先看系统预览；用户更改打印机边距或缩放可能影响纸面，需用实际打印打样验收。
- “打印学生卷”触发后显示“已请求打开打印对话框”；窗口被拦截时提示允许弹窗或重试。`afterprint` 只能说明打印流程已关闭，不能证明实际打印或保存 PDF 成功；统计只记打印请求，不记实际打印成功。
- “导出 PDF”是正式独立能力：当前浏览器生成具有固定页面尺寸、格线与嵌入字体的文件，生成完成后提供下载，失败可重试且不丢选择；手机不支持系统打印时仍可预览和导出。浏览器“另存为 PDF”只作为备用路径，不能替代导出按钮。
- 文件生成成功可以记录“PDF 生成成功”，下载按钮只能记录“下载已发起”，不声称文件已保存到用户设备；系统打印“另存为 PDF”也不能自动记为应用导出成功。

### 输出接口设计

以下为前端模块接口设计，不要求把手动词条上传到服务端；实现时可在 Worker 中执行排版与 PDF 生成。

| 接口 / 数据 | 输入 | 输出与一致性要求 |
|---|---|---|
| `createWorksheetSnapshot` | 校对通过的词条、筛选、种子、重复和版式配置 | 不可变 `WorksheetSnapshot`，含 `worksheetId`、`revision`、内容版本与字体版本；学生和答案输出复用此快照。 |
| `projectWorksheet` | 快照与 `student` / `answer` 类型 | `WorksheetProjection`；学生类型仅保留允许展示的题面与空书写区，答案字段在这一步删除。 |
| `layoutWorksheet` | 投影、毫米纸型、边距、字体度量 | `PageLayout`：页面尺寸、题号、逐页元素、坐标和分页哈希；输出警告、阻断错误及缺失字形定位。 |
| `renderWorksheetPdf` | `PageLayout` 与已验证字体资源 | `PdfArtifact`：`Blob`、页数、文件名、修订号与分页哈希；矢量格线不因手机屏幕尺寸退化。 |
| `previewWorksheet` / `downloadWorksheetPdf` | 同一个 `PdfArtifact` | 预览直接渲染将要下载的 PDF；不在导出阶段另做一次分页，确保页数、题号、答案投影相同。 |
| `requestWorksheetPrint` | 当前修订的 `PdfArtifact` / `PageLayout` | 优先打印同一 PDF；如需 HTML 打印适配则仅用已固定分页的独立 DOM，不重新自动流式排版；返回请求状态而非实际打印成功。 |

建议失败类型包括 `FONT_UNAVAILABLE`、`GLYPH_MISSING`、`ITEM_TOO_LARGE`、`PDF_GENERATION_FAILED`、`STALE_REVISION` 和 `PRINT_UNAVAILABLE`；界面给出中文原因及对应恢复动作。后者仅禁用系统打印，不能连带禁用应用内预览或 PDF 导出。

## 7. 状态、移动端与无障碍

| 状态 | 页面反馈与恢复动作 |
|---|---|
| 尚未选范围 / 空筛选结果 | 明确显示“请选择年级与教材”“当前范围无可用词条”；可清空筛选或切手动输入。 |
| 教材尚未提供 / 只提供部分内容 | 显示真实覆盖范围、缺失单元与来源状态，禁用不存在的选项；不将生成内容冒充教材词条。 |
| 加载 / 离线 / 请求失败 | 设置区骨架或进度状态；提供重试，保留当前选择；已经加载的快照可继续使用。 |
| 拼音、歧义、释义或缺字待校对 | 表格标记原因与修正入口；必要字段缺失、字形缺失等阻断生成，单纯来源未核验明确区别。 |
| 正在生成 / 设置已变更 | 自动重新分页，显示进度与取消；旧预览标为过期并禁用打印和导出，完成后恢复，防止输出与设置不一致。 |
| PDF 生成失败 / 系统打印不可用 | 保留快照与预览；PDF 失败提供重试，系统打印不可用时仍允许正常导出 PDF。 |
| 超过建议数量或页面容量 | 提供减小范围、分批生成与单题改行操作；不默默截断内容。 |

- 移动端固定使用“设置 / 词条 / 预览”三个标签，全站目录从左侧抽屉打开。设置短表单单列，词条使用卡片列表，逐条编辑使用单列抽屉或页面，不把桌面多列表格缩小塞入手机。
- 手机底部操作条保留“打印预览”主按钮、“导出 PDF”次按钮，标签页变化时位置一致；主按钮始终能进入应用预览。预览中的系统打印不可用时显示原因，并保留导出入口。
- 兼容宽度覆盖 320、360、390、768 px：320 px 下标题换行且按钮不溢出，360 / 390 px 保持完整单列，768 px 优先保留标签布局与宽预览，不强制恢复目录、设置、预览三列。页面不得横向滚动，纸张放大视口可单独平移。
- 触控热区建议至少 44 × 44 px，底部操作条考虑 `safe-area-inset-bottom` 并为内容预留等高内边距。软键盘出现时保证当前输入与错误提示可见，可将操作条收起到非遮挡状态；关闭键盘后恢复，不能挡住最后一条词条或输入框。
- 移动预览优先整页缩略图，可双指放大查看；放大状态不影响实际打印。返回编辑保留题号和当前页，切换设备不承诺自动同步。
- 所有输入均有可读标签，错误信息同时使用文本与图标；树和词条选择可键盘操作，切页与生成结果通过可访问提示通知。建议触控热区不少于 44 px。

## 8. 建议验收矩阵

| 场景 | 验收结果 |
|---|---|
| 语文两种模式 × 1—6 年级范围 | 确认筛选与可用内容一致；默写卷无答案汉字，拼音卷无答案拼音，题号与答案页逐条对应。 |
| 英语两种模式 × 3—6 年级范围 | 中文模式仅中文提示与空四线三格；英文模式仅英文提示与空汉义横线，大小写与短语保持正确。 |
| 全册 / 单元 / 课 / 手动 / 自动混合 | 选择数量、去重合并来源、随机抽取和重复展开正确；相同种子可重现，数量不足不自动重复。 |
| 多音字 / 同音词 / 多义词 / 组合声调 | 未解决阻断项不能打印，校对后题面与答案一致；消歧语境不包含待填写答案。 |
| 单字 / 长词 / 长短语 / 长标题 / 重复题 | 无格线截断、无跨页半题、无遮盖页脚；整行降级或明确报错，预览与打印页数相符。 |
| 学生卷答案隔离 | 检查打印 DOM、属性、可访问文本、脚本及 PDF 文本层和元数据，无答案字段；连续切换答案页后学生卷仍无残留。 |
| 字体慢加载 / 缺字 / 离线 / 备用字体 | 不先打印后换字体；缺字定位准确，备用字体切换后重新分页，已有快照不被悄悄改写。 |
| Chrome / Edge / Safari 桌面端与移动浏览器 | 在实施时记录版本；验证系统预览、取消、打印请求、正式导出和备用另存 PDF，不将取消记为打印成功。 |
| A4 实纸与导出 PDF | 用尺检查 15 mm 边距、低年级 14 mm / 高年级 12 mm 字格和四线三格，检查黑白可读性；预览 PDF 与下载 PDF 的分页哈希、页数、题号一致。 |
| 320 / 360 / 390 / 768 px 与软键盘 | 左侧目录正确折叠，标签与单列表单无水平溢出；输入、错误提示、底部两项操作和安全区互不遮挡。 |
| 手机系统打印不可用 | 仍能进入完整预览并独立生成、下载 PDF；系统打印不可用不会屏蔽全部输出功能。 |
| 快速连点 / 修改后打印 / 刷新 / 本机存储失败 | 只接受最新修订，自动分页期间不能输出旧卷；未保存状态和存储错误清楚提示且不丢当前页面内容。 |
