## 1. 执行规则

### 1.1 状态与结果

| 状态 | 使用条件 |
| --- | --- |
| `not_run` | 尚未执行；不能从代码存在或历史报告推导通过。 |
| `pass` | 本用例全部步骤和全部要求的参数组合满足预期，证据能够独立复核。 |
| `fail` | 已执行并观察到不符合预期的行为；保存首次失败证据和修复后重跑记录。 |
| `blocked` | 缺少运行条件，例如未取得对应教材来源、没有实体打印机、缺实机或无发布授权。写清原因、责任人、解除条件和受影响需求。 |

一个用例有多个子场景时，任一失败则主用例不能通过；有必测子场景阻塞时主用例也不能通过。先完成其他可执行子场景，不能用总体百分比隐藏缺口。每条记录包含 `caseId`、提交标识、构建版本、环境、开始/结束时间、步骤实际值、退出码或浏览器结果、证据路径、执行人和状态。证据中的凭据、cookie、内部令牌必须脱敏；需要验证归属时记录会话标签 A/B，不导出明文 cookie。

### 1.2 环境与设备

- 自动检查：Node 24、Java 21、独立测试数据库和公开存储根；PDF 服务、Storage、Scheduler、执行包采用拟发布配置。不得对现有生产 MyTools 执行压测、故障注入或清理实验。
- 桌面真实浏览器：Chrome、Edge、Safari，执行时填写版本、操作系统和设备。浏览器内核相同不能替代三者的下载/打印实际验证。
- 移动实机：iPhone Safari、Android Chrome；填写系统版本、设备型号及打印服务是否可用。模拟视口只能证明布局，不能证明软键盘、设备文件保存或系统打印。
- 布局矩阵：320、360、390、430、768、1280、1440 px 宽；推荐高度分别为 740、800、844、932、1024、900、1024 px；另测手机横屏和桌面 200% 缩放。
- 会话隔离：两个全新独立浏览器上下文 A/B，cookie 不共享；另备一个经授权的 MyTools 私有测试用户 C。C 仅用于测试环境私有行为回归。
- 数据：合成边界夹具与真实教材分别标识。真实教材未到位时合成夹具可验证代码，但不能代替 20 册内容验收。

### 1.3 数值容差与可判定边界

- PDF 几何值以 PDF 内坐标为准，换算 `pt = mm × 72 / 25.4`。A4 为约 `595.276 × 841.890 pt`；纸张、格线坐标和预设间距几何误差均不得超过 **0.5 pt**。屏幕缩放截图不用来测毫米。
- 实纸使用 A4、100%/实际大小、关闭适合页面和浏览器页眉页脚。田字格及四线三格间距相对目标值误差不超过 **±0.5 mm**；默认 15 mm 安全边距误差不超过 **±1 mm**。姓名栏、页眉等若不贴边，则测版式外框/测试定位标记，不把首字位置误当页边距。
- 至少四种模式各有一张真实打印样张，并覆盖中文 14 mm 和 12 mm 格；建议共五张。无打印机则 A28=`blocked`，打印成另一个 PDF 不能替代实体纸。
- 预览/下载“同一文件”要求 SHA-256、页数、题号、revision 一致；跨实现比较 PDF 引擎语义时，不要求二进制一致，比较页数、尺寸、内容、顺序和方向。
- 没有页面整体水平溢出：`document.documentElement.scrollWidth <= document.documentElement.clientWidth + 1`。允许已标明的纸张放大容器独立平移，不允许整个页面因此变宽。
- 所有需手指操作的图标实际点击框至少 44×44 CSS px；不能只测图标 SVG 尺寸或主按钮。

## 3. 夹具与证据目录

以下为**待建立**的建议目录。合成文件可进入仓库；真实来源原件须按内容取得时确认的使用范围管理，不能为验收方便把完整教材 PDF 公开进仓库。

```text
toolbox-web/tests/fixtures/
  manifest.json
  curriculum/synthetic/{catalog.json,entries.json,expected-selection.json}
  worksheet/{edge-cases.json,expected-projections.json}
  pdf/{inputs/,expected/}
  analytics/{events.json,tasks.json,expected-stats.json}
docs/verification/public-toolbox/
  implementation-status.md
  environment.json
  curriculum-coverage.json
  curriculum-mode-results.json
  release-manifest.json
  cases/A01/.../result.json
  cases/A25/downloads/
  cases/A28/{measurements.csv,photos/}
  cases/A46/{cleanup-before.json,cleanup-after.json}
```

`manifest.json` 的最小格式如下；尖括号值是待填写占位符，不能直接用于宣称完成。每个 fixture 记录实际 SHA-256，生成器本身也版本化；压缩包另记录内部文件名/大小/hash。

```json
{
  "schemaVersion": 1,
  "fixtures": [
    {
      "fixtureId": "pdf-seven-pages",
      "path": "pdf/inputs/seven-pages.pdf",
      "kind": "synthetic",
      "generatedBy": "<generator-path-and-version>",
      "sha256": "<actual-64-hex-digest>",
      "expected": {
        "pageCount": 7,
        "pageLabels": ["PAGE-1", "PAGE-2", "PAGE-3", "PAGE-4", "PAGE-5", "PAGE-6", "PAGE-7"]
      },
      "caseIds": ["A52", "A56"]
    }
  ]
}
```

真实内容 fixture 还必须有 `editionId/contentVersion/sourceRef/reviewRecordRef`，不得把 `kind: synthetic` 改成教材就通过。语文夹具至少含不同读音同字、组合声调、轻声、ü、隔音符号、补充平面字符；英语至少含大小写不同词、同词不同义、带空格/连字符/撇号短语。PDF 夹具至少含唯一页标、混合纸型、旋转、非零裁剪框、批注、空白、损坏、加密、交互表单、无文字扫描页、中文未嵌入字体、超大像素头、受管 Markdown 图片与表格。

单条结果使用下列格式。`actual` 和 `evidence` 只有执行后才能填；不得将计划步骤复制到 actual。必要时为每个浏览器、设备、教材模式生成子记录，父用例状态由最差子记录决定。

```json
{
  "caseId": "A25",
  "status": "not_run",
  "commit": null,
  "releaseId": null,
  "environmentRef": "../../environment.json",
  "parameters": { "browser": null, "mode": null },
  "startedAt": null,
  "finishedAt": null,
  "actual": [],
  "evidence": [],
  "blocker": null,
  "executedBy": null
}
```

## 5. 下载工具超时的替代取证流程

当前原型曾出现自动化下载事件等待超时。遇到同类问题时先保留工具错误，不能把“点到了按钮”记 pass，也不能立即判应用下载坏了。按以下顺序补证：

1. 在普通 Chrome/Edge/Safari 打开当前测试站，记录浏览器版本、构建标识、模式和 revision；手机用系统浏览器。
2. 明确设置或查看该浏览器的下载目录。点击网站正式导出/下载按钮；通过浏览器下载列表确认文件完成，记录实际文件名、时间、大小及目录。不能只检查下载 toast。
3. 从该实际目录读取文件；手机从“文件/下载”中定位，可通过用户授权的本机文件通道转存后核对 hash。记录设备路径和转存路径，不把另行调用生成函数得到的文件冒充按钮下载。
4. 独立检查文件头 `%PDF-`、字节数、SHA-256、页数、A4 几何、字体/文字和附件；打开首末页。与前端对应 artifact 的 hash/revision/页数核对。PDF 工具的 ZIP/图片/文本按各自文件格式检查。
5. 保存浏览器下载完成截图、实际文件路径和独立检查输出。满足 A25 对应浏览器的全部要求后才可 pass，并备注“自动化事件工具不可用，普通浏览器落盘已验证”。
6. 若仍无法实际观察文件落盘，则此子项 `blocked` 或在有失败证据时 `fail`；保留生成和预览已通过的子证据，但主项不算通过。系统“打印为 PDF”不能替代网站独立导出按钮的验收。

可使用 `shasum -a 256 <实际下载路径>`、可用的 `pdfinfo`/`pdftotext`/`pdffonts` 和独立渲染器；工具缺失应在执行环境安装或使用等效库检查，不假设已安装。检查工具、版本、执行命令及退出码都要存档。含个人自定义内容的文件不得上传第三方验证服务。
