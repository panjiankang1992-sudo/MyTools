# MyTools 内的 DSH Web 能力设计

DSH 标签保留当前 DSH Web 作为会话与工作区的界面和协议来源。Web 负责聊天、附件、模型、权限、终端、插件、任务和设置。MyTools 负责登录换票、网络恢复、手机系统选择器和下载保存。这样，网页和手机对同一个会话使用同一套权限、附件处理和运行状态。

## 手机交互

- 编辑区工具栏仍把模型、推理等级、语音和发送放在一行。打开附件入口后，可选「图片和视频」或「本地文件」，再由系统选择单项或多项。返回的授权 URI 交给原网页输入控件，由 DSH 提供附件预览、移除、上传与错误反馈。
- 上传窗口与当前页面、连接、账号绑定。离开 DSH、重新连接、切换账号或入口时结束旧请求。唤起系统选择器后短暂进入后台，允许该次选择正常返回。
- 使用 DSH 原有的 Markdown、文件预览、终端和设置组件。原生能力仅在可信 DSH 页面打开，第三方授权走系统浏览器，下载走系统保存器。文件选择沿用 ArkWeb 与系统 Picker 接口。[HarmonyOS Web 文件上传](https://developer.huawei.com/consumer/en/doc/HarmonyOS-Guides/web-file-upload/)

## 连接与代理

IPv6 直连在换票或加载阶段失败后，DSH 用公网 API 重取一次性票据，再打开公网网页。网络恢复或从系统网络设置回到 MyTools 后，即使业务仍使用相同地址，也能重试已失败的初次加载。已打开的公网 DSH 页面独立于业务入口的切换，以保留草稿、附件和在途操作。挂载后的会话恢复仍由 DSH 处理，明确失效时由用户触发重连。

公网和直连接入应覆盖同一版 DSH 的文件上传、已知 RPC、文件预览和插件流。共享入口按 DSH API 路径分流，经过现有 DSH 网页会话认证。请求与响应支持流式传输，DSH JSON 和二进制上传具备独立请求预算。公网中继还受 Cloudflare 套餐和站点配置的单请求上限约束。[Cloudflare 上传限制](https://developers.cloudflare.com/support/troubleshooting/http-status-codes/4xx-client-error/error-413/)

公司 Wi-Fi 到公网入口不可达时，换票和重连仍依赖实际可达的授权入口。前次在同一手机切到移动数据后恢复，说明该场景需要与家庭 Wi-Fi、IPv6 直连和移动数据分别验收。[公司网络排查](/Users/pankang/mycode/MyTools/docs/verification/2026-11-14-dsh-company-network/README.md)

## 功能验收

| 功能组 | 验收内容 |
| --- | --- |
| 连接和授权 | 公网、IPv6 和局域网换票，网络中断与恢复，旧票据与账号切换，外部网页登录回流。 |
| 附件与文件 | 手机文件选择、相册多选、拍照、取消；普通文件和图片进入同一编辑器，预览、移除、上传及下载；测试大于 1 MiB 的文件和超限反馈。 |
| 会话和模型 | 新建、搜索、历史、置顶、分叉、归档、模型与推理等级、生成与停止、授权交互。 |
| 工作区和预览 | 目录浏览、文件编辑、工作区权限、图片、PDF、Office、HTML、交付物下载。 |
| 终端、插件和自动化 | 触控快捷键、分屏和软键盘；插件浏览、配置和启停；任务创建、暂停与运行记录。 |
| 账号和语音 | 账号、设置、外部授权与原生录音。转写还需要 DSH 主机准备相应模型。 |
