# 组件状态与交互规范 · 1.2

这份规范与完整组件库配套。每个组件至少提供默认样例和相关状态示例；状态标签是索引，不能代替实际样例。HTML 为设计评审环境，客户端的触摸、读屏与原生行为在实施阶段验证。

## 全局约定

- 沿用固定打包 Noto Sans SC，动作文字16/22、字段值16/24、说明12/18。主按钮可见40、次按钮36、真实命中区域至少44；字段默认最小48高。
- 一个值只有一个来源；区分已提交值与弹层草稿值。取消恢复原值，确认才提交；即时开关应明确保存中、成功、失败回滚。
- 空、无搜索结果、无来源、未登录、无权限、离线、失败分别表达，不互相替代。后台刷新保留已有内容。
- 控件自身的禁用与整个功能的不可用分开：静态禁用不能代替解释。只读值可选择/复制，视觉不能与禁用混淆。
- 控件边界、选中、警告、错误与焦点不只靠颜色；结合勾选、文字、边框或结构变化。
- 普通交互反馈100–160ms；面板切换140–220ms，尊重减少动效。动效不改变核心操作位置。

## 状态矩阵

| 组件族 | 必备状态样例 | 状态转换与反馈 | 关键边界 |
| --- | --- | --- | --- |
| 按钮/链接 | 默认、按下、焦点、加载、禁用、完成 | 加载保持宽度，防止重复激活；失败在附近说明并允许重试 | 长文案、大字、同组主次、危险动作 |
| 文本/密码/数字 | 空、已有值、聚焦、错误、禁用、只读 | 标签持续可见；输入中不频繁打断；失焦或提交按规则校验 | 长文本、中文输入法、清除、显隐、合法小数/负数 |
| 搜索 | 初始/历史、输入、搜索中、结果、无结果、失败 | Enter与搜索按钮行为一致；清除恢复初始；新查询取消或忽略旧响应 | 中文组合输入不提前提交；分页去重；查询范围明确 |
| 单选/下拉 | 折叠、展开、选中、禁用、请求中、空选项、失败 | 选中后回填名称；值存稳定ID；选择与取消边界一致 | 无来源、旧值失效、超长选项、键盘定位 |
| 多选/级联 | 未选、部分选中、全选、已选数量、上限、下级加载 | 多选可清除单项；切换上级时清理失效下级并解释 | 全选仅当前范围或全部结果必须标明；不静默丢失已选项 |
| 日期/时间 | 空、选中、今天、不可用日期、越界、无效范围、清空 | 日期/时间草稿与提交分开；取消恢复；快捷日期与手选联动 | 末日、闰年、跨月/年、时区、夏令时、范围端点 |
| 开关/勾选 | 开/关、选中/未选、部分选中、禁用、保存中、失败 | 开关表示即时设置；需确认的多项配置使用复选框+提交 | 不能用开关替代导航；授权条款可单独打开 |
| 滑块/步进/色彩 | 最小、当前、最大、禁用、边界、输入错误 | 显示精确值与单位；连续预览与最终提交分开 | 双端不能无意越位；提供精确输入或增减替代 |
| 导航/菜单 | 当前、未选、不可用、溢出、带徽标、返回 | 同级切换保留必要的滚动与筛选；菜单执行动作 | 菜单动作与选择值不同；长路径省略中间层 |
| 列表/表格/树 | 默认、选中、部分选中、长内容、展开、空、刷新 | 使用稳定键；展开/选择语义独立；保留已有数据 | 表格窄屏按优先列/横向滚动，不能压到不可读 |
| 进度/任务 | 排队、不确定、确定、暂停、取消、成功、失败 | 有真实总量才显示百分比；取消与移除任务分开 | 0%不等于等待；99%不等于完成；不能伪造进度 |
| 弹层/提示 | 打开、关闭、输入、提交中、失败、危险确认 | 模态层限制焦点；Escape/返回关闭；关闭后回到触发处 | 键盘和安全区；未保存内容；禁止层层堆叠弹窗 |
| 文件/媒体 | 选择、权限不足、验证失败、处理中、完成、格式不支持 | 文件名、类型、体积与进度一致；预览失败可回退打开方式 | 同名、超限、损坏、网络失败、音视频续播 |
| 阅读/聊天 | 缓存中、已缓存、离线、失效、发送中、流式输出、失败 | 内容优先；缓存与阅读进度分开；流式状态可停止 | 封面详情/正文阅读命中分开；输入保留；不暴露凭据 |

## 成组操作的视觉一致性

确认/取消等一组按钮使用相同宽度、高度、字号、字重、圆角和基线。最小宽96、可见高40、点击高44、间距8，文字16/22、500。文字长度不决定各自独立宽度，取组中最长项的需求作为共享宽度。填满容器时等分；长文案共同增高；工具栏独立动作按内容自然宽度。

## 下拉与选择面板

1. 触发字段最小48高，右侧箭头属于同一触发区域；值可清空时清除与展开按钮有各自名称和44命中区。
2. 桌面弹出列表与字段至少等宽，间距4–8；碰到视口边缘自动调整方向。手机优先底部选择面板，提供标题、当前值、关闭及搜索。
3. 选项行至少44–48高，选中以勾选与文字表达。长列表有独立滚动；请求中、空选项和失败出现在选项区。
4. 搜索下拉匹配名称与必要别名，不把输入文本直接当作选中ID。无匹配显示“没有匹配选项”；没有配置来源显示“尚未添加来源”。
5. 多选显示已选数量及可移除项；级联明确当前层级。重置/取消/确认含义固定，不在不同页面互换。

## 日期与时间

- 日期只表示年月日，使用 `YYYY-MM-DD` 语义，不经过UTC隐式转换。时间值说明是否含秒、采用24小时制还是12小时制。
- 表示具体时刻时，保存时区或明确的偏移；展示日期时间时标明当前时区。范围开始必须不晚于结束；端点是否包含在组件接口里固定。
- 今天、已选日期、区间中段、不可用日期有不同表现。跳月/跳年不改变已提交值；选择预设范围会更新草稿和高亮。
- 7列日历的44宽命中区域至少需要308宽。320vp设备用全宽面板，网格左右最多6；不能在两侧20边距内重叠触摸区域。评审卡片空间不足时，示例可滚动查看，但不作为客户端布局方案。
- 键盘焦点进入当前已选日；方向键逐日/逐周移动，翻月后仍提供有效焦点。屏幕阅读名称包含完整日期和状态。

## 搜索按钮与搜索框

| 场景 | 采用样式 | 规则 |
| --- | --- | --- |
| 独立搜索页/书源搜索 | 输入框+明确“搜索”按钮 | 按钮16/22、底板40；Enter提交同一个查询；空查询不发请求 |
| 工具/本地列表筛选 | 带清除的搜索框 | 就地过滤；显示结果数；不要求每次再点击提交 |
| 页头搜索入口 | 44图标按钮 | 可访问名称说明搜索范围；打开后聚焦输入框 |
| 历史/联想 | 输入框+建议列表 | 区分历史与推荐；删除历史与选择建议不能互相误触 |

## 单个组件的交付条件

每项组件须具备：稳定ID、真实样例、场景、变体、适用状态、尺寸/字体、值与事件、输入校验、取消/重试语义、可访问要求、窄屏/大字/深色处理和不适用边界。公共规范加该项规范共同构成实施要求。
