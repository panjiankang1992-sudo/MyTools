# MyTools 全场景组件样例与规范 · 1.2

初版日期：2026-11-02；输入行规则修订：2026-11-03。状态：完整设计目录已获批准；现有客户端场景已进入公共组件迁移，具体实现与验证边界见 `../../verification/2026-11-02-ui-system/IMPLEMENTATION.md`。

本规范将按钮之外的选择、日期、搜索、表单、反馈、弹层、内容与业务组合纳入同一体系，共 **10 组、72 个语义组件**。机器可读目录在 `component-catalog.json`，可见样例在本地评审画布的组件库中。颜色、字体和按钮基础沿用 `UI-SPEC.md`、`FONT-SPEC.md` 与 `tokens.json`。

组件名与接口是拟定语义，不表示72个组件都已在客户端实现。部分日期、范围、评分等属于规范补齐，便于同类场景出现时直接复用；不会因此向现有只读页面新增业务能力。14张关键页面是业务布局模板，72项组件目录提供控件级样例与使用合同，两者都需要纳入后续迁移。

## 1. 使用与复用原则

- 先选业务语义，再选视觉变体：执行用Button，视图切换用Segment/Tabs，缩小结果用FilterChip，静态状态用TagBadge，不因外形相似而混用。
- 原生框架提供的输入、焦点、辅助设备能力优先保留；统一的语义组件负责外观、状态、尺寸、值和事件合同。没有必要重复造一套低层输入引擎。
- 相同任务使用相同组件与接口，不继续在页面内增加另一套私有文字按钮、选择器或提示条。特殊阅读/媒体覆盖层使用对应语义色，但不改变交互合同。
- 一个控件样例至少应展示正常使用及最关键的差异状态。完整规范列出该控件适用状态，不能把所有控件机械套成同一份加载/成功清单。
- 组件展示中的可见底板尺寸与实际可点击区域分别标注；实际命中区属于该控件本身，不能用覆盖邻居的透明层补足面积。

## 3. 值、草稿与异步状态

### 表单状态必须分清

- **禁用**：当前无法操作，附近说明原因；不要让用户只根据变灰猜测。
- **只读**：可读、可复制的已存在值，维持必要对比度，不冒充可编辑输入。
- **错误**：说明问题与修正方法，关联具体字段；原值保留，错误不是清空整个表单的理由。
- **草稿**：在选择层、日期层、颜色或参数面板里编辑但尚未确认的值；取消应恢复已提交值。
- **立即生效**：开关、快速筛选等场景可以直接变更；保存失败要恢复或明确显示未保存，不能只表现成成功。

### 请求状态必须分清

首次加载、已有内容刷新、加载更多、真实空数据、筛选无结果、无来源、无权限、来源失效与请求失败是不同状态。已有结果不因刷新而闪空；分页失败不丢已加载页；无法获取总量时用不定式加载，不制造百分比。

中文输入法合成阶段不提交查询或发送消息。新查询结果不能被较旧请求覆盖；搜索的清除、取消、返回和提交是不同动作。

### 日期与时区是明确的数据合同

- 单个日期采用 `YYYY-MM-DD` 等date-only值保存，不在中间隐式转成UTC午夜再显示。
- 范围UI默认包含首尾日期，按明确业务时区解释；服务端若使用半开时间区间，由业务层显式转换，不把结束日00:00当完整结束日。
- 时间点必须携带偏移或时区信息；切换时区时明示是保留同一瞬间还是保留钟面时间。纯时间值不擅自附加日期与时区。
- 选择层用草稿；切月或预览不等于提交；确认提交、取消保留原值。清空与取消不同。
- 日历7列各44命中需至少308宽；**320vp设备使用全宽面板，日期网格左右最多6**。不能继续套20页面边距，也不能用相互覆盖的命中区弥补。较宽设备可居中或左右16。

<a id="a01"></a>

#### a01 · 动作按钮 / Button

推进当前任务的标准按钮，以角色区分主要、次要与危险动作。

- **变体**：主操作、次操作、危险确认。
- **状态**：默认、按下、焦点、加载、禁用、成功、失败。
- **尺寸**：独立动作主底板40、次36、命中44；16/22，主600、次500；圆角10，左右14。与输入框同行时启用`fieldAligned`，可见底板与命中最小48、圆角12、上下内缩0。
- **值与行为**：同一任务区一个主动作；加载阻止重复提交并保留宽度，失败保留输入并给重试。
- **辅助设备**：名称描述动作与对象；键盘可激活；忙碌与不可用状态可读屏识别。
- **使用边界**：不要用多个同色主按钮并排争抢，也不要把静态状态做成按钮。
- **拟定接口**：`variant, label, enabled, loading, loadingLabel, grouped, fieldAligned, onAction`。

<a id="a02"></a>

#### a02 · 文字操作 / TextAction

工具栏和行内的轻操作，文字可辨认而外形克制。

- **变体**：纯文字、图文、危险文字。
- **状态**：默认、按下、焦点、加载、禁用。
- **尺寸**：16/22、500；左右8，命中44；按下弱底32；图文间距6。
- **值与行为**：一行保留2–3个高频操作，其余进入更多；不改变相邻内容布局。
- **辅助设备**：必须有按钮语义；图标不替代可访问名称；加载状态说明当前动作。
- **使用边界**：不要用可点击Text替代按钮，也不要压小字号以容纳过多操作。
- **拟定接口**：`label, icon, tone, enabled, loading, onAction`。

<a id="a03"></a>

#### a03 · 图标按钮 / IconButton

用于返回、搜索、关闭和更多等高频短动作。

- **变体**：透明、弱底、选中。
- **状态**：默认、按下、焦点、选中、禁用。
- **尺寸**：独立图标命中44×44、弱底可见32；图标20–24；相邻命中区间距至少8。输入行`fieldAligned`模式可见底板与命中均48×48、圆角12、无透明内缩。
- **值与行为**：作用范围由容器明确；关闭只关闭当前层，返回沿既有导航栈。
- **辅助设备**：提供返回、关闭或具体对象更多等名称；选中按钮播报切换状态。
- **使用边界**：不要用无标签图标承载难理解的业务操作。
- **拟定接口**：`icon, accessibilityText, selected, enabled, fieldAligned, onAction`。

<a id="a04"></a>

#### a04 · 成组操作 / ButtonGroup

同一流程的主次、确认取消或批量动作组合。

- **变体**：主次双按钮、确认取消、批量工具栏。
- **状态**：默认、提交中、部分不可用、大字换行。
- **尺寸**：组内等宽等高、间距8；可见底板与命中最小44同框；统一16/22、字重500、圆角10、左右12。非满宽双按钮组以200总宽为上限，受父级可用宽约束；各按钮默认最小宽0并由父级等分，长标签自然换行并共同增高。
- **值与行为**：确认/取消和主次双按钮默认等宽；按最长标签确定共享宽度，填满模式等分容器。两项和三项组合都由`AppEqualActionRow`承载单原生Button根的`AppGroupedButton`；父容器迭代实际子节点，先等宽测自然高度，再以相同最大精确高度二次测量并顺序放置。构建器直接输出动作，不增加Flex包裹；不通过布局回调反复写状态。兼容Pill包装器的grouped分支转交原生分组按钮；旧`AppButton.grouped`仅保留兼容，不作为等高保证。颜色区分主次，字重不再一粗一细。提交时宽度稳定，保留安全取消路径。
- **辅助设备**：焦点按视觉顺序移动；组名说明所作用的选中项目与数量。
- **使用边界**：不要把危险实色与普通主动作同时高亮。原生Flex Stretch不能单独作为等高保证；模拟测量也不构成平台实测，必须在真机验证长标签换行后的可见底板高度。
- **拟定接口**：`actions, equalWidth=true, minWidth=96, fullWidth, orientation, busy, selectionCount, onAction`。

<a id="a05"></a>

#### a05 · 链接 / Link

在正文或说明中进入明确位置，区别于执行动作。

- **变体**：行内、独立行、外部链接。
- **状态**：默认、焦点、已访问、不可用。
- **尺寸**：正文16/24或随段落字阶；独立链接命中至少44；行内保留可识别下划线。
- **值与行为**：内部链接保持返回路径；外部链接展示去向，触发后不丢失当前输入。
- **辅助设备**：使用链接语义和有意义名称；外部打开方式可被辅助设备识别。
- **使用边界**：不要把删除、保存等副作用动作伪装成链接，也不要只写点击这里。
- **拟定接口**：`label, href, external, accessibilityText, onOpen`。

<a id="a06"></a>

#### a06 · 悬浮操作 / FloatingAction

在长列表或沉浸内容上提供一个必要的快捷入口。

- **变体**：单图标、图文扩展。
- **状态**：默认、按下、焦点、暂时隐藏。
- **尺寸**：命中至少44；紧凑底板40；距内容边缘16–20，避开底部安全区与键盘。
- **值与行为**：同一视口最多一个；滚动和键盘期间可避让，不能遮住正文或列表最后一行。
- **辅助设备**：名称说明具体动作；按正常焦点顺序可达，隐藏时移出焦点树。
- **使用边界**：不要将多个低频操作悬浮堆叠，也不要持续闪动吸引注意。
- **拟定接口**：`icon, label, visible, placement, safeArea, onAction`。

#### i01 · 单行输入 / TextField

带持久标签、帮助信息和就近校验的基础字段。

- **变体**：文本、邮箱、网址、只读。
- **状态**：空值、输入、聚焦、已填、错误、只读、禁用。
- **尺寸**：字段最小48、圆角12、左右14；值16/24；标签14/20；帮助和错误12/18。
- **值与行为**：输入同步草稿；失焦或提交时校验，清除不触发提交；只读值仍可选择复制。
- **辅助设备**：标签关联字段；必填、错误和帮助可关联播报；键盘类型匹配内容。
- **使用边界**：不要仅用占位符作为标签，也不要把只读值做成不可辨认的禁用态。
- **拟定接口**：`value, label, type, required, readOnly, disabled, error, onChange, onBlur`。

<a id="i02"></a>

#### i02 · 多行输入 / TextArea

用于较长描述、提示词和文本处理输入。

- **变体**：自动增高、固定可滚动、计数。
- **状态**：空值、输入、聚焦、临近上限、超限、错误、只读。
- **尺寸**：表单多行输入最小120高、内边距14；16/24；计数12/18；随字号增高而不遮挡光标。会话输入使用b07的48–128增高规则，不强制套用表单120起始高。
- **值与行为**：换行输入正常保留；限制按约定字符规则计算；提交失败保留内容和滚动位置。
- **辅助设备**：标签与计数关联；超限用文字说明；键盘与辅助设备可进入滚动内容。
- **使用边界**：不要每输入一个字都弹出错误，也不要静默截断用户长文本。
- **拟定接口**：`value, label, minRows, maxLength, countMode, error, onChange`。

<a id="i03"></a>

#### i03 · 密码与敏感字段 / PasswordField

默认隐藏内容，可明确切换显示并提供就近错误。

- **变体**：隐藏、显示、只读凭据。
- **状态**：空值、输入、显示、错误、提交中、禁用。
- **尺寸**：字段最小48；值16/24；显示切换命中44×44，尾部为其预留空间。
- **值与行为**：显隐不清空值或移动光标；提交或离开流程后的保留规则由对应业务定义。
- **辅助设备**：显隐按钮播报显示密码或隐藏密码及当前状态；错误避免重复读取敏感值。
- **使用边界**：不要在列表提示、Toast或样例中回显真实密码。
- **拟定接口**：`value, label, visible, error, enabled, onChange, onToggleVisibility`。

<a id="i04"></a>

#### i04 · 数值输入 / NumberField

需要精确数值时使用，单位、范围和精度清楚可见。

- **变体**：整数、小数、带单位、可为空。
- **状态**：空值、输入中、有效、越界、格式错误、只读。
- **尺寸**：字段48；16/24；单位14/20；错误12/18；单位与输入区域分开。
- **值与行为**：允许负号和小数点等编辑中间态；提交时校验min/max/step，不静默改写未确认值。
- **辅助设备**：名称包含单位；上下界和步长可读屏获取；保留直接输入路径。
- **使用边界**：不要将种子或编号当浮点数格式化，也不要只靠数字键盘限制合法值。
- **拟定接口**：`value, min, max, step, precision, unit, nullable, onChange, onCommit`。

#### i05 · 搜索栏 / SearchBar

整合输入、清除、搜索触发和范围说明的完整搜索入口。

- **变体**：即时筛选、提交搜索、带范围。
- **状态**：空值、输入、建议、搜索中、有结果、无结果、错误。
- **尺寸**：输入区48，16/24；搜索/清除各44命中；组合间距8。多媒体使用紧凑同行工具栏：目录、标签在左，弹性搜索在右；目录/标签触发器各68宽、13/18字、间距6。三者可见边框与底板统一48高、12圆角；大字时按同一行高同步增高，不能只统一透明点击区。长选中值省略并保留完整可访问名称。
- **值与行为**：即时筛选和提交搜索必须明确区分；中文输入法合成期间不发请求；新查询取消或忽略旧结果。
- **辅助设备**：字段名称描述搜索对象；键盘搜索与按钮同效；结果数量适度播报。
- **使用边界**：不要让正在请求显示成无结果，也不要清除输入时顺便离开搜索页。
- **拟定接口**：`query, scope, mode, loading, resultCount, onChange, onSubmit, onClear`。

<a id="i06"></a>

#### i06 · 搜索触发按钮 / SearchButton

明确提交当前查询，与搜索框清除动作分离。

- **变体**：文字搜索、图标搜索、取消搜索。
- **状态**：可提交、查询中、取消中、禁用、失败可重试。
- **尺寸**：独立搜索动作文字16/22、底板可见36或主路径40、命中44；图标20、命中44×44。与搜索字段同排时使用`fieldAligned`，可见底板与命中最小48、圆角12、上下内缩0。
- **值与行为**：空查询是否允许由场景明示；搜索中防重复触发，支持的长查询提供取消并保存原输入。
- **辅助设备**：图标按钮命名为搜索图书等具体对象；键盘搜索键触发同一事件。
- **使用边界**：不要把清除图标当搜索按钮，也不要在每个本地筛选框旁增加无效提交按钮。
- **拟定接口**：`query, enabled, loading, cancellable, onSubmit, onCancel`。

#### i07 · 搜索建议与历史 / SearchSuggestions

帮助完成查询，区分建议、历史和直接结果。

- **变体**：分组建议、历史记录、即时结果。

- **辅助设备**：建议列表关联输入，当前项可播报；删除历史有独立名称和命中区。
- **使用边界**：不要把广告或无关内容混为建议，也不要删除历史时同时执行查询。
- **拟定接口**：`query, items, activeId, loading, onChoose, onRemoveHistory, onDismiss`。

#### i08 · 表单分组与校验 / FormGroup

- **使用边界**：不要只在Toast中列出全部错误，也不要每次失败重置整个表单。
- **拟定接口**：`fields, values, errors, dirty, submitting, onValidate, onSubmit, onCancel`。

#### i09 · 验证码与重发 / VerificationCode

提供完整验证码输入、发送、倒计时和重试路径。

- **状态**：未发送、发送中、倒计时、可重发、错误、过期。
- **尺寸**：输入最小48；数字18/26；发送/重发按钮16/22、命中44；倒计时12/18。
- **值与行为**：支持整段粘贴；发送成功后才启动倒计时；错误保留可修正内容，过期后提供重发。
- **辅助设备**：优先一个可访问输入而非六个难导航小格；倒计时不逐秒打断读屏。
- **使用边界**：不要自动无限重发，也不要只靠倒计时颜色说明不可用原因。

- **使用边界**：不要把无匹配当无来源，也不要搜索时清掉原选择。

- **使用边界**：不要把已缓存等静态状态做成可点胶囊，也不要给所有标签都加关闭图标。

- **状态**：首页、中间页、末页、加载中、请求失败。

- **使用边界**：不要把滚动位置当页码，也不要请求中先清空并显示末页。
- **拟定接口**：`page, pageSize, total, loading, onPageChange, onPageSizeChange`。

- **使用边界**：不要用表格排普通表单，也不要隐藏对理解数据必要的列却无详情入口。
- **拟定接口**：`columns, rows, sort, selection, loading, empty, onSort, onSelect, onRowOpen`。

<a id="c05"></a>

#### c05 · 层级树 / Tree

显示可展开的层级结构，节点选择与展开分别明确。

- **变体**：只读层级、可选择、懒加载。
- **状态**：收起、展开、选中、部分选、子级加载、空子级、失败。
- **尺寸**：节点至少44高；缩进每级16；图标18–20；文字16/24；过深路径可横滚或逐级进入。
- **值与行为**：展开只加载子节点；选择是否包含子节点明确；失败保留已展开祖先与当前选择。
- **辅助设备**：树层级、展开和选择状态可读；左右键展开/回父节点，上下键移动。
- **使用边界**：不要只用缩进颜色表示层级，也不要点击展开箭头时顺便提交选择。
- **拟定接口**：`nodes, expandedKeys, selectedKeys, loadingKeys, onExpand, onSelect, onLoadChildren`。

<a id="c06"></a>

#### c06 · 标签与徽标 / TagBadge

表达分类、状态和数量，与筛选按钮区分。

- **变体**：分类标签、状态标签、数量徽标。
- **状态**：中性、成功、警告、失败、数量上限。
- **尺寸**：静态标签视觉20–24、12/18；数量徽标最小18；普通可点击筛选另用FilterChip，命中44。媒体文件标签位于预览图左上角，12/18字、22高半透明深底白字，保留至少44高点击区；浮层只占标签实际内容宽度。
- **值与行为**：徽标只显示真实数量；超过显示上限用99+等并保留完整可访问值；状态配图标或文字。
- **辅助设备**：标签与所属对象一起播报；不单靠颜色区分；装饰徽标不重复朗读。
- **使用边界**：不要让静态状态套用按钮外形，也不要以小红点替代所有重要错误说明。
- **拟定接口**：`label, tone, count, maxCount, icon, accessibilityText`。

<a id="c07"></a>

#### c07 · 头像与身份标识 / Avatar

呈现人物、账号或来源身份，提供稳定的加载回退。

- **变体**：图片、首字母、固定默认图。
- **状态**：加载、已加载、缺失、加载失败、可进入。
- **尺寸**：常用32/40/48；可点外层至少44；首字母16–20、600；尺寸变化不引起行跳动。
- **值与行为**：图片失败回退既定默认资源或字母，不改变身份名称；可进入账号时路径清楚。
- **辅助设备**：替代文字描述身份；邻近已有名称时装饰图不重复播报；可点击时说明去向。
- **使用边界**：不要依赖系统emoji作为固定头像，也不要无说明地以颜色区分账号。
- **拟定接口**：`src, name, size, fallback, interactive, onOpen`。

<a id="c08"></a>

#### c08 · 详情描述与键值 / Description

把元信息和较长说明按可扫描的标签和值组织。

- **变体**：单列键值、多列宽屏、可复制值。
- **状态**：正常、缺失值、长值、可复制、只读。
- **尺寸**：标签12/18或14/20；值16/24；行间12–16；窄屏标签置顶，复制44命中。
- **值与行为**：缺失值说明未提供；日期、容量和状态格式统一；敏感或超长值保留适当查看/复制路径。
- **辅助设备**：标签与值作为关联信息读取；复制按钮名称含字段名；长值可获取完整内容。
- **使用边界**：不要将键值数据排成无语义的两列绝对定位，也不要把缺失值显示成0。
- **拟定接口**：`items, layout, valueFormatters, copyableKeys, onCopy`。

#### f01 · 就近提示 / InlineNotice

在相关内容附近持续解释成功、限制、警告或错误。

- **变体**：信息、成功、警告、错误、可关闭。
- **状态**：显示、展开详情、处理中、可重试、关闭。
- **尺寸**：内边距12–14、圆角10；文字14/22；图标18–20；关闭/动作44命中。
- **值与行为**：长期问题留在相关区域；用户可采取的动作明确；错误消失后再撤销，不用固定超时隐藏。
- **辅助设备**：信息等级配文字和图标；必要错误适度播报；链接或重试可被键盘访问。
- **使用边界**：不要只用Toast承载必须修复的字段或服务错误。
- **拟定接口**：`tone, title, message, action, dismissible, onAction, onDismiss`。

<a id="f02"></a>

#### f02 · 短暂操作反馈 / Toast

反馈复制、保存等短操作结果，不打断当前任务。

- **变体**：成功、中性、短错误。
- **状态**：出现、停留、消失、重复合并。
- **尺寸**：文字14/22；左右16、上下10–12；距底部安全区至少16；不覆盖主操作。
- **值与行为**：普通反馈约2–3秒，读屏场景延长或可再次获取；重复相同消息合并，重要问题转就近提示。
- **辅助设备**：使用非打断式状态播报；消息不抢焦点；不要让消失时间成为完成任务限制。
- **使用边界**：不要放长文本、必需确认或唯一重试入口，也不要连续堆叠遮屏。
- **拟定接口**：`message, tone, duration, dedupeKey, placement, onDismiss`。

<a id="f03"></a>

#### f03 · 确定进度 / Progress

仅在存在可信总量时表达处理比例，保持步骤与取消可达。

- **变体**：线性、环形、步骤加数值。
- **状态**：等待、进行中、暂停、完成、失败、已取消。
- **尺寸**：线性轨道4–6；环形32–40；数值14/20；说明12/18；取消44命中。
- **值与行为**：百分比来源于真实已完成量与总量；总量未知改不定式；100%后仍处理需说明收尾状态。
- **辅助设备**：播报当前进度、总量和任务名；更新适度节流；暂停、取消与重试可独立操作。
- **使用边界**：不要用计时器伪造百分比，也不要进度归零后丢失失败原因。
- **拟定接口**：`value, total, status, label, unit, cancellable, onCancel, onRetry`。

<a id="f04"></a>

#### f04 · 不定式加载 / Spinner

总耗时或总量未知时说明任务正在进行。

- **变体**：行内、内容区、按钮内。
- **状态**：请求中、超时、失败、完成。
- **尺寸**：行内16–20、内容区28–32；说明14/22；按钮中图标20且不改变按钮宽度。
- **值与行为**：短请求避免闪烁；较长请求给当前动作和可取消路径；结束时明确进入结果或错误。
- **辅助设备**：区域标记忙碌并提供加载名称；动画不承担唯一信息；尊重减少动效。
- **使用边界**：不要无限转圈且没有超时或返回，也不要阻塞仍可使用的整页内容。
- **拟定接口**：`loading, label, delay, timeoutState, cancellable, onCancel`。

<a id="f05"></a>

#### f05 · 骨架占位 / Skeleton

首屏结构尚未获取时预留最终布局，减少跳动。

- **变体**：列表行、卡片、图文。
- **状态**：首次加载、部分就绪、转为结果、失败。
- **尺寸**：尺寸与最终行/封面一致；圆角4–8；占位间距沿用最终布局；避免过强闪动。
- **值与行为**：只在首次无内容时使用；已有数据刷新继续显示内容；失败转错误而非永久保留骨架。
- **辅助设备**：占位装饰隐藏于读屏，父区域统一播报加载中；减少动效时停止闪动。
- **使用边界**：不要在每次后台刷新覆盖已读内容，也不要用骨架暗示虚构数据。
- **拟定接口**：`loading, layout, count, reducedMotion, preserveContent`。

<a id="f06"></a>

#### f06 · 空状态 / EmptyState

区分没有内容、无筛选结果和未配置来源，并给下一步。

- **变体**：首次空内容、筛选无结果、来源为空。
- **状态**：真实空、可添加、可清除筛选、只读空。
- **尺寸**：图标32–40；标题18/26；说明14/22；主底板40、命中44；内容间距12–20。
- **值与行为**：只有请求完成且确认无数据才显示；无结果提供修改查询，未配置提供添加来源，不混用。
- **辅助设备**：标题和说明完整可读；提供一个主路径及必要补充路径，焦点不被空白吸走。
- **使用边界**：不要把请求中、网络错误或无权限都显示为暂无内容。
- **拟定接口**：`reason, title, message, primaryAction, secondaryAction, onAction`。

<a id="f07"></a>

#### f07 · 内容区错误 / ErrorState

说明当前无法完成的动作，提供重试或返回并保存上下文。

- **变体**：局部错误、整页错误、离线可恢复。
- **状态**：失败、重试中、恢复、无权限、来源失效。
- **尺寸**：标题18/26、说明14/22；错误详情12/18可折叠；重试按钮可见40、命中44。
- **值与行为**：展示用户可理解原因；重试保留来源、查询和输入；有缓存时提供对应已支持的离线路径。
- **辅助设备**：错误与受影响区域关联；重试和返回名称清楚；详细错误不直接暴露技术堆栈。
- **使用边界**：不要无止境自动重试，也不要重试失败时清空已缓存内容。
- **拟定接口**：`reason, message, retryable, cachedAvailable, onRetry, onBack, onOpenCached`。

<a id="f08"></a>

#### f08 · 流程结果 / Result

在任务完成、失败或取消后展示产物与后续动作。

- **变体**：成功、部分成功、失败、已取消。
- **状态**：有产物、无产物、部分失败、可预览、可重试。
- **尺寸**：标题20/28；摘要14/22；产物用64行；一个主动作40可见、44命中。
- **值与行为**：区分已提交与已完成；产物数量准确，部分失败可定位并重试；返回不重复执行任务。
- **辅助设备**：结果摘要、成功/失败数量和主要下一步可读；初次进入适度播报。
- **使用边界**：不要把已排队画成处理成功，也不要只用绿色对勾替代结果信息。
- **拟定接口**：`status, summary, artifacts, failures, primaryAction, onPreview, onRetry`。

<a id="f09"></a>

#### f09 · 刷新与加载更多 / RefreshLoadMore

维护已有列表的刷新、分页和结束状态，不闪空内容。

- **变体**：下拉刷新、按钮刷新、滚动加载、游标分页。
- **状态**：可刷新、刷新中、加载更多中、末页、部分失败、重试。
- **尺寸**：顶部/底部状态区至少44；文字14/22；加载图标16–20；保留列表行结构。
- **值与行为**：首屏加载与后台刷新分开；刷新失败保留旧内容，分页失败保留已加载页；新查询重置游标。
- **辅助设备**：刷新完成和新增数量适度播报；加载更多有等价按钮路径；末页说明清楚。
- **使用边界**：不要将正在请求显示为无来源或空列表，也不要因刷新回到列表顶部丢失阅读位置。
- **拟定接口**：`refreshing, loadingMore, hasMore, error, cursor, onRefresh, onLoadMore, onRetry`。

- **状态**：打开、草稿已改、键盘出现、提交中、错误、取消。

- **拟定接口**：`open, title, size, draft, dirty, busy, dismissible, onConfirm, onCancel`。

#### o03 · 锚点浮层 / Popover

- **状态**：打开、边缘避让、焦点内、关闭、转底部层。
- **尺寸**：最小宽160，最大不超过视口减32；选项至少44；内边距8–12，圆角12。
- **值与行为**：与触发器定位并避让屏幕边缘；点击外部或返回关闭，带草稿时按取消规则处理。
- **辅助设备**：触发器播报展开状态；可键盘进入和关闭；关闭回触发器，背景交互规则明确。
- **使用边界**：不要让浮层超出屏幕或覆盖触发器全部位置，也不要放长列表而无滚动。
- **拟定接口**：`anchor, open, placement, content, dismissOnOutside, onDismiss, onConfirm`。

#### o04 · 简短辅助说明 / Tooltip

- **状态**：显示、延迟关闭、隐藏。
- **尺寸**：文字12/18或14/20；宽度不超过240；内边距8–10；帮助触发器44命中。
- **值与行为**：聚焦或明确帮助操作显示，离开可关闭；不承载提交、表单或唯一错误信息。
- **辅助设备**：说明与触发器关联；键盘和触摸均有等价入口；出现时不抢焦点。
- **使用边界**：不要把必要标签或关键风险只藏在悬停提示中。
- **拟定接口**：`content, triggerId, open, placement, onOpenChange`。

#### b01 · 文件上传 / Upload

完整表达选择、校验、进度、取消、失败与结果的上传流程。

- **变体**：单文件、多文件、图片预览。
- **状态**：待选、校验中、排队、上传中、完成、失败、取消中、已取消。
- **尺寸**：选择按钮可见36/命中44；文件行至少64；进度4–6；缩略图48，移除44命中。
- **值与行为**：类型/大小/数量限制选择前可见；无效文件就近说明；重试不重复创建记录，取消明确是否保留已完成项。
- **辅助设备**：选择、移除和取消按文件名命名；进度可读；支持系统文件选择与辅助设备操作。
- **使用边界**：不要自动提交整个业务任务，也不要上传失败后悄悄删除用户本地文件。
- **拟定接口**：`files, accept, maxSize, maxCount, status, progress, onChoose, onUpload, onCancel, onRetry`。

#### b02 · 来源与文件选择 / FilePicker

在已支持来源中选择文件或目录，显示来源、路径和当前选择。

- **变体**：单文件、多文件、目录、来源切换。
- **状态**：无来源、来源加载、目录加载、空目录、已选择、无权限、失败。
- **尺寸**：来源字段48；路径44命中；文件行至少64；选择标记20、命中44；底部确认44。
- **值与行为**：来源列表请求中不显示无来源；切换来源保留或清空选择的规则明确；确认后返回稳定文件标识。
- **辅助设备**：来源、路径、文件名和选择状态可读；目录进入和文件选择职责分离。
- **使用边界**：不要在只读浏览页新增上传、新建等写能力，也不要把来源失效等同空目录。
- **拟定接口**：`sources, sourceId, path, selectedIds, multiple, mode, onNavigate, onSelect, onConfirm`。

#### b03 · 文件与目录行 / FileRow

以类型、名称、大小、状态和必要操作呈现文件。

- **变体**：目录、文件、缩略图、可多选。
- **状态**：正常、选中、下载中、不可访问、失效、操作中。
- **尺寸**：最小64；图标40或缩略图48；名称16/24、最多两行；元信息12/18；尾部操作44。
- **值与行为**：目录整行进入，文件按已支持行为打开；更多动作不触发行打开；类型未知仍可查看信息。
- **辅助设备**：名称包含文件/目录区别与选择状态；更多按钮说明作用对象；完整长文件名可获取。
- **使用边界**：不要只用扩展名或颜色表达文件类型，也不要在窄屏截掉所有可区分名称。
- **拟定接口**：`file, kind, selected, progress, actions, onOpen, onSelect, onAction`。

#### b04 · 媒体播放控制 / MediaControls

将播放、时间、拖动和扩展操作组织成稳定控制区。

- **变体**：音频常驻、视频沉浸、紧凑迷你播放器。
- **状态**：准备中、播放、暂停、缓冲、结束、失败、续播。
- **尺寸**：核心控制至少44命中；播放主图标24；时间12/18；进度交互行44；覆盖层文字对比独立验证。
- **值与行为**：拖动预览与实际seek分开；缓冲不误报暂停；隐藏控制前保留唤出路径，失败可重试不丢播放位置。
- **辅助设备**：播放/暂停名称随状态更新；当前时长和总时长可读；键盘与辅助设备可跳转时间。
- **使用边界**：不要只靠手势提供音量或进度调整，也不要让控制栏遮住字幕和系统安全区。
- **拟定接口**：`playing, buffering, position, duration, seekable, onPlayPause, onSeek, onRetry`。

#### b05 · 书架图书行 / BookRow

封面、续读信息、缓存与阅读进度组合，入口语义稳定。

- **变体**：书架续读、搜索结果、缓存中。
- **状态**：默认、已缓存、缓存中、缓存失败、有进度、已读完。
- **尺寸**：封面56×84；书名16/24、600；作者/章节12/18；缓存12/18；行内间距12–14。
- **值与行为**：封面进入详情，文字区域继续阅读；缓存状态真实可读；阅读进度与下载进度区分，不显示重复详情按钮。
- **辅助设备**：封面详情与正文续读分别命名；书名、章节、阅读进度、缓存状态按合理顺序播报。
- **使用边界**：不要让整个行与封面点击冲突，也不要把已缓存做成无法理解的操作按钮。
- **拟定接口**：`book, readingProgress, cacheStatus, cacheProgress, onOpenDetail, onContinue, onManage`。

#### b06 · 阅读参数面板 / ReaderSettings

组合字体、字号、间距、页边距和主题，实时预览且可恢复。

- **变体**：即时设置、带预览确认、恢复默认。
- **状态**：默认、已修改、预览、自定义色、不可用选项。
- **尺寸**：标题18/26；设置行64；滑杆/步进44命中；字体选择48；正文预览左右边距相等。
- **值与行为**：默认使用打包字体；用户主动选择阅读专用字体独立保存；取消草稿恢复原值，恢复默认说明影响范围。
- **辅助设备**：设置名称包含单位；滑杆有精确输入路径；主题选择有名称而非仅色块。
- **使用边界**：不要用固定高度裁切大字号预览，也不要美化时覆盖读者既有页边距与阅读偏好。
- **拟定接口**：`fontFamily, fontSize, lineHeight, paragraphSpacing, margin, theme, onPreview, onSave, onReset`。

#### b07 · 会话输入与附件 / ChatComposer

组织消息、附件、发送和生成中停止，保持编辑过程稳定。

- **变体**：文本、带附件、生成中。
- **状态**：空值、输入、附件上传、可发送、发送中、生成中、失败。
- **尺寸**：下载会话空白/单行输入48高，长多行可增至128并在框内滚动；16/24。附件、发送、停止及系统粘贴可见底板与命中48、圆角12；多行时保持动作48高并底部对齐，不拉成128高。预览文件行minHeight64。
- **窄窗口**：输入组件实际宽度不足360vp时，附件与输入框同排，粘贴与发送另起一排靠右。保留同一编辑器与草稿，不依赖设备型号或整屏宽度判断；系统粘贴授权行为保持一致。
- **字体与组合**：输入值和placeholder都显式指定本地Noto Sans SC；输入行按钮启用`fieldAligned`，上下内缩0。保留系统PasteButton的授权语义，不替换为普通粘贴按钮。
- **值与行为**：中文输入法合成不发送；换行与发送快捷键按场景固定；失败保留草稿，停止生成不误清历史。
- **辅助设备**：输入有名称；发送、停止名称随状态变化；附件状态和移除可读，消息更新不反复抢焦点。
- **使用边界**：不要每次回复自动清空未发送草稿，也不要上传附件后未经明确发送就提交消息。
- **拟定接口**：`draft, attachments, sending, generating, canSend, onChange, onAttach, onSend, onStop`。

#### b08 · 异步任务行 / TaskRow

显示真实任务阶段、进度、产物和可执行的恢复动作。

- **变体**：排队、处理中、有产物、失败恢复。
- **状态**：排队、处理中、取消中、已取消、成功、部分成功、失败。
- **尺寸**：任务行最小80；标题16/24；阶段/时间12/18；进度4–6；取消/重试/查看44命中。
- **值与行为**：阶段来自实际任务状态；已提交不等于已完成；取消中不得显示为已取消，重试范围与产物对应。
- **辅助设备**：名称、阶段、百分比和主要动作可读；更新适度播报，列表刷新不跳焦点。
- **使用边界**：不要持续转圈而无阶段说明，也不要把重试做成重复创建多个相同任务。
- **拟定接口**：`task, status, phase, progress, artifacts, cancellable, onCancel, onRetry, onOpenResult`。

#### b09 · 文件预览 / FilePreview

在可支持的格式中展示内容，区分加载、预览失败和不支持。

- **变体**：图片、PDF、文本、不支持格式。
- **状态**：加载中、可预览、预览失败、不支持、无权限、文件失效。
- **尺寸**：页头操作44命中；内容使用可用视口；PDF页码14/20；文本16/26；缩放控制44。
- **值与行为**：加载失败提供重试；不支持格式给已支持的外部打开/下载路径；返回保留列表位置与当前文件。
- **辅助设备**：图片替代信息、PDF页码和文本内容可获取；缩放有按钮路径，不仅依赖捏合手势。
- **使用边界**：不要把不支持格式显示成文件损坏，也不要为预览执行未授权的文件写操作。
- **拟定接口**：`file, format, loading, error, page, zoom, canOpenExternal, onRetry, onOpenExternal, onClose`。
