# 字帖工作流改造：可执行验收方案

编写日期：2026-10-03。配套 [修改主方案](modification-plan.md)、[输入、状态和排版契约](data-and-layout-contracts.md)。本文验收本轮字帖与英语字帖改造，不能代替站点既有 PDF 工具、教材完整性和后端隔离验收。

**本文是待执行计划。W01—W44 共 44 个主用例的初始状态全部为 `not_run`，本轮编写文档没有执行产品测试。** 历史报告、旧截图、函数已存在或构建通过，均不能直接作为新流程验收通过的依据。

## 1. 验收前提与最新需求

以用户最新修正为准：先选择或输入内容，完成后由用户统一决定生成“拼音字帖”还是“汉字字帖”。识字表、写字表、词语表只承担教材内容筛选职责，**不得据此自动决定题型，不按来源分配不同题型，不生成混合题型卷**。

统一流程为“数据输入 → 数据处理 → 生成预览并允许调整 → 打印或 PDF”。教材、自定义文本和图片识别均落入同一个可编辑文本框 `WorksheetInputDocument.rawText`，来源引用单独保留于 sidecar；导入时明确选择追加或替换。第二步对整个草稿选择一个全局 `mode`。英语使用相同流程，统一选择“看中文写英文”或“看英文写中文”。

### 1.1 结果状态和证据

| 状态 | 使用条件 |
| --- | --- |
| `not_run` | 尚未执行，或只有历史结果。 |
| `pass` | 本用例全部子场景符合可判定标准，证据可独立复核。 |
| `fail` | 观察到与标准不符；保存失败证据和修复后复测记录。 |
| `blocked` | 缺教材、字体、实机、打印机等必需条件；注明原因、责任人和解除条件。 |

每条结果记录提交标识、构建版本、浏览器/系统/设备、执行时间、夹具及其 SHA-256、步骤实际值、断言结果、证据路径、执行人和状态。一个主用例任一必测子场景失败或阻塞，主用例不得标记 `pass`。打印机缺失不能以“另存为 PDF”替代实体打印。

证据只用原创夹具或已取得使用权限的教材样本。HAR、控制台、草稿和截图不得收集真实学生姓名、私人图片或凭据；需要展示来源时使用测试会话和公开来源标识。

### 1.2 执行环境与固定尺寸

- 自动检查在本地或独立测试站运行；E2E 必须显式配置本地 `E2E_TARGET`。现有运行脚本缺省指向公网，不得省略目标造成统计污染。
- 桌面真实浏览器覆盖 Chrome、Edge、Safari；移动实机覆盖 iPhone Safari、Android Chrome。模拟视口只能证明布局，不能替代相册选图、软键盘、设备下载和系统打印。
- 布局宽度为 320、360、390、430、768、1280、1440 CSS px，另测手机横屏及桌面 200% 缩放。
- A4 纵向，四边默认 15 mm，内容宽度 180 mm。默认米字格 12 mm，可选 10/14 mm；题号宽为 `max(3 mm, 实测文字宽 + 0.8 mm)`，题项间距 **2.5 mm**、行间距 3 mm。四线三格每格 3 mm，总高 9 mm；中文拼音书写区每个音节最小 16 mm；字体不得为压缩布局自动小于 9 pt。
- PDF 几何换算 `pt = mm × 72 / 25.4`，坐标及预设尺寸误差不得超过 0.5 pt。屏幕截图不作为毫米测量工具。
- 实体打印使用 A4、100%/实际大小，关闭适合页面和浏览器页眉页脚。格线/四线间距允许误差 ±0.5 mm，页面边界允许误差 ±1 mm。
- OCR 首期只接受 PNG/JPEG/WebP；单张最多 10 MiB、合计最多 30 MiB、最多 5 张；原图像素最多 24 MP、最长边最多 8192 px。识别工作图缩小至不超过 6 MP 且最长边不超过 4096 px，原图保留以便重选区域。模型/资产加载超时 60 秒，实际识别另计 120 秒，允许取消。
- 原文最多 64 KiB UTF-8，一次解析最多 2000 token；处理步选入题单最多 200 项，重复 1—5 次且展开最多 500 题。解析候选超过 200 不等于必须删原文，用户应能选择所需数量。

| F09 草稿迁移组 | 当前 v1 真实结构的去敏夹具：含全局 mode、手工读音/释义、版本引用和来源不明条目；另有缺字段、损坏 JSON、不支持版本、配额失败条件。 |
| F10 并发与观测组 | 可控 OCR/渲染异步桩、取消令牌、fake timer、晚到结果、worker 失败、字体失败和缺字样本。自动桩只用于状态机验证，不能代替 F06 的真实 OCR。 |

### 4.1 OCR 正确率计算

固定清晰基准图的 ground truth 由人工对照图片建立。严格采用 [契约 4.3](data-and-layout-contracts.md#43-静态资源与测试) 的口径：中文对原始识别结果与参考文本先做 NFC，只去 Unicode 空白、不去标点或数字，以码点序列编辑距离计算 `CER`；英语先做 NFC，连续空白统一，保留大小写和标点，以空白分隔 token 序列编辑距离计算 `WER`。

指标只使用未经人工修正的 `rawRecognizedText`。清晰中文集合要求 `CER = Σ字符编辑距离 / Σ参考码点数 ≤ 0.05`；清晰英文集合要求 `WER = Σ词编辑距离 / Σ参考词数 ≤ 0.05`。不平均逐图比率，不混合中英指标；无文字图单独验空结果，不进入零分母计算。不得删掉错字或难样本提高分数。

低质量/歪斜图不强设同样识别率，验收其校对和恢复路径。OCR 原始结果与校对后 rawText 都保存，后者必须与确认文本逐码点一致。此为新实现的验收目标，不是本轮实测成绩。
