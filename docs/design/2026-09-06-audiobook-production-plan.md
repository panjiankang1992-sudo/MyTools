### 0.1 腾讯云通用 TTS 方案（2026-09-07，当前首选）

因豆包方案要求较高的预充值，首期主 Provider 调整为**腾讯云基础语音合成 `TextToVoice`**。这不是腾讯的长文本异步接口：后者不适用本次免费资源路径。MyTools 继续以“章节 → 安全短段 → MP3 片段 → ffmpeg 无重编码拼接 → 章节资产缓存”的路径生成，因此保留了增量章节复用、失败重试和 App 自动下一章播放，不需要实时合成。

- `reader_synthesize_audiobook` 已实现 `TENCENT` 执行器：使用 TC3-HMAC-SHA256、固定 `tts.tencentcloudapi.com` 主机、数值型已审核 `voiceType`、MP3 回执校验，以及每段最多 450 UTF-8 字节的保守边界（最多 150 个中文或全角字符）。密钥只存在 Executor 包级受限环境，不进入 App、任务参数、数据库或日志。
- `reader_match_audiobook_voices` 以 `apiVersions:["tencent-v1"]` 冻结腾讯音色目录，并且只让 `AUDIOBOOK_TTS_DEFAULT_PROVIDER=TENCENT` 指定的目录项参与自动匹配，禁止在一本书中混用供应商音色与鉴权契约。
- 首期仅从腾讯控制台人工试听并审核 4–6 个基础/精品音色，目录先将 `ssmlSupported` 设为 `false`；完成特定音色的读音 SSML POC 后才可开启读音词典重生成。多角色开关仍须满足既有黄金集、NER 与人工复核质量门禁。
- 不在仓库或发布包中保留会产生供应商费用的语音 POC。供应商侧试读仅能在费用审批、内容处理授权和额度可用后，通过正式受限任务链路执行；本地回归覆盖请求签名、响应校验、分段边界和失败契约。

部署时必须由操作者在受限主机完成以下最小配置，保持 `AUDIOBOOK_GENERATION_ENABLED=false` 直到 POC、音色试听、费用控制和一章端到端验收均通过：

```dotenv
AUDIOBOOK_TTS_DEFAULT_PROVIDER=TENCENT
AUDIOBOOK_TTS_SUPPORTED_PROVIDERS=TENCENT
TENCENT_TTS_SECRET_ID=<least-privilege-subaccount-secret-id>
TENCENT_TTS_SECRET_KEY=<least-privilege-subaccount-secret-key>
TENCENT_TTS_VOICE_TYPE=<approved-narrator-numeric-voice-id>
TENCENT_TTS_SAMPLE_RATE=16000
TENCENT_TTS_TIMEOUT_SECONDS=90
TENCENT_TTS_MAX_RETRIES=3
```

密钥不得粘贴到聊天、代码库、样例文件或部署日志。`AUDIOBOOK_TTS_SUPPORTED_PROVIDERS` 必须只包含默认 Provider；预检会拒绝混合目录、非数值腾讯音色 ID、缺失密钥或未审核的供应商契约。免费额度耗尽后的后付费开关与每用户/每日字符预算属于上线审批项，未经明确成本上限确认不得开启后付费。

### 0.2 火山引擎兼容路径上线前置条件

1. 在火山引擎开通对应的在线语音合成资源。新部署选择 V3 时，取得豆包语音控制台创建的 `API Key`、`Resource ID`、音色和 V3 HTTPS 接口地址；旧 V1 兼容资源才使用 `App ID`、访问令牌和集群。云账号 AK/SK 只在供应商明确要求签名鉴权的接口中使用，不能代替 V1 服务令牌或 V3 API Key。
2. 在部署主机的 `services.env` 中设置 `VOLCENGINE_TTS_*`，文件必须为 `0600` 且仅 Executor 服务账户可读；不得放进 Git、调度参数、数据库、日志或 App。
3. 在 Executor 主机安装并验收 `ffmpeg` 与 `ffprobe`；任务会在缺少二者或音频时长无效时失败，而不会发布不完整章节。
4. 用一章无敏感样书进行端到端 POC，核验供应商接口版本、请求上限、音色 ID、生成结果、成本、失败码和限流重试策略。新部署默认使用 V3 HTTP Chunked（`/api/v3/tts/unidirectional`）：每个分段使用 V3 API Key、Resource ID 和请求 ID，执行器逐个解析跨网络分片的 JSON 音频事件，并且只在完成码后发布 MP3。V1 HTTP 非流式（`/api/v1/tts`，每段最多 900 UTF-8 字节）仅为已上线旧资源兼容保留。两套配置和端点禁止混用；V3 读音 SSML 尚未经过供应商 POC，不得将目录 `ssmlSupported` 设为 `true`。生产正文在该 POC 验收前不得发送给供应商。
5. 不提供独立的供应商 POC 工具。文本处理权、外部调用授权、额度和单章验收均确认后，部署操作者才可启用正式受限任务链路；在此之前保持 `AUDIOBOOK_GENERATION_ENABLED=false`。验收证据仅保存无敏感摘要，绝不包含凭证、试读正文、文件路径、音频内容或供应商响应；运行时配置和样书路径必须由操作者在受限主机上自行指定，不能提交到代码库。

## 1. 总排期与里程碑

## 2. M0：技术验证与契约冻结

### M0-01：样书与评测基线

- 选取 10 本有处理权的样书，并完成章节、人物、关系、引语和读音标注的最小黄金集。
- 覆盖 EPUB、TXT、文字 PDF、现代小说、古风、多角色对话、英文夹杂、长章节。
- 输出：`audiobook-eval` 数据集、脱敏标注规范、评分脚本。
- 验收：每类目标至少有 100 个有效标注；同一标注流程由两人抽样复核。

### M0-02：TTS Provider POC

- 比较豆包精品长文本/大模型 TTS 与 MiniMax Async Long TTS。
- 同时测试“整章长文本任务”和“按角色分段拼接”两条路径。
- 记录：音质 MOS、中文人名读音、情绪自然度、章节时长、失败率、限流、最长耗时、时间戳、每万字成本与重试行为。
- 输出：Provider 基准报告和 `TtsProviderCapabilities` 配置。
- 验收：选择一个主 Provider 和一个备 Provider；主 Provider 满足受控样书全章生成、可查询任务状态、可下载结果。

### M0-03：LLM 与结构化输出 POC

- 比较 NER + LLM 与纯 LLM，在人物候选、别名、关系、显式引语归因上的表现。
- 定义 JSON Schema、证据定位格式、最大窗口大小、重试和纠错策略。
- 输出：Prompt 模板、Schema、服务端校验器、误差分析。
- 验收：所有模型输出均通过 Schema/证据范围检查；主要人物召回率达到 85% 以上才进入 M2。

### M0-04：音频与格式 POC

- 选择统一章节格式（优先 AAC 或 MP3）、采样率、码率、响度目标和封装格式。
- 验证 HarmonyOS App 能稳定播放章节资产并支持连续列表播放。
- 输出：音频规范、ffmpeg 命令封装、真机报告。
- 验收：10 个连续章节无解码失败，章节切换无明显音量跳变。

| ID | 任务 | 验收 |
|---|---|---|
| B2-01 | 中文 NER、称谓、引号和说话动词候选器 | 候选人名召回率 ≥ 90% |
| B2-02 | 分章事实抽取任务 | JSON Schema、证据位置和重试全部可审计 |
| B2-03 | 分卷状态卡与全书归并 | 别名合并有证据，不确定角色不强制合并 |
| B2-04 | 人物、别名、关系、SpeechSegment 持久化 | 章节和全书查询性能达标 |
| B2-05 | 引语说话人归因 | 显式引语准确率 ≥ 90%，全量 ≥ 80% |
| B2-06 | 评测脚本与回归门禁 | 指标每次模型/Prompt 变更可复现 |

**M2 退出条件：**一本完整样书可生成可追溯人物档案和关系图；所有关系、别名和归因均能定位到原文证据。

当前实现中的 `reader_analyze_audiobook_book` 使用受部署配置保护的兼容 Chat Completions 端点。端点必须为无内嵌凭据的 HTTPS 地址，响应体限制为 8 MiB；仅网络错误和 408/429/500/502/503/504 进行指数退避的有限重试。每段模型结果只可引用被冻结章节的 Unicode 码点范围；服务端不接受未知角色、无效证据、重叠片段或与已保存结果不一致的重试。该任务不把完整正文放进 Scheduler 参数、业务数据库、App 响应或任务结果；唯一例外是低置信度归因审核所需、由冻结正文计算的 320 Unicode 码点以内受限摘录，且不会写入调度结果或日志。分析端点、模型名和密钥尚未配置时任务必须失败，而不是降级为虚构人物或虚构音色。

## 5. M3：音色匹配与多角色合成

| ID | 任务 | 验收 |
|---|---|---|
| B3-01 | 音色库同步与元数据管理 | 音色语言、年龄、风格、样本、能力可查询 |
| B3-02 | 规则过滤与 Top-K 评分 | 不符合语言或锁定条件的音色不会入选 |
| B3-03 | LLM 精排与理由生成 | 只在候选集内排序，理由可解释 |
| B3-04 | 人物音色绑定与锁定 | 锁定人物全书音色一致率 100% |
| B3-05 | 对话分段合成与章节拼接 | 角色变化顺序、响度与时间映射正确 |
| B3-06 | 读音词典和 SSML 模板 | 人名/地名修正仅重跑受影响章节 |

**质量门槛：**自动多角色默认开启前，错误角色音色率必须低于 3%。否则上线“旁白 + 手动角色音色指定”模式。

当前音色目录只从 Executor 进程的 `AUDIOBOOK_VOICE_CATALOG_JSON` 读取，目录中必须显式声明 Provider、音色 ID、语言、声音呈现类型、风格、是否可旁白，以及 `ssmlSupported`。后者只能在针对具体非实时端点和音色完成验证后置为 `true`；缺失或 `false` 时读音修订明确拒绝。它不是密钥，仍必须作为部署配置维护；正文、分析模型密钥和 TTS 令牌均不会进入目录或匹配结果。任务只会从该目录选择，不能把模型生成的任意音色 ID 直接交给 TTS。`AUDIOBOOK_TTS_SUPPORTED_PROVIDERS` 是当前 Executor 已实现的 Provider 白名单；匹配任务在冻结计划前逐项校验音色目录，当前仅允许 `VOLCENGINE`。`AUDIOBOOK_VOICE_MINIMUM_CHARACTER_CONFIDENCE` 控制低置信度角色、`AUDIOBOOK_VOICE_MINIMUM_SPEAKER_CONFIDENCE` 控制低置信度角色说话人片段的旁白回退，默认均为 `0.80`。多角色音色要求同时开启 `AUDIOBOOK_MULTI_CHARACTER_ENABLED` 和独立验收凭据 `AUDIOBOOK_MULTI_CHARACTER_QUALITY_GATE_APPROVED`；后者只能在拥有处理权的黄金集、NER 和人工跨章节复核均通过后设为 `true`。合成时旁白和角色的冻结 Provider 仍会逐段复核，形成双层保护；接入第二家供应商前必须新增其独立适配器、POC 和契约测试。

若需要试听，每条目录项可选配 `preview` 对象：`storageUri`、`contentSha256`、`sizeBytes`、`format`（`mp3`、`aac`、`ogg` 或 `wav`）和 `durationMs` 必须同时存在，且样音必须是已验收、受管存储中的固定短语。该内部 URI 不会出现在目录响应或 App；目录仅返回 `previewAvailable`，播放由所有者、生成版本和音色三元绑定的短期票据代理。

## 9. 首个开发迭代（10 个工作日）

## 10. 验收清单

- [ ] 同一书籍重复点击不会重复创建或计费。
- [x] 取消和失败不会删除已验证的章节资产；恢复只重调度最后一个终态阶段。
- [ ] 文本、人物、音色或读音变更只使受影响章节失效。
- [ ] 任意 App 客户端无法越权查询、播放或下载其他用户的生成结果。
- [ ] 任务参数和日志不含正文、密钥、Cookie 或私有文件路径。
- [ ] 所有可播放资产已通过解码、摘要和格式校验。
- [ ] 章节结束后自动进入下一 READY 章节；生成中、失败和末章状态可区分并可恢复。
- [ ] 新增章节仅创建增量 generation；不重复生成正文摘要未变化的章节。
- [ ] 正文、角色音色和读音词典变更只使依赖章节失效，历史可播放版本不被原地覆盖。
- [ ] 人物、关系、音色结果均能追溯到模型版本、规则版本和原文证据。
- [ ] 没有配置云端 TTS 时，原有设备朗读功能不受影响。
