# MyTools PDF 工具：端内优先重设计方案

日期：2026-09-28。状态：设计评审稿，不代表功能已实现或能力已通过真机验证。本次范围仅 PDF 工具；不继续重做解压工具，不改其他工具、不部署后端。三张概念图是设计示意，示例 PDF 内容、大小和缩略图均非用户原文件。

## 一、结论与当前问题

基础操作默认在 APP 内闭环：授权导入 → 本机解析 → 可视化编辑 → 本机生成 → 结果浏览 → 用户决定保存/分享。无需登录、联网或后端 capabilities 成功才能打开这些功能。服务端保留为其他 Agent 的 MCP 执行环境和经证明必要的补充处理环境。

### 实际代码核对

- `PdfToolsPage.load()` 依赖远程 capabilities 决定可用操作。
- `pick()` 选中文件后直接调用 `PdfToolsApi.upload()`，随后等待服务端解析。
- 输入缩略图、操作预览和生成任务调用远程 inputs/plans/jobs；结果需下载才能交给本机 PdfView。
- 当前工具覆盖八项：图片、文本、Markdown 生成 PDF；PDF 转图片、提取文字；页面切分、按页拆文件、合并。不能因为后端已经实现，就继续把这些基础操作默认放到服务器。

### 本轮界面审查

仅采集并检查了当前模拟器的 PDF 主页，未上传用户文件或运行生产处理任务。下面的流程问题来自代码审查，不伪称为本轮完整 UI 走查。

1. 工具入口 → PDF 主页：可达，三列布局已实现；但过大的卡片、分组间距、搜索和副标题挤占首屏。仅八项固定能力也占据大部分屏幕。字符“▧”“T”“┆”“⑵”难以解释动作，且视觉不统一。
2. 文件导入 → 处理预览：代码显示必须上传和轮询，断网时无法完成本可本机执行的动作。应改为本地导入状态，不再把“上传进度”作为默认过程。
3. 操作理解：现有“页面裁切”实际包含将一页切成多页，和“拆分文件”容易混淆。需明确区分页面对半切、裁掉白边、按页拆文件。
4. 结果：当前结果表达偏任务产物和过期时间；本机结果应表现为可立即阅读、继续编辑和保存的文件，不显示云端过期时间。

截图证据：[当前主页](01-current-home.jpeg)。截图不能证明读屏、焦点顺序、动态字体或所有屏幕尺寸可用，需实施时实测。

## 二、端内能力评估及职责

依据当前安装 SDK `@hms.officeservice.pdfservice.d.ts` 和项目已引入的 `@kit.PDFKit`。下表“接口已找到”不等于组合算法、内容保真、性能、线程模型已经验收。

| 能力 | 默认执行位置 | 已发现的本机接口/实现路径 | 必须验证的边界 |
|---|---|---|---|
| 打开、密码解锁、预览、缩略图 | APP | PdfDocument.loadDocument、PdfView、getPagePixelMap/getCustomPagePixelMap | 加密文件、权限、可见页缓存、超大页面 |
| 页面对半切 | APP | 复制源页面两次、getBox/setBox、saveDocument | 旋转、非零原点、MediaBox/CropBox、文字选择、批注坐标 |
| 按页拆文件、提取页 | APP | insertPageFromDocument、deletePage、saveDocument | 范围校验、空文档、书签/链接、表单字段引用 |
| 合并 PDF | APP | insertPageFromDocument | 混合页尺寸、同名表单、加密输入、目录链接 |
| 旋转、排序、删除页 | APP | setRotation、movePage、deletePage | 页索引变化、撤销、最后一页保护 |
| 裁掉白边 | APP | 手动边框与 setBox；自动建议另做本机图像分析 | 不把删除画面外内容当成真正脱敏 |
| 图片生成 PDF | APP | createDocument/insertBlankPage、addImageObject | EXIF 方向、透明图、色彩、纸张、分页、初始空白页 |
| PDF 转图片 | APP | 逐页 PixelMap → ImageKit 编码 | DPI 与内存预算、逐页释放，不一次渲染整份 |
| 提取文字 | APP | getTextContent | 多栏阅读顺序；扫描页无文本要提示，不伪装成 OCR |
| 纯文本生成 PDF | APP | addTextObject + 自己的分页/换行布局 | 中文字体、字形覆盖、嵌入、换行测量 |
| Markdown 基础生成 | 优先 APP | 解析为标题/段落/列表/图片，复用本地排版 | 表格跨页、代码块、长行、离线图片、字体 |
| 复杂 Markdown/HTML、Office 格式转换 | 尚未承诺；需要时评估后端 | 端内布局无法满足时复用服务端排版器 | 不新增没有交付条件的入口；给出具体差异与需上传内容 |
| 扫描件 OCR、复杂表格还原 | 优先评估端内，后端备选 | SDK/模型适配与质量样本评测另立验证项 | 本轮不假定可离线高保真，也不直接承诺后端可解决 |
| 深度压缩/修复特殊坏文件 | 后续能力，先本机评估 | SDK/可移植原生库能力探针 | 质量和大小目标；坏文件不能自动反复上传 |

首期现有八项全部列为端内迁移目标；Markdown 的复杂排版需单独设门槛。旋转、排序、删除页作为同一页面管理器的基础补充。新增 OCR、Office、深度压缩不塞入首期菜单。

后端不能解决手机文件授权不足、用户拒绝权限、错误密码、空间不足等本机问题。这些情况应本机提示、重新授权、清理空间或调整参数。

## 三、架构及迁移

### APP 模块

- `PdfWorkspacePage`：单一工具栏 + 文档画布/页面网格 + 底部操作面板；不再把所有状态堆在一个表单。
- `PdfDocumentStore`：保存导入副本、派生文件、缩略图索引和本地任务。未登录也能处理，账号切换不能把本地私有文件自动上传或混入其他账户的云任务。
- `PdfEditSession`：声明式操作列表、文档 revision、页面身份映射、撤销/重做。参数变化取消陈旧预览，旧任务回调不能覆盖新状态。
- `PdfLocalEngine`：封装 PDF Kit，统一返回进度、错误、能力缺口。文档句柄在同一执行上下文创建/使用/释放，不直接跨 Worker 传递原生对象。Worker/TaskPool 是否支持相关同步 API 必须探针验证；不支持时优先本机 N-API 引擎，不因此直接转后端。
- `PdfOutputStore`：先写临时文件，保存成功后重新打开验证页数与页面尺寸，再发布为正式结果；原文件默认不覆盖。崩溃遗留临时任务启动时标记中断并可清理，不宣称能任意断点续处理。
- `PdfExecutionRouter`：本地能力表独立于网络。默认 local；只有明确 unsupported/质量差异/资源需求且存在已验证远程能力时，展示用户可选的云处理。
- `PdfRemoteAdapter`：复用当前 PdfToolsApi，改为可选而非默认路径。

### 数据与任务

本地模型：Document(id, sourceName, localPath, bytes, pageCount, createdAt)；EditSession(sourceIds, operations, revision)；Task(id, local/remote, operation, status, progress, resultIds, errorCode)。密码仅会话内使用，是否保存独立设计，不把解压密码库默认复用到 PDF。

任务状态：校验 → 本机处理中 → 验证结果 → 完成；另有等待密码、等待授权、取消中、已取消、失败、中断。后台继续执行需有系统允许的任务机制并经过验证；否则明确显示已暂停/中断，不能显示仍在处理。取消需等待底层停止再删临时文件。

### 后端及 MCP

现有服务器与 MCP 保留给远程 Agent 使用：Agent 所在环境无法直接访问手机沙箱，不能声称 MCP 已调用手机处理器。APP 与 MCP 共用操作语义和测试样本，不强求共用进程或 UI。

统一计划字段：operation、sourceRefs（local/remote）、pages、axis、ratio、order、outputName、revision。APP 本地路径、文件 URI、密码不进入远程计划。远程任务继续使用 server inputId，MCP 保持现有鉴权与任务接口兼容。

云处理必须由一次明确操作触发：展示“本机无法完成的具体原因、上传哪些文件、大小、处理能力、保留策略”，用户选择后才上传；不能因超时/未知异常/SDK bug 自动上传。取消或失败清理远程临时文件，日志不记录正文、密码或访问令牌。旧云任务仍可在“云端记录”查看，用户打开/保存时下载为本机文件；不后台自动下载全部历史。

### 迁移顺序

1. 能力探针：两页对半切、跨文档复制保存、文本/图片生成、中文字体、线程执行与渲染。先证明端内方案可行。
2. 本地文件与编辑会话；移除首页对远程 capabilities 的硬依赖。保留远程旧记录独立入口。
3. 对半切、拆分、合并、页面管理与本地预览形成闭环。
4. 图片/文本/Markdown 生成、图片导出、文字提取迁移；逐项记录支持范围。
5. 依据独立证据决定是否需要补充原生库或远程特殊操作。不要为省实现成本提前增加服务端依赖。

若 PDF Kit 缺少所需编辑语义，评估本机 PDFium 等原生库的移植、许可证、包体与字体资源成本。当前只有官方 API 证据，尚未完成 HarmonyOS 移植，不直接写成已可用。

## 四、关键算法：两页变四页

“页面对半切”定义为：对每一张选中源页，在当前视觉方向按比例切成左右或上下两张输出页；默认中线 50%。不等同于按页拆文件，不等同于转图片后重新生成。

1. 读取有效页面边界、旋转、页面尺寸和坐标原点。UI 拖动得到归一化位置，转回 PDF 页面坐标；90°/270°页需矩阵换算。
2. 每张源页复制两次，分别设置裁切范围；校验输出显示边界及页面尺寸，不仅修改预览遮罩。
3. 默认顺序：源1左、源1右、源2左、源2右。另可显式选择先全部左页再全部右页；图示与真实排序必须一致。
4. 全部2页切分输出4页；如果只处理所选页，默认保留未选页原样，则总数为原总页数 + 选中页数。提供“仅输出所选页”时总数为2×选中页数，界面实时说明。
5. 保留文字与矢量是验收目标，失败不可静默降级成整页图片；扫描件本来没有文本层，不能宣称切分后可以搜索。
6. 仅裁切可见范围可能仍保留画面外内容，因此不作为脱敏/永久删除工具。需明确修正文案，避免用户错误理解。

## 五、UI 与完整交互

### 入口

工具页仍挂一个 PDF 入口。PDF 首页保持三列紧凑图标；不放最近使用、大横幅或远程管理卡。主入口“选择文件”，快捷工具按“整理 / 生成与转换”分组。图标使用统一系统 Symbol 或已许可图标库，禁止用字符替代。

第一组：页面对半切、拆分文件、合并 PDF；第二行页面管理、裁掉白边（剩余格留空或不渲染，不能硬填未实现工具）。生成与转换：图片转PDF、文本转PDF、Markdown；转为图片、提取文字。概念图中的旋转和排序可在页面管理中集中，不形成重复导航。

### 编辑工作台

- 顶部单栏：返回、文件名、更多。显示页数，文件大小放详情；不重复“工具 / PDF 工具 / 操作名”三层大标题。
- 中部优先给画布；双指缩放、页码、缩略图条。页面管理切换多选网格，支持拖动排序并提供可访问的“前移/后移”替代动作。
- 参数按需从底部面板展开；不出现与当前操作无关的控件。底部主按钮固定在安全区上方，键盘出现时仍可达。
- 对半切：垂直/水平、拖动线与百分比输入、页范围、顺序、结果页数。
- 拆文件：按每N页或自定义范围分组；先展示将生成几个文件及各自包含页面，不让用户只面对语法输入框。
- 合并：按文件拖动顺序，允许进入文件选页；输出预览显示最终页码与来源。
- 图片生成：缩略图排序、单页/每图一页、纸张/方向/边距；在确认前预览分页。
- 文本与Markdown：编辑/预览切换、字号/纸张/边距；资源默认本地，远程图片不自动请求。

### 结果及异常

结果先在 APP 内直接打开，显示“4页 · 实际文件大小 · 已保存到本机”。主操作“保存到文件”，次操作“分享”，更多中“继续编辑/重命名/删除”。导出取消不删除本机结果。不存在有效预览就不能显示成功。

分开表达：无权限（重新选择）、需要密码（本机输入）、扫描页无文字（解释并提供已验证OCR入口）、空间不足（释放空间/降低图片DPI）、不支持（具体原因及可选处理途径）、处理失败（保留源文件、可重试）、部分图片导出成功（列明已完成/失败/未开始）。不能统一报“网络异常”。

### 视觉规格

390×844逻辑尺寸设计，360宽适配；页面边距16，间距8/12/16/24。标题22sp，正文15–16sp，辅助文字12–13sp。图标22–24vp、点击热区至少44vp；工具格建议高度80–88vp，避免每格巨大白卡。主背景#F3F6F4、正文#1E2622、次文字#59645E；品牌绿#0DA678用于装饰，白字主按钮改用更深#087F5B并验算对比度。圆角12–16，常规列表用分隔线，少用阴影。

字体放大到200%、深色模式、读屏标签、切分线的非拖动输入方式、选中态不能仅靠颜色均纳入验收。概念图是方向稿，精确尺寸、颜色及文字以本方案和后续可交互稿为准。

## 七、交付门槛

- 断网且未登录：本机导入、缩略图、对半切、按页拆分、合并、基础生成/转换、查看结果、保存全部可完成；抓包确认基础流程零上传、零远程预览请求。
- 原始“两页垂直中线切成四页”逐页验收，文字可选择，坐标/旋转/顺序正确，不覆盖源文件。
- 测试不同页尺寸、旋转0/90/180/270、非零CropBox、空白页、加密PDF、字体缺失、表单/批注/书签。对无法完整保留的内容明确说明，不能以“能打开”代替保真验收。
- 低内存下缩略图逐页生成并释放；性能先采集10/100/500页文档的用时和峰值内存，再定准入上限，不把当前后端100MB限制原样移植成本机标准。
- 本地结果生成后重新打开，页数、尺寸、输出大小与UI一致；取消、后台切换、授权撤销、存储满、崩溃恢复不损坏源文件。
- 基础流程不出现云任务ID、过期时间或上传文案。所有云处理均可见、可拒绝、可取消。
- 真机与模拟器分开记录结论；清理所有合成输入/结果/测试密码，保留截图和验收报告。
