# 工具模块 UI 统一优化

2026-09-28。原生 HarmonyOS APP 已实现并安装模拟器。

## 已实现

| 界面 | 调整 |
| --- | --- |
| 工具首页 | 保留三列小图标，按文件实用工具和影像创作分组，增加短说明，搜索使用原有统一结果集。未恢复此前移除的工具。 |
| 二维码 | 生成与识别分段切换；输入、结果卡片分开；空输入禁用生成；相册与扫描操作区分主次。 |
| 解压 | 去掉重复标题，统一返回按钮，增加步骤说明，文件卡片、密码区、记录及密码库空状态分层展示。 |
| 下载聊天 | 统一导航、系统图标机器人标记、输入框样式、两列附件按钮及首次会话引导。 |
| 视频生成 | 优先展示创作方式，将模型配置折叠；更多不可用模式按需展开，保留服务端能力限制和提交校验。 |
| 文件传输 | 操作从标题栏移入独立工具栏，位置卡片与可横滑存储源；点击文件即进入操作面板；面板可关闭，管理操作分两行；修复空白文件图标，统一按钮主题。 |
| PDF / 图片生成 | 保留上一轮优化后的主体交互，本轮接入分组入口。 |

统一使用已有 AppTheme、原生系统图标、44vp 导航触控区、18–20vp 卡片圆角。没有引入前端依赖，也没有更改后端 API、文件处理算法或数据存储协议。

## 验收

正式 ArkTS 构建与签名成功，构建日志无 WARN / ERROR；修改文件通过 git diff --check，资源名无重复。

模拟器点击验证：

- 首页七个工具入口；搜索二维码及无匹配结果。
- 二维码空输入禁止生成；输入测试文本后实际生成二维码；生成与识别切换；选择图片打开系统图库。
- 解压文件 / 记录切换；选择压缩文件打开系统文件选择器，取消后恢复可操作。
- 视频模型配置展开 / 收起；创作入口切换、作品页打开；不可用模式不允许提交。
- 下载附件栏展开；本地文件按钮打开系统选择器并可取消。
- 文件传输打开，新建文件夹面板与取消；点击文件进入重命名 / 移动 / 下载 / 删除面板，关闭时不修改远端文件。

本轮没有提交图片或视频生成、下载任务，未执行文件增删改，未重跑解压内核、密码匹配或相机实际扫码全流程。模拟器中没有扫码样图，因此图库识别仅验证到选择器；视频服务默认模型暂无可用生成模式，因此未验收生成结果。

真机当前未连接，本轮未安装或声称真机验收。临时输入通过重启清除，未产生后端测试数据。界面截图和操作记录保留在本目录。
