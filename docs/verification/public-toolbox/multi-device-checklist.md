# 多浏览器与实机验收清单

公网地址：**https://toolbox.yuyutian.top**

用途：把需要真实设备、真实打印或人工判断的验收项固化为一组可勾选步骤。执行后请把结果与证据（截图、落盘文件、测量值）回填到本文件，或告知执行代理写入 `docs/verification/public-toolbox/`。

每项状态填写 `pass` / `fail` / `blocked`。没有实际执行的项目保持空白，**不要填写 pass**。

## 0. 准备

- [ ] 使用无痕窗口，确认不会带上任何已登录状态
- [ ] 浏览器控制台保持打开，记录出现 `error` 或 `warn` 的页面与操作

## 2. 系统打印与实纸（需实体打印机）

- [ ] 2.1 字帖页点「打印预览」，确认打开独立窗口且不含站点导航
- [ ] 2.2 在打印对话框中设置 A4、实际大小 / 100%、关闭浏览器页眉页脚
- [ ] 2.3 打印学生卷，用直尺测量：**格距 14 mm（1—2 年级）或 12 mm**、页边距约 15 mm
- [ ] 2.4 检查纸张：无内容被裁切、无多余空页、每道题及其书写区完整在同一页
- [ ] 2.5 检查答案未出现在学生卷上
- [ ] 2.6 英语四线三格实测：**共四条线、三个间隔、每个间隔 3 mm**
- [ ] 2.7 打印后回到页面，确认界面状态正常恢复

## 4. 键盘与辅助技术

- [ ] 4.1 只用 `Tab` 遍历首页、字帖页、PDF 页：焦点顺序合理，焦点可见
- [ ] 4.2 用键盘完成：选择年级、切换练习方式、勾选词条、翻页
- [ ] 4.3 抽屉与弹窗关闭后焦点回到触发它的按钮
- [ ] 4.4 打开趋势图的「查看数据表」，确认图表信息有等价的文字与表格入口
- [ ] 4.5 系统开启「减少动态效果」后，图表动画与过渡减弱
- [ ] 4.6 使用系统缩放/朗读功能检查主要标题与按钮可被正确朗读

## 5. 网络与异常

- [ ] 5.1 断网后打开字帖页：仍可使用示例与自定义内容生成 PDF
- [ ] 5.2 断网时首页：显示「统计暂时不可用」，四个工具入口仍可用
- [ ] 5.3 恢复网络后：统计自动恢复，事件队列不重复计数
- [ ] 5.4 刷新页面：确认字帖自定义内容按提示不保留，或已显式保存本机草稿
