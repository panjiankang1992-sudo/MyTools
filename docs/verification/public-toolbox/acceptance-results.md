## 明确未通过的项目

1. 20 册教材词库（R05、R06）——缺可用来源与人工校对，未发布任何教材正文。
2. 服务端 PDF 执行链与匿名文件隔离（R04、A40—A55）——缺公开 Scheduler 领域守卫、独立 Storage 根与受控删除、专用 Executor 包与沙箱验证。
3. A4 实纸打印与测量（A20—A33）。
4. Edge／Safari 桌面与 iPhone Safari／Android Chrome 实机，以及软键盘遮挡实测（A70—A76）。
5. 生产 HTTPS 发布与域名配置。

以上项目均未使用替代手段标记为通过；[release-verification.json](release-verification.json) 中的人工项同样保持未验证状态。
