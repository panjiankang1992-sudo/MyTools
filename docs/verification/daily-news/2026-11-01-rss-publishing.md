## 协议与公网检查

W3C Feed Validator 对实际公网技术源返回 “This is a valid RSS feed.”，结果保存在 `out/news-rss-publishing-20261101/w3c-validation.html`。本地 XML 回读与特殊字符往返检查通过。真实桌面/手机阅读器的布局差异仍需在使用过程中观察，未将格式校验当成所有阅读器界面验收。

公网检查脚本与结构化结果位于 `out/news-rss-publishing-20261101/`；检查内容包括五个源、条件 GET、图文页面、所有配图、订阅页、OPML 和内部路径拒绝访问。

最终通过公网 HTTPS 完整检查：5 个 Feed 均为 200，5 次携带 ETag 的请求均为 304；40 张 PNG、5 个日报网页和订阅页可访问；OPML 包含 4 个分类。`manifest.json`、`job.json`、`personal.json`、未知 Feed 和非法图片路径均返回 404。完整批量检查从 Ubuntu 经公网域名执行；本机也验证了 Feed 与图片公网响应，技术源另经 W3C 外部服务校验。

说明：验收连接曾遇到本机 Python TLS 间歇断连，随后采用 curl 验证；校验脚本也修正了 HTTP 响应头大小写及 304 无正文处理，不涉及线上发布逻辑变更。
