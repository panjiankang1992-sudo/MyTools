# 第十八批：订阅、内容身份与运行容量预留

状态：实现、本地验证及隔离 MySQL 验证完成。持续目标 ACTIVE。

## 本批行为

- News V9 增加长期保留的订阅、目标配置所有者、每日运行、预览身份四类额度；现有 V1—V8 不修改。
- 地区绑定和日报共用同一内容身份，旧数据通过并集合并回填，未登记身份不能直接插入内容表。
- 每日运行接收时预留后续身份，已接收任务在额度满后仍能完成；定时身份校验运行、所有者和请求参数，不能借用另一用户或伪造运行。
- 调度超额原子回滚，日期不推进；重复请求不重新占用额度；正文到期、取消和停用保留原身份。
- 投递目标捕获一次，运行时投递关闭也冻结空目标集，重试或修改配置不会给旧日报追加收件人。现有 5 目标、100 分片限制在仓储边界再次检查。
- 管理接口只读核对控制账本，默认环境、发布配置范围门禁、V9 JAR 门禁和容量预警同步。

## 验证范围

新增测试覆盖预览/地区共用身份、不同 owner 同键、载荷冲突、解析失败回滚、生成失败保留绑定、额度满时停用/移除目标、调度失败不推进日期、取消不归还身份、额度满后完成已接收任务、定时键归属、目标不追加、跨实例预览争用和定时地区并发重放、外层事务回滚、账本差异、旧数据回填和旧任务升级后继续完成。

使用 MySQL 的测试单独验证 V8→V9 实际旧数据迁移、额度满后发布、并发预览准入和并发定时地区绑定。测试运行在独立临时 MySQL 实例，不使用生产账号或业务库。最终数量与清理证据见 `news-control-capacity-test-summary.json`。

本批不同测试合计 **263 项通过**：News 本地 210 项、部署工具 38 项、隔离 MySQL 15 项。News 本地报告共 229 项，其中跳过的 19 项包括已单独在 MySQL 执行的 15 项，最终仅 4 项可选外网来源测试未运行。Java 21 严格编译与打包通过，无新增编译告警；204 个既有迁移文件摘要保持不变。

真实数据库为 MySQL 8.4.11，迁移范围 News 9 / Messaging 20 / Scheduler 176，完整迁移和旧引擎历史接续仍通过。首次远端准备因公共依赖下载失败而结束，未启动测试；核对临时目录后确认缺少 97 个依赖。同一公开 Maven 端点普通连接约 21 秒，IPv4 约 0.7 秒，临时下载器限定该域名使用 IPv4并逐项验证大小和 SHA-256，最终校验 521 个测试包文件后运行 15 项用例，全部通过。未修改生产网络配置。

本地发布包含 18 个 Java 服务、7 个 Python 服务、153 个任务包及 733 个文件；本批重建 News JAR，其余 Java 复用既有制品。V9/仓储类、固定迁移依赖版本及完整文件门禁通过，两项包内 CLI 帮助检查不改变文件。9 条监控规则通过 YAML 解析，未执行 promtool 或现场加载验证。

## 限制

只覆盖指定控制记录行数与其后续有界子记录，不是整库物理容量保证。额度为全局共享，个人使用优先，多用户公平分配未实现。旧定时内容统一归为 LEGACY 预览身份，回填采用保守占用；不会自动删除旧数据。地区任务、来源登记、地区观测/来源包、Messaging 额度及派生内容授权期限仍未全部完成。没有生产部署、真实消息发送、成功的实际节点定位或七日影子运行证明。
