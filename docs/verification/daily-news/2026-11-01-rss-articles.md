# RSS 独立文章上线验证

日期：2026-11-01。运行包 `news-personal-1.4.0` 已部署，替换 1.3.0 的分类日报 Feed；订阅地址保持不变。目标：每条新闻独立呈现且有详情，并补存最近一周。

覆盖 2026-10-26 至 2026-11-01，共 555 条日报候选记录。复用合格详情，对只有简述的条目执行独立 DSH 技能；46 条材料不足的候选记录暂缓，509 条合格记录按规范主来源 URL 合并为 **506 篇独立文章**。

## 验证证据

- 52 项 Python 测试通过，覆盖独立正文、跨日相同原文身份、详情门槛、缓存恢复、邮件先发送、体积超限不丢历史、业务时区窗口、公开内容边界和幂等。
- 独立模块 Java 21 `mvn compile` 成功；Java 采集器未改变，运行包复用已验证 JAR。
- 新技能通过 `skill-creator` 的 `quick_validate.py` 校验。
- 本机及执行主机核验 1.4.0 的 16 个文件 SHA-256；原 1.3.0 的 14 个文件仍与原清单一致。
- 真实七日数据先在隔离站点生成。506 篇文章全部检查正文、页面存在、引用图片存在、来源与 GUID 唯一性；核对七个日期均有文章。
- 175 个冻结材料、日报、投递相关 JSON 的哈希保持不变。部分回执由邮件通道账户所有，仅借助 sudo 计算哈希，不修改权限或内容。
- 白名单公开内容扫描未发现收件地址、服务器私有路径、邮件任务及模型响应路径。
- 公网五个规范订阅地址均返回 HTTP 200 和 RSS MIME；数量与隔离验收一致。抽查技术、国内独立网页和 PNG 均 HTTP 200，网页包含该条 Feed 的完整正文。
- ETag 条件请求返回 304；OPML 包含四分类；manifest、详情缓存路径、发布锁均返回 404。
- 生产 `personal_daily.py ... publish-only --date 2026-11-01` 返回 `unchanged`，无重新采集或邮件发送。
- Nginx 配置校验通过并 reload；原 timer 保持 enabled/active，新执行路径指向 1.4.0。

`systemd-analyze --user verify` 另报告系统现有 `spice-vdagent.service` 的 Install 配置警告，与新闻 unit 无关；未修改该服务。

## 边界

详情来自已采集证据，材料不足的候选不生成臆测正文。现有逐日 DSH 聚类负责同日事件合并；跨日只按规范主来源 URL 去重，不宣称不同 URL 的所有转载事件都能自动归并。旧阅读器已经下载的分类日报可能仍在本地保留，刷新后的新内容使用独立文章 GUID。
