# 第十五批：运行进程检查与 Ubuntu 来源探测

目标仍为 **ACTIVE**。本批完成可重复的只读运行检查和实际宿主机网络探测，没有部署业务应用、修改生产配置、连接业务数据库或发送消息。

## 工程变更

- 新增 `service/deploy/inspect_news_runtime.py`，使用部署生成器的五个固定 systemd 单元名。读取进程环境而不是猜测多个 EnvironmentFile 的合并结果；只输出固定键名与状态。
- 同时检查 PID、启动时间和非 root 身份。读取中重启、PID 复用、非法/重复环境键或超大输入均失败，不输出部分报告。
- 区分缺少进程、缺少环境键及跨角色环境不一致；识别命令行、JVM 和 Spring 等覆盖入口。始终说明环境快照不等于 Spring 最终绑定。
- 任务包、索引、定位文件只报告候选路径存在性；权限、摘要、定位库新鲜度和真实任务需要后续验证。不会执行环境指定的程序或打印凭据摘要。
- 部署装配自动携带新工具，已有装配测试增加文件检查；运行手册补充命令、退出码和字段边界。

44 项测试通过：新增运行检查 15 项，相关发布与环境工具回归 29 项。覆盖脱敏、缺项、跨角色不一致、进程重启/PID 复用、root 身份、非法/过大环境、外部覆盖入口、定位配置名称，以及与实际 systemd 生成器的单元名称一致性。

开发时首次现场检查暴露了单元名称遗漏 `mytools-` 前缀，已修复并新增生成器交叉校验；该次全未安装结果不作为证据。最终现场结果来自修复后的脚本。

## 真实 Ubuntu 观察

从当前本地 SSH 配置解析目标并验证连接，通过 SSH 直接执行；检查脚本从标准输入运行，没有落地到生产发布目录。只有脱敏 JSON 保存在本地。

| 项目 | 实际结果 | 结论边界 |
| --- | --- | --- |
| News | 单元未安装 | 尚未部署 |
| Gateway、Scheduler、Executor、Messaging | 均运行，均非 root | 不证明使用本次构建 |
| 新闻凭据与节点 | 所需进程环境键未齐备，节点绑定缺项 | 不排除命令行/配置文件另有值 |
| Gateway、Scheduler、Executor | 存在命令行配置覆盖入口 | 最终 Spring 绑定仍待核对 |
| 三个新任务包 | Executor 环境指定的目录中入口不存在 | 另有索引，但不能据此认定包含新闻包 |
| 定位候选配置 | 环境未提供可用 MMDB 文件或 MaxMind Web 必需项；无显式地区代理 | 不读取、输出账号/密钥，也不自行配置 |

宿主机探测以 `mytools` 非 root 身份执行，无隐式代理、无凭据、只访问固定公共 URL，并以外层进程超时限制总时长。出口探测调用当前不可变 `news_resolve_region/1.1.0` 的实际网络和地址校验函数；没有调用其任务执行入口或提交报告。来源探测只验证受限大小响应的结构/数量，不写文章或数据库。

| 公共入口 | 结果 |
| --- | --- |
| GitHub 仓库搜索（1 条） | HTTP 200，1 条元数据 |
| Hacker News topstories | HTTP 200，500 个条目 ID |
| DEV 一周文章列表（1 条） | HTTP 200，1 条元数据 |
| 中新网国际 RSS | HTTP 200，30 个条目 |
| ipify IPv4 | 连接失败；没有返回或记录 IP |
| ipify IPv6 | 网络超时；没有返回或记录 IP |

探测时间和结构化结果见同目录 `news-runtime-inspection-test-summary.json`。未记录新闻正文、标题、原始 IP、私有路径或生产配置内容。
