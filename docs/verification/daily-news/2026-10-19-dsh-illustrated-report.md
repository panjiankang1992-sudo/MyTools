## 实现与检查

- `IllustratedReportCollector` 冻结排名、标题、证据地址及图片；图片从原文取得，限制格式、像素、单图与分类总大小。
- `personal_report.py` 通过标准输入调用 DSH，校验完整排名并绑定原始事件 ID。固定模板生成 HTML 与纯文本备选正文，来源链接不由模型生成。
- `dsh-news.patch.yml` 复用已有登录配置并关闭文件、终端、网络、子代理等报告任务不需要的工具。本机与 Ubuntu 的无头调用均返回 `READY`；本次四分类分析在本机实际执行。
- `news_infographic.py` 使用 Pillow 与中文字体生成要点图解。实际图片和图解均通过 CID 内嵌邮件正文。
- `send_personal_mail.py` 在 Ubuntu 复用活动 MyTools 邮件服务的 SMTP 参数；本地和远端的图片哈希、CID 引用、收件地址及 MIME 校验一致。
- Java 定向测试 12 项通过，Maven 打包成功、日志无编译警告；Python 测试 4 项通过。浏览器检查 HTML 排版，图解检查中文排版，32 个预览图片路径均存在。
