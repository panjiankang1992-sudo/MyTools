# 第二十批：来源与地区登记容量

状态：实现、本地验证及隔离 MySQL 验证完成。持续目标 ACTIVE。

## 行为

News V10 为来源、不可变来源包版本、地区节点、地区任务和独立观测设置有限全局额度，默认 1000 / 10000 / 1000 / 100000 / 10000。新来源与来源包 JSON 最多 32 KiB，新观测最多 8 KiB；现有载荷不改写。

每个接纳的地区任务预留一个报告名额。节点游标、任务、Outbox 和额度在同一事务提交，超额时不留下新空游标。任务报告仅使用自身预留，完成时不反向申请全局容量锁；所有额度满时，已有任务仍可完成和重放。任务、节点与报告身份严格绑定，不能挪用独立观测或提交第二份报告。

新准入超额返回 503 / NEWS_030。同内容来源/来源包/观测重放不重复计费，不改变生效或接收时间；来源启停和任务取消仍可执行。身份不因停用、取消或内容清理而删除，旧日报的地区快照不漂移。

管理 operations 响应增加 `registryCapacity` 只读核对，五组固定指标沿用私有鉴权和三十秒缓存，80% 十分钟容量告警加入现有规则。五项配置默认值、范围检查及 V10/容量仓储类的发布检查同步。

## 升级与限制

迁移前停止旧 News 写入者。V10 保守回填旧身份并关联既有任务报告；旧报告被多个任务占用或存在孤立来源轮询游标时迁移失败，必须调查，不能自动删除或修复历史。V10 后未计费的新写法被约束拒绝，回退需兼容 V10 的应用。

额度为全局准入，未实现多用户公平分配，不承诺整库物理磁盘上限。历史包和观测暂不自动删除，长期额度需按实际增长审查扩容。派生正文授权与保留期限、真实执行节点定位、七日影子运行和真实渠道验收继续在持续目标中推进。
