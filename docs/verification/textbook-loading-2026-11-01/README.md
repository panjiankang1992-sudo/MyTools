# 教材加载失败修复（2026-11-01）

## 原因与证据

- 线上日志：2026-11-01 16:44:13、16:44:16、16:44:26（Asia/Shanghai），四年级上册 `1.0.4/entries` 返回 404。
- 截图说明对应 `1.0.4`；当前线上版本是 `1.0.5`，157 条词条。
- `local-textbook-completion-2026-10-18/public-before.json` 记录目录 `catalog-6`、四年级版本 `1.0.4`；修复前实时目录仍为 `catalog-6`，但四年级已经变为 `1.0.5`。
- 原先直接把 `catalogVersion` 用作 ETag，编号重复使带旧 ETag 的浏览器持续获得 304，沿用旧内容地址。

## 修复

- ETag 改为同一次快照实际响应内容的 SHA-256，涵盖教材元数据和筛选结果；支持弱校验值，移除子串误匹配。
- 前端目录请求使用 `no-store`，绕过历史错误缓存。
- 旧版本不存在或身份不匹配时刷新目录，对更新后的同一教材重试一次；保留年级、册次，拒绝迟到响应覆盖新选择。
- 手动重试保留当前教材。
