## 固定字体

- 三份完整 Noto Sans SC静态字体随包分发：400/500/600分别注册 `MyTools UI`、`MyTools UI Medium`、`MyTools UI Semibold`。首屏构建前调用 `AppFonts.register`，窗口加载后幂等补充注册。
- 逐份核对真实OS/2字重、移除fvar可变轴、30,890个Unicode映射、SOURCE.json哈希及签名HAP内字节一致；许可证也在包内。
- 三份字体合计31,770,524字节，签名HAP约48.91MiB。保留完整中文覆盖，避免只按样稿汉字做子集后让动态书名/文件名回退系统字体。
- UI不跟随手机主题字体；系统字号缩放仍保留。阅读正文显式选择的系统/宋体/等宽偏好继续有效，默认黑体改为随包字体。
- DSH远端网页、RSS Web文章正文继续遵守既有网页字体/CSP边界；系统文件、相册、分享与授权界面由平台绘制。这些边界不承诺与原生UI完全同字形；没有为字体放开Web本地文件权限或放宽CSP。

## 真机补测与修复

- 初版搜索占位文字仍采用系统个性字体；在公共单行、多行和搜索输入显式补充placeholderFont，重新安装后确认字形一致。
- 初版进入书籍详情触发 `AppControls.onPlaceChildren` 访问不存在的第二个布局子节点。主机模拟固定提供两个节点，没有暴露此运行时结构问题。改用单个原生Flex承担按钮组布局，不再对自定义组件子节点做固定索引；单按钮保留原生Row与透明Button测量。修复构建中，详情显示、等宽等高与取消边缘命中已通过；最终安装包再次打开详情成功，当前进程未出现该布局运行时异常。
- 单按钮以官方BuilderParam模式注册布局入口。三套直接相关测试已在真机修复后重跑通过，完整记录见tests.json。
