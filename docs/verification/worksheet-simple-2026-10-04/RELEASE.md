# 字帖简化版发布与验证

日期：2026-10-04（Asia/Shanghai）。站点：[禹宇天的工具箱](https://toolbox.yuyutian.top)。

本轮已发布 `worksheet-simple-20261004-011600`，延续用户先前“请部署并验收”的要求。

## 使用上的变化

- 保留三个页面，按钮名称缩短为“选内容 → 确认内容 → 预览打印”；返回保留原文、题型和设置。
- 来源只有选教材、自己输入、上传图片三个入口，每个输入区有一个主要前进操作。教材只有一个版本时直接显示名称。
- 确认页默认只显示原文、两种字帖样式和生成按钮。首次默认语文“看汉字填拼音”、英语“看英文填中文”，已有选择不会被重置。
- 不需要的拼音/释义校对默认折叠；需要时自动展开。选择汉字字帖自动补缺少的拼音建议，多音字仍需确认。
- 排版、抽题、草稿、分项与导入选项收起；预览优先提供打印、下载，参考答案另行展开。
- 手机来源入口紧凑三列，题型两列，详细表单单列。
- 修复两列导入失败丢失输入、空 OCR 候选无法继续编辑、抽取后被未选中词条误拦截；图片空候选可恢复原始识别文字。
