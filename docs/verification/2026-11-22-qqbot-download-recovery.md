# QQBot 下载故障恢复

2026 年 11 月 22 日北京时间 16:26 至 16:28 的四条 QQ 消息已进入 Messaging 和 Automation，均被识别为 X 单帖下载。

## 已确认原因

- 前两条在解析步骤失败，错误为 `REMOTE_NETWORK_FAILURE` 和 `SSL UNEXPECTED_EOF_WHILE_READING`。同帖的 FxTwitter 公开元数据接口经下载代理失败，直连返回有效媒体清单。
- 一条执行租约过期后，旧报告收到 `409 EXECUTION_LEASE_LOST`。旧 WAL 将其列为人工诊断，导致节点停止领取后续任务。另两条请求因此停留在排队状态。
- 恢复领取后已能解析帖子并创建媒体子任务，但媒体传输经同一代理仍失败。范围读取对照中，代理立即断开 TLS，直连超时。代理日志显示上游节点域名解析失败，多个地区节点连通性测试均失败。

## 已部署修复

- 新增 `download_resolve_x_post/1.0.1`。公开元数据请求显式直连优先，以原 X 代理作为网络重试路线。最多三次、单次最多 20 秒，并在请求前检查共同的 60 秒预算。gallery-dl 达到进程超时后也进入备用解析。保留 TLS 校验、源帖身份、媒体域名和大小限制。持续滴流的整体耗时由外层步骤时限兜底。
- 前向迁移 V186 按旧包版本条件切换两个 X 解析任务定义，重复执行不会再次递增版本。现场已按相同条件热更新，后续 Flyway 执行该迁移时无需重复变更定义。
- 执行器对明确的 `409 EXECUTION_LEASE_LOST` 保存 `FENCED` 报告和 `LEASE_LOST` 执行记录，继续处理其他任务。其他协议错误仍进入人工诊断。旧报告载荷、工作目录与调度器业务终态均保留。
- 执行器补丁在实际线上 Jar 副本中仅替换两个源类及其内部类。逐项比对确认其余类、依赖和资源内容一致。发布索引追加新脚本版本，并逐文件验证已有条目与新版本的大小和 SHA-256。

执行器已重新注册并返回健康 `UP`。三个旧报告已转为 `FENCED`，旧执行保留为 `LEASE_LOST`。现场完整 WAL 备份与配置备份保存在服务器的本次修复审计目录。

## 验证与待完成事项

- 新解析包 23 项测试通过。
- WAL Journal 和 Metrics 25 项测试通过，包含五项针对失租恢复的回归。
- 扩展 Worker 27 项测试中 25 项通过，两项既有真进程测试受本机 Xcode Python 与沙盒进程树权限影响失败。
- 两条初始失败先创建了幂等补跑并关联回原 QQ 运行，同时写入恢复审计事件。原排队任务也重新执行。首次补跑因媒体代理仍不可用而失败，该轮失败记录与回执保留。
- 自动审批拒绝了向额外公共 DNS 服务发送生产节点域名进行比对。后续改用本机 DNS 检查，结果同样无法解析。
- 自动审批曾拒绝使用本机 Clash 保存的订阅凭据访问原订阅服务。用户随后明确授权刷新订阅并同步服务器。
- 按授权检查两个已保存的同服务订阅，转换服务均返回 HTTP 400，脱敏错误为没有有效节点。当前订阅中内嵌的原始源另返回 HTTP 404。用户随后提供有效的新入口，原始源路径有变更。订阅地址、令牌及节点凭据未写入仓库或工具输出。

## 新订阅同步与最终验收

使用用户提供的新入口取得 90 个节点、21 个分组。配置经 SSH 直接从内存同步至服务器，更新代理节点与分组前备份原配置并运行 Mihomo 配置校验。已有节点重新测得 33 至 130 毫秒的探测延迟。原失败媒体的 1 KiB 范围读取经代理返回 HTTP 206，用时约 0.42 秒。

网络恢复后，按稳定恢复标识重新提交四条原 QQ 消息的下载，逐条关联原自动化动作，并写入新的恢复审计事件。重复执行恢复脚本会识别已恢复标识，避免重复提交。

最终验收结果如下。

- 四个自动化运行、四个动作及其最新绑定的四个下载请求均为 `SUCCEEDED`。
- 八个文件均已登记且为 `COMPLETED`，对应八个不同存储对象。通过 Storage Gateway 流式读取全部对象，共 4,178,539 字节，大小和 SHA-256 全部一致，无读取失败。
- 四条最新成功完成事件均已发布，四页发送游标全部完成。QQ Connector 的四个出站 WAL 均为 `DONE`，对正文和路由载荷重新计算的摘要均匹配。
- 执行器健康为 `UP`，原三条失租报告保留为 `FENCED`，后续任务已能正常领取。

## 回退注意事项

旧执行器 Jar 无法识别新增的 `FENCED` 持久状态。回退需要先停节点并核对期间新增执行，结合完整 WAL 备份处理，避免覆盖上线后已产生的报告或重复执行旧任务。原脚本版本保留在发布目录中。
