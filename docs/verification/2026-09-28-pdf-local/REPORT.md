## 本轮点击与功能验收

- 八个工具入口均实际点击并生成结果：文本、Markdown、图片生成、分割、拆分、合并、转图片、提取文本。
- 空内容/未选文件时禁止生成；合并单文件时禁止生成，添加第二个后启用。
- 文件选择取消、追加、移除；合并文件上移/下移及边界禁用状态。
- PDF 阅读器真实显示内容，返回结果；系统另存为成功、取消后保留结果，另存文件能重新导入。
- 重启应用后历史仍在，打开历史标题正确，返回历史列表。
- 分割方向、比例弹层、范围校验、输出顺序、缩放、拖动、重置、上一页/下一页。
- 普通滚动保持比例；从切割线拖动可从 50% 调到 70%；两页文件生成四页。
- 空密码禁用、错误密码提示、正确密码重试成功，加密输入生成四页结果。
- 图片导出后重新导入生成 A5 PDF，独立校验纸张宽度；文本提取输出包含预期正文。
- 10 个 UI 任务共 11 个输出文件已独立校验文件大小、PDF 页数、图片格式及文本内容。详见 ui-file-validation.txt。

### 点击验收发现并修复

1. 历史结果返回误入编辑页，修正为回到来源列表并同步工具标题。
2. 普通画布滚动误改分割比例，改成只有触摸分割线附近才开始拖动。
3. 翻页先清空缩略图导致滚动跳位，改为新图准备好后替换，复测前后页码及按钮位置稳定。
4. 重置仅影响分割参数，补齐纸张、边距、页码、导出格式、DPI、拆分设置的默认恢复。
5. 范围弹层改用草稿，校验成功后提交；文件选择/保存时不再误显示文件处理进度。
6. 限制窄长页面预览高度；不足 1 KB 的文件显示字节数。

## 当前边界

- Markdown 支持基础标题、段落、列表等文本排版，图片、HTML 和表格会明确拒绝；不是完整网页排版引擎。
- 提取文本不包含 OCR，复杂嵌套图形文本尚未完整覆盖。
- 裁切保留原 PDF 文本和矢量，不属于安全涂黑/内容擦除。
- 未完成复杂图片 EXIF 方向、500 页文档性能和中断恢复的全面测试。
