### 一件必须说清楚的事：**几乎所有验证都在 H2 上**

审查 S7 明确要求"**使用隔离 MySQL 验证真实事务，不仅 H2**"。
**我没有做这一步。**

**H2 与 MySQL 的差异在本目标里是实质性的**，至少包括：

- **唯一键冲突的报错形态**（`publishVersion` 依赖唯一键拒绝重复版本号）
- `CONCAT('catalog-', epoch + 1)` 这类表达式
- `INSERT ... ON DUPLICATE KEY UPDATE` 的语义（`saveDraft` 用它）
- 事务隔离级别与行锁行为（发布的事务与回执）

**所以"362 项全绿"这句话的适用范围是 H2，不是 MySQL。**
