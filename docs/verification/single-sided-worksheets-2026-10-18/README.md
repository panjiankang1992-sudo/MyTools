# 单侧字帖与自动备用行验收

2026-10-18 已发布到 https://toolbox.yuyutian.top/ ，发布标识 `single-sided-20261018-180914`。此文记录本轮实现、测试和发布证据。

## 交互规则

| 已输入内容 | 可使用的模板 | 留空区域 |
| --- | --- | --- |
| 语文：只有汉字 | 拼音字帖 | 拼音四线三格 |
| 语文：只有拼音 | 汉字字帖 | 按音节数留米字格 |
| 英语：只有中文 | 英语默写 | 英语四线三格 |
| 英语：只有英文 | 中文释义练习 | 中文释义横线 |

完整配对允许选择该学科的两种模板。可用模板由全部有效行共同决定，自动选中兼容模板；缺少题面的一项不会因去重或随机抽题而被隐藏。不同单侧行没有共同模板时，提示补齐对应一侧。参考答案需要完整配对，不推测缺失答案。

自定义输入的最后一行，只要任意一栏有非空白内容，即展示一行备用。备用行不计入条数、不写入题单，不影响光标和首次补全。仅有空白时不继续增行，2000 行上限保持有效。

保留教材库优先、每行只自动补全一次的既有规则；后续修改或清空不再自动覆盖。首次补全未获得结果时，可用现有一侧生成对应练习。返回选内容或确认内容、保存和恢复草稿均保留单侧内容。

## 实现范围

- `WorksheetPairedEditor.vue`：按任意栏已使用来补备用行；单独拼音只校验音节格式，两栏都有值时才检查字音数量。
- `worksheet-editable-pairs.ts`、输入和草稿模型：增加可选 `chineseText` 语义字段，纯拼音保存显式空汉字，原文及 token 身份保持可追溯。
- `worksheet-processing.ts`、`worksheet-session.ts`：按模板、学生卷和答案卷分别校验，纯拼音按音节拆分、去重和留格；全行校验防止抽题绕过缺项。
- `useWorksheetV2Session.ts`、`WorksheetV2View.vue`：模板交集、禁用原因、自动选择可用模板及答案入口限制。
- `worksheet.ts`：四种单侧练习的真实 PDF 投影和绘制，未知答案不进入学生卷。
