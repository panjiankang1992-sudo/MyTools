# LTX 原生图生视频候选验证

本目录记录隔离实验，产品能力仍关闭；不是已发布模型。

## 固定配置

- 官方 LTX-Video 2B 0.9.8 distilled，BF16 权重；T5 XXL scaled FP8 文本编码器。
- 使用现有 ComfyUI 原生 LTX 节点，不安装第三方自定义节点、不升级生产依赖。
- 原正式样例的三张上传原图、seed 42/932；同一英文提示词，832×480、49 帧、16 fps。
- 图像保持比例，灰色补边；CFG 1、Euler、八步固定 sigma；单阶段采样，不使用空间放大器。
- 保存全部生成帧，不做输出颜色均值校正。不把本实验等同官方默认双阶段流水线。

官方参考：[模型卡](https://huggingface.co/Lightricks/LTX-Video)、[推理配置](https://github.com/Lightricks/LTX-Video/blob/main/configs/ltxv-2b-0.9.8-distilled.yaml)。
权重使用 LTXV Open Weights License 0.X，不能标记为 Apache-2.0；版本与 SHA-256 由下载元数据固定并实际校验，许可随模型留档。

## 执行与恢复

`service/deploy/prepare_ltx_candidate.py` 下载并校验公开权重，不使用 GPU。
`service/deploy/evaluate_ltx_candidate.py` 只读历史上传素材，使用验收窗口和共享 GPU 锁；生产 GPU 任务入队即中止，恢复进入前容量和图片 Comfy。
通过 systemd 执行，`ExecStopPost` 再次检查本实验提示任务、卸载模型并恢复窗口。

本实验只评估候选画质与资源需求，未接入 Scheduler 视频任务，因此不能替代 B06 真实混合负载验收。

## 实测结果

| 轮次 | 条件 | 运行 | AI 逐帧复核 | 采样显存峰值 |
|---|---|---|---|---|
| r2 | 原 832×480 补边、通用提示词 | 6/6，6.20–9.33 秒 | 2/6 有限通过；手部凭空出现、补边被改写、镜头方向漂移 | 11735 MiB |
| r3 | 原图比例 640×640、具体场景与镜头描述 | 6/6，6.21–12.41 秒 | 6/6 开发样例有限通过，未见严重变色或新增人物 | 13783 MiB |

两轮均 `restored=true`，图片 Comfy 与调度容量恢复。资源每五秒采样，可能漏过瞬时峰值；r3 最低可用主机内存约 15432 MiB。
耗时包含轮询、保存帧和编码；不与旧生产任务的全链路耗时直接相除作为正式加速倍数。

已实际查看 12 条视频全部 588 帧的联系图，观察分别记录在各轮 `ai-review.json`。这不是实时播放或官方 VBench 分数。
r3 同时更换比例和提示词，只能证明组合配置改善，不能把改善单独归因于某一项。
该组被用于调参，因此不作为独立测试集；尚未接入 App，也不据此开放任何生产模式。

## 接入边界与后续执行

1. 原生比例采样，输出尺寸应来自模型能力目录；若需要固定横屏，生成后再加边，不把大面积灰边输入模型。
2. 提示词保留用户动作意图，结合图片描述补足主体、场景、镜头信息；不得将本次针对三图的固定描述直接作为通用产品实现。
3. 发布新的不可变 LTX 脚本包及模型/工作流版本，服务和 App 展示独立模型能力；旧 VACE 输出仍可浏览。
4. 用未参与调参的素材覆盖人物、动物、复杂动作及横竖比例，再跑正式稳定性和 Scheduler 真实混合 GPU 负载。
5. B06 长视频混合负载仍未完成；本次直接 Comfy 实验不能替代调度器验收。
