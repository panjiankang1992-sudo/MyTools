# 首帧模式颜色漂移修复后的验收（2026-09-20）

## 问题回顾

按 [human-review-rubric.md](../../../research/2026-09-14-video-generation/human-review-rubric.md) 的锚点复核
[上一轮验收](../p0-reaccept-20260919/README.md) 的成片时发现：**补边是中性灰，但画面内部会漂色**——
冷白底素材的内容区整体变蓝（末帧相对首帧 R−B 变化 −109 ~ −176），暖色/风景素材则是整体变暗
（亮度 Δ −13 ~ −39）。机器预评因此给出 4/6、结论 reject。

## 修复（`video_generate/1.0.2` → `1.0.3`）

1. **控制融合强度 α：0.25 → 0.50**（1.0.2）。依据是 P0 的
   [blend 扫描](../p0-window-20260914T112215Z/blend-sweep.txt)：α=0.25 的帧均亮度偏离源图 −0.037、
   α=0.50 只有 −0.013 且运动量几乎不变，而 0.75 与 repeat 已被判 FROZEN。
   α 同时改为**运维可覆盖**（`VIDEO_FILL_BLEND`），便于以后调参而不必改包。
2. **出片后颜色校正**（1.0.3）。实测 α=0.50 仍不足以解决（seed 932 仍漂 115），说明色偏来自模型先验、
   与种子相关，因此加一步与模型无关的确定性校正：把每帧**内容区**（排除补边）的三通道均值平移对齐首帧，
   只平移不改增益（不动对比度与结构），随后按同一几何把补边盖回中性灰，成片与封面共用这份像素。
   强度由 `VIDEO_COLOR_MATCH` 控制（默认 1.0，置 0 关闭），结果里记录 `colorMatch` 与实际偏移 `colorOffsetLast`。

## 效果：6/6 通过，色偏与亮度漂移同时消失

| 样例 | 色偏（R−B 最大变化）修复前 → 修复后 | 亮度 Δ 修复前 → 修复后 |
|---|---|---|
| 冷白底 seed42 | **109.0 → 0.6** | −5.4 → −0.4 |
| 冷白底 seed932 | **176.4 → 0.2** | +14.4 → +0.1 |
| 暖色 seed42 | 4.8 → 1.4 | −37.6 → +0.7 |

| 风景 seed42 | 25.0 → 1.0 | −23.1 → −0.4 |
| 风景 seed932 | 29.2 → 0.4 | −13.2 → −0.2 |
