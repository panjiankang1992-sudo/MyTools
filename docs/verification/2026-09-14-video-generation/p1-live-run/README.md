## 补边修复的判定（本次运行的主要目的）

P0 的白边方案实测成片左右边缘亮度 **0.94–0.98**（近乎纯白）；

| 帧 | 左边缘均值 | 右边缘均值 | 左灰边列数 | 右灰边列数 |

| 0 | 0.4998 | 0.5032 | 176 | 176 |
| 24 | 0.5288 | 0.5304 | 176 | 177 |
| 48 | 0.4347 | 0.4414 | 0 | 0 |

**结论**：白边缺陷消失，边缘亮度落在中性灰量级。同时量化了代价：
1024×1024 方图放进 832×480 后，**前段左右各有 176 列（各占 21%）灰边**，
到末帧已被生成内容覆盖（灰边列数降为 0，因为首帧模式下只有第 0 帧被保留）。
