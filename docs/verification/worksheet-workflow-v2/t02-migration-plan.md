# T02 迁移方案：把既有字帖/英语字帖页面切到统一输入流程

状态：**未执行**。本文件是执行计划，不是完成记录。

## 1. 为什么需要这份计划

方案 T02 原文要求：

> 新增 `components/worksheet/WorksheetInputStep.vue`、`WorksheetTextEditor.vue`，复用 CurriculumPicker；**改 `useWorksheetDraft` 为持有 InputDocument**，新增教材"导入所选内容"。EntrySelector 变为校对/高级导入组件，导入完成不清空原文。

当前实现**偏离**了这一点：新增了独立页 `/worksheet-v2` 与独立的 `useWorksheetV2Session`，既有页面的 `useWorksheetDraft` 未被改造。结果是**用户默认看到的仍是旧界面**。

## 2. 两种可选路径

### 路径 A（贴合方案原文）：改造 `useWorksheetDraft`

把 `src/composables/useWorksheetDraft.ts`（约 600 行）改为持有 `InputDocument`，让 `WorksheetView.vue` 直接使用 v2 的输入层。

- **优点**：完全符合方案；不新增并行实现。
- **代价**：改动正在服务的 composable；`WorksheetView.vue` 的模板与逻辑需大量替换；旧 E2E 断言需重写。
- **风险**：高。

### 路径 B（最小改动达成同等用户效果）：让既有路由渲染 v2 视图

`/copybook` → `<WorksheetV2View subject="chinese" />`，`/words` → `<WorksheetV2View subject="english" />`，并给 `WorksheetV2View` 加一个 `subject` prop 替代按路由判断。

- **优点**：改动小（路由 + 一个 prop）；用户立即在原有入口看到统一流程；旧组件文件保留，回滚只需改回路由。
- **代价**：旧页面代码成为未引用代码（可在后续清理）；旧 E2E 断言仍需重写。
- **风险**：中。

> ### ⚠️ 路径 B 已被否决（2026-10-03 核对后更新）
>
> 原先建议路径 B 的理由是「小改动达成同等效果」。核对 E2E 断言后确认**该前提不成立**：v2 **未复用 `CurriculumPicker`**，教材导入只能「整册全量追加」，缺少旧页面的**按单元/课文范围选择**、**内容缺口提示**、**单元条目数与勾选一致性**。
>
> 因此路径 B 是**以丢失功能为代价的降级切换**，不可执行。
>
> **修正后的顺序**：先让 v2 复用 `CurriculumPicker` 并补齐范围选择与缺口提示，迁移对应 E2E 断言，**然后**才切路由。详见 status.md §6.30。

- 就「完成字帖与英语字帖统一输入流程改造」而言，**目标未达成**。
