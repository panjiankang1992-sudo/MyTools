# 字帖三步流程实现与修复记录

完成日期：2026-10-04。目录沿用本轮开始日期 2026-10-03。

语文和英语已改为「数据来源 → 数据确认 → 数据预览」三个独立界面。改动已落在本地 `toolbox-web`，本轮未部署生产。下文区分代码修复、实际执行的验证与未完成的整体验收，不继承旧报告的“全通过”结论。

## 当前交互

1. **数据来源**：初次只呈现教材、自定义文本、图片识别三个入口。教材选择年级、上下册、版本、字表、单元/课文；自定义来源输入文本及分项方式；图片来源选择图片并旋转、框选、识别、编辑候选文本。
2. **数据确认**：所有来源进入相同界面。原文可编辑，语文校对拼音、英语补充中文释义；统一选择题型、数量、标题、格距、重复次数等。字表类型只筛选教材内容，不决定题型。
3. **数据预览**：展示真正生成的 PDF，可翻页、缩放、导出、打开打印预览，并独立生成答案 PDF。上一步返回确认页，步骤栏也可返回来源页。返回保留原文、校对、设置和来源候选；再次继续相同来源不会重复追加。

教材目录使用真实教材、年级、册次、单元和课文名；内部 ID 仅用作身份和查询键。没有名称时回退到序号，不把内部 ID 当标题。已发布教材中已经校对的条目可选择；草稿及阻断条目仍排除。

## 上轮问题的实现处置

| 问题 | 本轮实现 | 回归证据 |
| --- | --- | --- |
| R01 正文或解析方式变化仍输出旧 PDF | 内容、版式和生成版本共同决定输出有效性；等条数替换也会作废旧产物 | `worksheet-session`、`worksheet-workflow`、`worksheet-v2-composable` 测试 |
| R02 无效原文继续使用旧词条 | 当前解析错误写入会话；处理和生成均拒绝无效原文 | 输入、会话、composable 回归 |
| R03 迟到任务覆盖新编辑或清空 | 生成快照、请求序号和当前内容签名核对；仅提交有效产物，丢弃并释放过期结果 | 清空、编辑、乱序完成、销毁、学生卷与答案并发回归 |
| R04 草稿恢复丢字段 | 恢复解析策略、配对校对、来源、模式、数量及版式；损坏草稿不替换当前编辑；v1 只读迁移 | draft-session、draft-v2、composable 回归 |
| R05 单项确认误确认全部 | 只更新目标词条；批量确认仍检查歧义 | 单项确认与读音编辑回归 |
| R06 固定教材及目录 ID | 完整教材选择组件、真实元数据标题、版本身份保留；允许 published 版本下 reviewed 条目 | 真实一年级 318 条教材 fixture 回归及浏览器导入 |
| R07 重复展开两次 | 处理层只展开一次，渲染收到已展开题目；超过上限明确阻断 | 2×2=4、200×2=400、500 上限及真实 PDF 题号检查 |
| R08 英语缺少释义入口 | 按学科展示释义输入，不依赖拼音状态 | 英语浏览器输入、生成及真实 PDF 回归 |
| R09 第 61 项以后不可校对 | 每页 30 项，支持上一页、下一页和页码跳转 | 浏览器实际定位第 61 项和第 200 项 |
| R10 移除图片后旧队列残留 | 清除队列、选区及占用额度，取消任务并释放图像和 worker | image-session、OCR 取消和迟到任务回归 |
| R11 OCR 未使用预览旋转 | 预览和 OCR 输入共用旋转后坐标与裁剪定义 | 四个方向的 image-render 与裁剪回归 |
| R12 缺少排版和答案入口 | 确认页增加排版控件，预览页提供独立答案 PDF | 真实页面与四模式学生/答案 PDF 回归 |

验收脚本也已改为严格的 44 个主项模型：必测子项缺失不能记通过，失败退出 1，未完成退出 2，新运行不覆盖历史证据。完整 44 项尚未全部执行，不能把本轮单元测试数当作完整验收通过数。

## 本轮已执行验证

- 自动化测试 **337/337 通过，0 失败、0 跳过**；类型检查及生产模式构建通过。证据：[unit-tests.log](unit-tests.log)、[typecheck.log](typecheck.log)、[build.log](build.log)。构建输出到隔离临时目录，日志中的外部 outDir 提示不是编译错误。
- 教材结构、引用、校对、hash 检查通过：20 个必需槽位，5 个已发布版本。此数量不代表所有槽位内容完整，页面会显示内容缺口。证据：[curriculum.log](curriculum.log)。
- 21 个本地依赖版本检查通过：[dependencies.log](dependencies.log)。
- 真实 composable 调用正式 PDF 渲染器，四种模式分别生成学生和答案 PDF；另有 100 题、多页样本。独立解析器检查 A4 尺寸、题号、题目顺序、页数、学生卷无答案、答案卷有答案及产物隔离。样本、hash 和检查结果：[PDF 证据](pdf/README.md)。
- 浏览器实际操作：中文自定义输入→确认→预览→返回编辑；再次返回来源保留编辑内容；英文含 `"ice cream"` 的两项输入、补释义、学生卷及答案生成；教材整册 318 项导入，返回后继续仍为 318 项；第 61 项及第 200 项可达。
- 最终复核补充：中文“春天”仅填 `chūn`，汉字字帖的生成按钮禁用；切换拼音字帖后学生卷可生成，进入预览后需要完整读音的答案生成与下载禁用。未完成拼音编辑不会影响不需要拼音的学生输出，也不会让答案使用旧确认值。空闲切换图片来源不再误报“已取消识别”。
- 390 px 确认页及 320 px 预览页检查中，文档宽度没有超出视口；截图见下方。临时移动端视口已恢复。

## 复跑

在仓库 `toolbox-web` 目录、已安装本地依赖的环境中：

```bash
npm test
npm run typecheck
npm run build:production
npm run test:curriculum
npm run verify:deps
npm run test:acceptance
```

最后一个命令在尚缺必测证据时返回 2 是预期行为，不可改成空断言或历史字符串以获得通过状态。
