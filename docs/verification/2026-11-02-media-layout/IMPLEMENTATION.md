# 多媒体与选择弹层布局修订

日期：2026-11-02。依据：用户反馈选择列表“清除”超出卡片、多媒体标签过大，并要求目录/标签筛选与搜索同行。

代码和本地评审稿已同步，签名构建及8套相关主机检查通过，最终修订包已覆盖安装并冷启动。解锁后已完成最终真机检查：同行工具栏、搜索输入/清空、目录/标签选择层边界和对齐、卡片标签位置均通过。

## 修改

| 范围 | 实现 |
| --- | --- |
| 选择层头部 | 新增 `AppSheetHeader`，左右原生操作槽各64宽、禁止收缩，头部左右留白16；标题仅占剩余宽度、单行省略。空操作槽保留对称宽度，但不创建空按钮。 |
| 覆盖入口 | 目录/标签选择、通用媒体来源/类型选择、远程图书来源、网盘选择共4个Builder接入统一头部。关闭、清除、确认及各自可用条件保留。 |
| 按钮边界 | `AppButton`自然宽度结果添加maxWidth钳制；其余共同高度、透明原生命中层、固定字体和防重复操作逻辑不变。 |
| 媒体工具栏 | 保留上方图片/视频/音频分段；下方单行搜索＋目录＋标签。筛选各68宽、13字号、6间距；搜索消费剩余宽度，选中长值省略并保留完整可访问名称。320宽且页边距20时，搜索仍有132宽。 |
| 媒体卡片 | 标签移到文件信息下方，字号12、行高18、可见薄底24、独立点击区至少44；横向滚动避免挤破窄卡，大字时行高随配置增加。标签筛选回调及前三个可点击标签保留。目录标题16，图库文件名13。 |
| 本地评审稿 | 同步媒体单行工具栏和紧凑标签；修复组件库多选展开时被卡片裁掉底部确认按钮的问题。保留72项组件、14张页面、固定字体及已批准状态。 |

## 验证

- ArkTS编译、HAP资源打包、签名及独立签名校验通过；随包三份固定字体哈希一致。见 `build.log`、`build.json`。
- 8套主机检查通过，见 `tests.json`：UI尺寸测量、UI规范、画廊回归、媒体操作面板、媒体页面、远程选择策略、书源布局、DSH认证。
- 新增有限宽度回归：即使自然测量返回320，48/64/96宽父级下，返回尺寸、底板约束和命中区仍保持在父级范围内。
- 新增结构约束：4类选择层共用有限头部；搜索和两个筛选必须位于同一原生Row；元数据标签必须位于文件信息之后，不覆盖预览。
- 本地评审页经CUA视觉检查：同行工具栏无横向溢出；底部选择面板“清除”在卡片内；多选“在读→完成选择”可正常完成。生成脚本及语法检查通过。
- 最终真机检查：搜索输入与目录/标签按钮均位于y=533至689；输入临时test并清空成功，清空图标在搜索框内。两个选择层的清除文字及点击区在卡片边界内，左右操作围绕卡片中心对称。两张可见卡片的标签行位于预览下方，单独143像素高的滚动区，不覆盖缩略图。见device-final-smoke.json；早期检查另留在device-selectors.json、device-tag-placement.json。
- 未专项覆盖：320宽、大字号、超长标签横向滚动的完整设备矩阵。本轮只临时输入/清空查询、打开/关闭选择层，未删除或修改媒体，也未保存任何新数据。
- 构建保留一条改造前已有的下载剪贴板权限诊断，本轮没有新增相关权限或修改该流程。
