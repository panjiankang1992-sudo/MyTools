# RSS 首版验收记录

日期：2026-11-01。已完成开发、构建、本地验收及生产部署；**RSS 生产路由和自动更新已启用**，详见[生产发布记录](PRODUCTION.md)。仓库配置模板仍保持默认关闭。

## 交付

- 独立 `feed-core` 和 `rss-service`：公开 HTTPS RSS 2.0 / Atom 1.0，安全 XML、HTML 清洗、条件请求、身份去重、后台轮询、租约、退避、90 天正文清理。
- MySQL 初始迁移：四张业务表及 `rss_owner` 协调表；Gateway 双前缀、既有登录验证、可信 owner、请求体限制与独立 RSS 超时。
- 鸿蒙 App「阅读 → RSS 订阅」：未读/全部/收藏、来源/分组筛选、搜索、图文阅读、已读收藏、批量已读、添加检测、设置/暂停/取消、分组、OPML。
- 阅读页禁用脚本、存储、文件访问，使用隐私 Web 视图；按用户后续要求，HTTPS 图片默认自动加载，外链交给系统浏览器。列表显示左侧缩略图，缺图或加载失败时文字占满整行。
- 服务清单、环境变量示例、独立构建脚本、发布组装时自动先安装 `feed-core`、[接口契约](../../../service/contracts/rss-v1.md) 与[运行说明](../../../service/rss-service/README.md)。

## 模拟器与真实网络

环境：HarmonyOS 6.1.1 API 24，手机模拟器 1320 × 2856；本机 MySQL 容器，正式 RSS/Gateway jar，HDC 回环端口转发。**只有身份校验使用回环测试替身**，便于独立验收；Feed 传输器、解析器、数据库、业务 API 和 App 页面均为实际代码。验收包通过脚本临时替换入口，退出后恢复源文件，测试入口未进入正式 HAP。

- 真实 Atom：`https://www.ruanyifeng.com/blog/atom.xml`，检测、创建、后台抓取和中文长文显示通过。
- 真实 RSS：`https://sspai.com/feed`，在 App 输入地址、检测预览、确认添加，后台抓取成功。
- 正文首屏实际绘制后自动已读；点击收藏、标记未读均回写 MySQL。字号/图片重新加载不会覆盖手动未读。
- 初版验证过手动加载图片。后续已按用户要求去掉按钮，进入正文直接显示 HTTPS 图片，并重新通过模拟器实测。
- 系统返回恢复列表；收藏页与阅读动作可用。返回保留已加载页、游标与滚动位置，刷新计数。补测短摘要文章自动已读、手动改回未读，以及滚动后进入详情再返回，均通过。
- OPML 经系统保存选择器写入 Download，再经系统选择器选回；预览显示两个重复项，确认导入后来源数量与阅读状态未被重置。
- RSS 服务与 Gateway 本地重启后，2 个订阅、11 条未读、1 个收藏及每篇状态版本保持一致；人为留下的到期租约自动被接管，两个来源继续成功更新。证据：[restart-result.json](restart-result.json)。

实测修复：ArkWeb 的初始 `about:blank` 导航会覆盖 `loadData`；现使用空初始地址，只放行组件自身生成的完整 data 文档，以首次内容绘制或明确归属的文档加载完成事件判定可读，兼容短文和缓存场景。使用隐私视图与 CSP 保持阅读隔离，不通过开放导航或脚本解决空白问题。
