# 图片标签展示修复验收

原因：下载任务的 `generate_tags` / `record_tags` 已将标签写入下载记录，但媒体投影发生在标签生成之前，后续没有同步媒体库。APP 图片卡片仍有标签浮层，拿到空数组时不显示。

修复：

- 新增受内部令牌保护的下载标签事件接口，按所有者与资产定位媒体，并校验下载来源。
- 事务内记录幂等事件并合并 DOWNLOAD 来源标签，保留已有手工、迁移和分析标签；读取时去重。
- 发布不可变 `download_record_tags/1.1.0`，保存下载标签后同步媒体库，失败交由步骤重试。
- Flyway V171 切换脚本版本，不修改已发布版本内容。
- 后端媒体服务 `media-tags-20260927-v2`；调度器及执行器 `media-tags-20260927-v1`。

生产回填：417 条下载媒体中，397 条有可复用标签，400 个来源事件成功同步，零失败；其中 366 条由空标签恢复。逐条 HTTP 读取验证 397 条，最近一页 10 条均返回标签。另有 20 条记录原本标签生成失败，未伪造标签。

验证：媒体服务 30 项测试、脚本 3 项测试、APP 目录刷新测试 1 项通过。线上验证覆盖幂等重放、标签筛选、错误令牌和跨所有者拒绝、V171 迁移及步骤版本。APP 无代码改动，无需重装；本次未声称进行真机视觉验收。

审计结果见 `backfill.json`、`runtime-verification.json`。测试只重放已有标签数据，没有创建测试媒体文件。
