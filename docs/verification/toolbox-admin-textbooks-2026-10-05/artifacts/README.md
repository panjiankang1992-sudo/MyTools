## 复现方式

```bash
# 1) 启动本机服务（前端 4173、后端 23199）
# 2) 用 CDP 驱动 headless Chrome 访问本机地址并截图 / 触发下载
```

截图脚本本身**未纳入仓库**（一次性使用）；如需长期保留，应作为 E2E 的一部分固化。

## 尚未覆盖

**管理页的截图无法产出**：管理页需要真实登录，而本环境缺少可用凭据（见 `../acceptance-matrix.md` 的说明）。
因此 A04 的"登录后管理入口可见"、以及编辑页／目录树的实际观感，**目前没有任何视觉证据**。

**D05 要求的「两页以上样例」已产出**（第 102 轮）：

- `sample-chinese-dictation-2-pages.pdf`：**2 页**，由 `pdf-lib` 读取页数确认（不依赖界面文字）；
- `desktop-preview-2-pages.png`：预览截图，纸面上可见「第 1 / 2 页」与翻页控件。

**产出过程中得到的两条判据教训**（详见 `../step1-permissions-and-contracts.md` 第 100—102 轮）：

1. **不能读界面上的「第 N / M 页」来判定 PDF 页数**——配对编辑器自己也分页（每页 30 行），
   318 行会显示「第 1 / 11 页」。必须**下载 PDF 后用 pdf-lib 读**。
2. **318 项会触发 200 项的练习题数上限**，生成会被拒绝（界面明确提示「系统不会自动截取」）。
   要得到多页样例，需把题目数量策略改为「随机抽取」并设定在上限内。
