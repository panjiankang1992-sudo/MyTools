## 线上验收重点

1. `/copybook` 与 `/words` 显示“数据来源 → 数据确认 → 数据预览”三个独立步骤；返回保留原文、校对、来源和版式，不能绕过有效输入与生成进入预览。
2. 教材可选择年级、上下册、版本、字表及课文；已发布教材内 `reviewed` 条目可用；同一选择返回后继续不重复追加，缺失册次如实提示。
3. 同数量正文替换、题型切换、版式变化后旧学生/答案 PDF 作废；生成中返回、清空或编辑，不允许迟到结果复活旧内容。
4. 四种题型均通过正式按钮生成和下载：确认实际 PDF 签名、完整页数、内容和题号；学生文件不含答案。两项重复两次须为 4 题。
5. 汉字字帖中的未完成拼音编辑应阻断该学生卷；切换拼音字帖后，学生卷只需要有效汉字，不能被无关答案读音阻断。
6. 图片可选择、裁选、旋转、识别、取消和移除；四种旋转实际使用同一方向坐标；取消/移除后的迟到候选不能落回原文；确认应用后进入数据确认页。
7. 页面刷新无旧缓存资源报错；字体、PDF 及 OCR 静态资源同域可取；窄屏步骤、末项校对和输出按钮可达；首页、左导航及既有 PDF 工具入口仍可使用。

验收范围沿用已记录的辅助 OCR 与 PDF 导出止步决定；不能把本地测试结果替换成尚未执行的生产按钮下载证据，也不自行增加实体打印要求。
