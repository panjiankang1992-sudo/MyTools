# 解压工具异常场景回归

2026-09-28。继续补做首期未覆盖的异常场景，并修复导入阶段的取消时序。最终构建已覆盖安装至模拟器 `127.0.0.1:5555`，启动成功。当前未连接真机。

## 修复

计算输入压缩包 SHA-256 是异步步骤。此前用户在此期间取消或离开页面，计算结束后仍可能进入预览并重新清除取消标记。现在线程返回后再次检查取消，删除本次导入缓存并返回 `ARCHIVE_010`；页面在导入完成后也检查生命周期、当前标签页和前后台状态。单文件保存选择器返回后增加页面可见性检查。

## 本轮实跑结果

| 测试 | 通过数 | 范围 |
|---|---:|---|
| 原生真实引擎 | 55 | 包含新增混合密码 AES ZIP、父文件/子路径冲突、真实输出开始后取消解码及半成品清理 |
| 业务服务故障测试 | 17 | 真实临时文件，平台接口由主机适配器代替：批量导出进度、重复目标拒绝、取消后的未处理目标保持原样、源大小变化拒绝、目录失败回滚、空目录及层级、有限密码轮询、错误密码记录、指纹计算期间取消 |
| 目录树/导出策略 | 20 | 父子选择、搜索、展开、同名文件及非法路径 |
| 密码策略 | 6 | 去重、排序、原文空格大小写 |
| 合计 | 98 | 全部通过 |

混合密码测试使用 7-Zip 两次增量写入同一个 ZIP，两个真实 AES 加密条目采用不同合成密码，分别解密并比较字节。业务层混合密码测试验证候选循环和记录逻辑，原生接口注入可控返回值；两者不能替代手机上输入多个密码的端到端验收。

真实运行中取消测试：对 64MiB 合成文件解压，另一线程等待实际输出字节大于零再设置取消。断言错误码为取消、任务输出目录不存在。测试没有修改生产原生引擎。
