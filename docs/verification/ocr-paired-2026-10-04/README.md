# 字帖配对编辑与图片词表识别验收

发布日期：2026-10-04。发布版本：`paired-editor-20261004-170000`。
线上：https://toolbox.yuyutian.top/

## 实现结果

- 自定义选内容与确认内容共用同一个配对编辑器。语文左汉字、右拼音；英语左中文、右英语。
- 一行一组，单列可粘贴多行；保留空行的对应位置和短语内部空格。支持整组增删，超过30组分页。
- 输入一侧后，在确认步骤自动补全；已有人工输入和图片识别释义不被自动翻译覆盖。
- 使用稳定的行身份，重复词、编辑、删除、迟到翻译回包不会串行。拼音错误保留输入供修正。
- 返回来源或确认页均保留修改；手机按每组上下显示，在390像素宽度无横向溢出。
- 修复确认页输入失焦后保存提示挤动按钮、首次点击上一步失效的问题。
- 英语图片候选也用同样的左右配对表，保留OCR得到的中文；取消、裁剪重选及超时按版本隔离。

## 图片识别的实际限制

两张图片共提取23个英文条目，22个英文准确，`week`仍可能误识别为`Weak`；13条中文释义成功对应且核对正确，10条未可靠识别而留空。缺项可以在确认步骤自动翻译或手动补充，但翻译结果不等于识别到了课本原文。不能据此宣称整张单词表完全识别正确。

本次修复增强结果被原图高置信乱码覆盖的原因，恢复了walk、free、Monday与完整短语，并按坐标配对中英文。未硬编码用户照片答案。

线上自动翻译对10条缺失释义补全了9条，walk出现可重试的失败。free自动译为“免费”、up译为“上涨”，与照片中的“空闲的”“起床”不同，说明多义词仍需要按教材语境手工校对。双栏可直接修改，但本次界面验收通过不代表OCR和词义已全部准确。
