# 下载工具回复格式化验收

> 后续按用户反馈简化为普通列表，最终状态以 [列表版验收](LIST-UPDATE.md) 为准。以下保留第一版的历史验收记录。

日期：2026-10-03。设备：Pura 90 HarmonyOS 模拟器。范围：APP 下载聊天页的结果展示与交互。

## 改动

原页面把状态、文件、标签类型、置信度和长归档地址拼接成一段文本。现在使用服务端已提供的结构化结果渲染：

1. 状态摘要：完成、部分完成、未完成、处理中、取消中明确区分。任务失败但已归档文件时保留“部分处理完成”，不会把已保存文件说成全部失败；未知状态不显示成功。
2. 文件卡片：文件名、真实扩展名对应的类型图标、大小、归档状态、标签状态分开展示。85 MB 的 MP4 即使归在图片目录仍标记为视频。
3. 标签：去重后的标签名称以小标签展示，默认六个，展开详情可看全部。技术类型和置信度不再挤占聊天正文。
4. 详情与长列表：默认展示前三个文件，可展开全部；完整路径按需展示并可选择复制。新增复制回复按钮。
5. 进度：数值限制在 0–100，明确标注“下载进度”；本地媒体整理不冒充外链下载进度。取消按钮置于进度附近，取消中禁用重复操作。
6. 兼容旧数据：缺失大小显示未知，空标签/空结果不崩溃。联测发现列表复用可能保留旧标签状态，已用内容变化触发更新解决；相同数据刷新不重建卡片。

## 验证

正式版和离线验收包均构建成功且无警告，`git diff --check` 通过。纯计算测试覆盖大小边界、缺失旧字段、标签去重、视频类型、未知状态、部分失败与进度边界。

离线验收入口复用与正式版字节一致的 `DownloadReplyCard`、展示规则与聊天页文件，哈希见 [component-hashes.json](component-hashes.json)。入口只存在于临时副本，不访问业务服务、不创建下载任务。

| 场景 | 实际结果 |
| --- | --- |
| 成功文件列表 | 视频 85.31 MB、图片 120.00 KB、音频 7.52 MB 分开展示 |
| 展开详情 | 显示第七个标签、完整归档地址；可收起 |

| 正式版恢复 | 替换验收包后正常打开工具→下载工具→刷新，加载真实历史消息；详情展开与收起通过 |

## 交付与边界

最终正式版已安装模拟器，离线测试入口已覆盖移除。本次没有新增后端接口，也没有修改下载、标签和归档处理规则。状态矩阵与取消、复制使用合成数据验收，正式版另对真实历史消息进行只读展示与详情操作验证。本次未重新执行生产下载或 QQbot 全链路，也未安装真机。

离线样例不写应用数据库或文件，不产生待删除下载任务。临时验收构建目录及测试编译产物已清理；可复现测试源码和截图保留在仓库，正式签名 HAP 保留在 app 的标准构建输出目录。
