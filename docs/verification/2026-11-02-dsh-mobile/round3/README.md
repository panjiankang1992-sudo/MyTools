## 本轮修复

1. 移除按禁用态隐藏分栏控件的规则，修复宽度测量循环引起的 React #185 和文件面板空白。
2. 手机文件标签与工具分行、文件行 44px；横屏工作面板占满视口，避免遮住会话操作。
3. 修复插件开关变形、长组件说明挤成窄列、侧栏图标重叠；手机断点对齐 768px。
4. 短屏次级弹窗整体滚动，修复安装说明把输入框挤成边框；按钮可滚动到达。
5. 侧栏更多菜单常驻，触屏可访问置顶、重命名、分支、归档、复制 ID；新建会话后收起抽屉。
6. App 加入受来源与生命周期约束的 ArkWeb 下载代理、系统保存器和麦克风授权，普通外链交给系统浏览器。
7. DSH 独立优先 HTTPS，保持麦克风安全上下文；连接失败可选择经过验证的局域网备用，其他业务接口继续使用原端点。
