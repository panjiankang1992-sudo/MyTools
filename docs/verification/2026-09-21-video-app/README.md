# 视频 App 功能验收

2026-09-21：在已有 HarmonyOS 模拟器 `CopilotPerf0912`（本轮 HDC 地址 `127.0.0.1:5555`）覆盖安装签名 HAP，保留原登录态，通过真实生产接口验证视频工作台。当前无连接真机，本轮不属于真机验收，也不代表整个 App 的所有模块通过。

## 发现并修复

1. 后端已返回两种模型，但 App 没有模型切换控件。增加 VACE/LTX 选择，切换时清除旧素材、模式与待提交快照，规格随模型更新。
2. LTX 提示词说明与本机整理流程不符，单图模式还使用“一张或两张”的泛化描述。按模型修正说明，并区分“不支持”与“未验收”。必填提示词说明已编译验证；生产模式关闭，因此该输入区域本轮没有实际显示测试。
3. “模型已就绪”容易被理解为允许生成，改为明确显示“模型已就绪，暂无可用模式”。
4. 再次创作被门禁拒绝时，提示位于长作品列表底部，当前屏看不到反馈。将页面消息移到内容上方，真实点击回归确认可见。

代码：`app/entry/src/main/ets/features/tools/VideoGenerationPage.ets`。
