# 图片详情页连续滑动

日期：2026-11-15。范围：鸿蒙 App 图片详情页上下切换。

## 结果

- 当前图与相邻图使用同一屏幕高度沿纵轴移动，取消原来的淡入、缩小和 220vp 位移上限。
- 拖动跟手；松手按距离与同向速度判断是否切换。成功翻页用 260ms 完成整屏移动，短拖动或取消用 200ms 回弹。
- 动画完成后才提交目标图片；过渡封面保留到目标图解码完成，高清替换也有封面保护。
- 图片来源变化时用来源键更新节点；旧图完成事件不能清除新图的过渡封面。
- 放大后只平移当前图；加载失败回弹；关闭、退出登录和页面销毁使旧动画回调失效。
- 尚未加载的分页末尾不错误循环到第一张；一次手势固定目标，分页回包不会改变正在拖动的相邻图片。
