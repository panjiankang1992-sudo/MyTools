## 本次行为

- 教材、自定义、图片三种来源统一补缺：汉字生成拼音，中文生成英语，英语补充中文释义。
- 自定义在停顿或失焦后开始，图片识别完成后开始；教材导入统一确认页后开始，无需另点补全。
- 教材已有值、图片已有对应内容和人工修改保持原样；未生成成功的项可重试或手填。
- 自动结果记录生成来源，返回上一步、确认以及草稿往返后改原文，会清除旧自动结果并重新补全。
- 取消或切换页面后不再回填旧请求，返回可继续补缺；成功项不重复请求，失败项最多自动重试一次。
- 英译中主候选含拼音或英语时，只采用原文精确匹配、语言方向正确、匹配度不低于0.99的有效备用候选，解决walk未补全的问题。

## 准确性边界

自动补全通过不等于原图内容全部识别正确：week仍可能识别为Weak，自动译成“微弱”；free、up、walk的自动译文为“免费”“上涨”“走”，与照片里的“空闲的”“起床”“牵着（动物）走，遛”存在语境差异。已有课本释义不会被这些候选覆盖，缺失时生成的候选仍需按教材核对，双栏可直接修改。本次未硬编码照片答案，也未将自动译文冒充OCR识别原文。
