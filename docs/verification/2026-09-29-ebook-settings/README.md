## 改动与观察

1. 原设置只提供数字滑杆：增加与当前字体、字号、行距、主题一致的样例预览。样例不表示实际页面宽度或段间距。
2. 字号滑杆难以微调：改为 A− / A+，每次调整 1，范围 14–32，到边界禁用对应按钮。
3. 刻度含义不清：段距与页边距显示整数，行距使用 0.05 步长及两位小数，亮度使用 1% 步长并显示百分比。
4. 拖动排版滑杆时连续分页：仅在松手或点击提交后应用设置并保存。
5. 系统返回关闭设置缺少与完成按钮一致的保存动作：统一关闭方法。
6. 设备观察发现预设切换后滑杆数值未刷新：预设变更时同步重建滑杆，确保显示和实际值一致。
