# 教材库优先补全：前端验证

日期：2026-10-18（Asia/Shanghai）。本报告仅说明本地代码及测试，生产发布由主任务另行记录。

## 实现

- 公共及管理员翻译客户端增加可选 `subject` 参数；不传时保留原英文协议，语文请求明确 `subject: "chinese"`。语文只读本地查询使用 12 秒超时，英文外部翻译保留 45 秒。
- 新增 `src/lib/curriculum-pinyin.ts`，每批最多 20 项，先读取服务器已发布教材拼音；只对未命中或不可用项调用本机拼音库。教材结果必须与行身份、原文、字素和有效音节对应。一次网络失败后其余批次直接本机降级，取消后不再降级。
- `useWorksheetPairCompletion` 覆盖自定义输入、图片识别候选和简洁管理录入；`useWorksheetV2Session` 覆盖教材导入与确认页；旧高级管理页同样通过管理接口读取教材拼音。
- 已有两栏内容、人工修改和已初始化行保持原样；只首次自动补空。显式补空仍只填空栏，取消或迟到响应不会覆盖当前输入。
- 语文预览和答案生成等待异步补音结束，避免查询尚未完成就生成。旧高级页补音回写同时核对账号、目录范围和字段快照。
- 输入控件已有说明改为“首次优先使用教材库补齐”，未增加额外操作步骤。

## 浏览器验收发现并修复请求字段问题

生产浏览器操作暴露出原测试未覆盖的问题：调用方传入的待处理对象带有 `source`、`target` 或 `fields`，共享 helper 原样传给 API，严格后端拒绝额外字段并返回 422。直接 curl 仅含 `id/text`，因此能通过；界面随后降级本机拼音，未真正命中教材库。

修复：在 helper 的网络边界显式将每项投影为 `{ id, text }`。新增两项回归，分别检验带编辑快照对象的参数裁剪和真实 `translateEntries` 客户端最终 JSON 请求体；教材命中测试禁止静默降级。

修复后定向回归 **53/53 通过**，类型检查再次通过。详情见 `frontend-request-shape-tests.log`。前述 739 项完整测试记录属于修复前版本，本次额外修复的线上重建与浏览器复核由主任务记录。
