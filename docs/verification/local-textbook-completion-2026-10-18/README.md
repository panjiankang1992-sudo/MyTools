# 教材库优先补全：实现与上线验收

2026-10-18 已部署到 https://toolbox.yuyutian.top/ 。最终发布标识 `local-textbook-20261018-174010`，17:41:51 完成前端切换；后端于 17:33:51 完成更新。

## 行为

- 英语中英双向补全优先查已录入并发布的教材：完整词条 → 括号外的独立中文义项 → 内置常用词 → 有效缓存 → 原外部翻译渠道。支持单词及短语，不做子串猜测或拼接翻译。
- 中文拼音优先采用教材整词的已校对读音，未命中或查询不可用时才用本机拼音库。拼音必须逐字对齐。
- 多本教材匹配时优先最近发布时间；时间相同或缺失时按稳定教材及条目顺序选择。完整词条优先于义项别名。草稿不进入公开词典。
- 教材发布后刷新词典和旧翻译缓存。本地命中不调用外部翻译或消耗外部额度。
- 自定义输入、图片识别结果、教材导入和确认页、简洁管理录入及旧高级页均使用同一优先规则。已有配对与人工修改保留，每行仍只首次自动补空；显式再次补空也不覆盖非空内容。
- 语文预览和答案生成等待异步补音完成；取消、返回、删行、改字和切换账号后的旧回包不覆盖当前编辑。

关键实现：后端 `TranslationDictionary`、`TranslationService`、`TranslationRequest/Result`、`CurriculumCatalog/CatalogSnapshot`；前端 `curriculum-pinyin.ts`、两个自动补全 composable、公共及管理 API 客户端和旧教材编辑页。没有新增数据库迁移。
