# 英语教材照片识别修复

发布版本：`ocr-photos-20261004-160000`。

## 问题与处理

旧英语入口仅加载英文模型，中英混排页中的中文被识别为拉丁乱码；整页原始识别文字直接进入练习内容，释义、页码与圈线噪声没有分离。

本轮使用中英混合模型读取原图，并针对蓝青色印刷文字生成原始掩码、两档有限垂直断笔修补图。三路增强缩至最长边 1600 像素，沿用同一方向和坐标，通过置信度与空间范围合并，保留黑色英文和完整混色短语。没有词典纠错或根据样图答案替换文本。原图与三路增强由同一个 worker 串行运行，共用每图总超时预算。

候选每行一个单词或短语，自动排除可识别的中文释义与页码；保留句内空格、标点、大小写。原始全文单独保存，可展开核对。取消始终作废迟到结果；增强超时会终止 worker 并返回此前成功阶段的候选，显示未完成提示。黑白图不执行颜色增强；语文入口的模型及识别行为保持原样。

实现参考了 Tesseract 关于噪声、字高与页面分割的[官方说明](https://tesseract-ocr.github.io/tessdoc/ImproveQuality.html)，最终参数依据真实样图实验选择。

直接调用生产 `encodeWorksheetImage`、`prepareOcrInkImages`、`createLayoutOcrWorker`，使用相同锁定的 Tesseract.js 和本站模型。Node Canvas 替代浏览器 Canvas；没有把图片发送到第三方。

剩余差异为第二图 `week` 识别成 `Week`。`lesson`、`walk`、`See you tomorrow!`、`What day is it today?` 均正确，未漏词或混入释义、页码。见 `integration-results.json` 与 `photos.log`；`verify-photos.mts` 接收两张原图路径即可复现。实验阶段完整原始结果保存在 `experiment-results.json`，不要把模型置信度当作实测准确率。

黑白英文、混色短语、左右部分蓝色句子、空白图的真实识别回归通过，见 `experiment-regressions.json`。中文夹具存在旧模型本身的误识：新旧原始输出完全相同，报告如实保留准确性失败，不把“无回归”表述为“汉字全部识别正确”。
