# PDF 工具模拟器体验优化与验收

日期：2026-10-03。平台：HarmonyOS Pura 90 模拟器，1320 × 2856。仅安装模拟器，不涉及真机或后端部署。

## 体验路径与结论

1. **选择工具：已改善。** 整理区原来三个相同文档图标，不能快速区分切页面、拆文件和合并。现在有独立图标和一行用途说明，保留三列布局。[之前](01-before-home.png) / [最终入口](16-final-home.png)。
2. **准备输入：已改善。** 原空页面先露出输出名，选文件入口弱，底部生成不可用。现在先说明输入和步骤，底部主按钮直接选择 PDF/图片；单文件显示“更换”，多文件显示添加；合并只有一份时提示“再添加一个 PDF”；文字输入可直接填写，导入明确为可选。[之前](02-before-empty.png) / [优化后](08-after-empty.png) / [文本输入](15-after-text.png)。
3. **设置参数：已改善。** 原分割预览过高，核心参数挤出首屏。现在预览上限 200 vp，方向与比例可同屏查看；范围和输出顺序继续向下滚动访问。比例、顺序弹层使用草稿，确认后生效。拆分用“按页数 / 自定义分组”切换，隐藏不生效的设置，空分组不会悄悄回退。错误自动滚到可见位置。[之前](06-before-cut.png) / [最终分割](18-final-cut.png) / [越界提示](17-invalid-range.png)。
4. **执行与反馈：已验证。** 主按钮随阶段显示选文件、分割页面、拆分文件、合并文件、导出图片、提取文本、生成 PDF。无正文禁止提交；空输入禁止无效重置。生成时仍保留进度与取消机制。参数重置及切换工具恢复默认值。
5. **结果与连续处理：已改善并验证。** 原结果只能预览/保存/返回。现在可“调整参数”或“继续处理”，结果直接带入下一工具；多文件结果必须在对应文件卡片选择，不会默认误用第一份。继续菜单显示当前文件名。[之前](04-before-result.png) / [最终结果](19-final-result.png)。
