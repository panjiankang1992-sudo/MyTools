## 结论与边界

六种模式均由真实 HarmonyOS App 页面选择素材并提交到本机 HTTP 夹具，角色和输出规格断言通过。不是六种模式真实推理、画质或正式全链路验收通过。生产所有视频模式继续关闭；本轮未修改 Ubuntu。

设备为 `127.0.0.1:5555` 模拟器，没有真机。测试入口仅注入 `/tmp` 副本，引用与正式源码一致的 VideoGenerationPage，使用合成账号 A/B；不访问真实认证存储。服务仅绑定回环 23110，通过本轮创建的 HDC reverse 转发访问。任务状态由控制接口驱动，成片是固定既有素材；上传服务只检查非空，不验证媒体格式/大小上限。测试不证明真实模型行为、后端持久化、鉴权安全或媒体校验正确。
