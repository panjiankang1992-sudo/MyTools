## 本次行为

1. 教材、图片、自定义内容共用逐行的一次初始化标记。新行首次可补空；完整配对也直接标记已初始化。
2. 后续修改、清空、前后返回、切换题型、生成预览、恢复草稿均不自动重新补全。旧草稿按已初始化处理。
3. 只有用户主动点击“补全空白”“补全拼音／中英文”或重试才再次处理空项；已有非空内容不覆盖。
4. 请求失败、取消和编辑途中到达的旧响应不会触发自动重试或覆盖新输入。下一步等待正在执行的首次补全，编辑则取消旧导航。

## 验收边界

图片 OCR 仍存在词形和语境差异，例如照片中的 week 被识别为 Weak，free/up 的默认翻译不一定是教材义项。此次保证人工校正后不会被再次自动覆盖，不能把“配对字段齐全”当成“OCR 与教材释义全部准确”。
实体打印与系统打印窗口验证状态以 `printer.json` 和后续用户实物反馈为准；队列完成本身不能证明纸面清晰度。
