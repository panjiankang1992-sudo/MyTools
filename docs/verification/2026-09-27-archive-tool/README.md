# 解压工具实现与验收

2026-09-27。本文为首期验收记录。后续目录树、空目录和批量导出已补齐，当前交付情况见 [续实现验收](followup/README.md)。真机尚未连接，当前只在本机处理，不新增后端服务。

## 已实现

- 使用完整 7-Zip 26.03 原生解码器，包含 arm64-v8a 和 x86_64 两种 ABI。ZIP、7z、RAR4/5、TAR、GZIP/TGZ；加密 ZIP、7z、RAR 可提交密码解压。
- 文件选择与系统“打开方式”、目录清单预览、搜索、全选/选择文件、进度、取消、持久解压记录和逐文件系统导出。
- 所有实际使用过的非空密码均加密存入系统 Asset Store，包括错误密码；保留空格及大小写，去重并记录成功/尝试次数。手动密码优先，然后按文件成功记录、近期成功和其他历史自动匹配。
- 文件、解压记录、密码库三个页面；密码默认隐藏，查看需设备身份验证，自动隐藏，可单条删除或清空当前账户。密码库和结果按账户隔离，密码不上传。
- 路径穿越、链接、大小写冲突、条目数和展开额度检查；取消或失败不发布结果。限制：输入 500MiB、5000 条目、展开 300MiB。
- 引擎异步运行，已用候选有限轮询；30 秒在候选之间提示继续，后台/离开页面可取消。原生密码缓冲在完成后清理；不承诺 ArkTS 字符串可靠擦除。

## 实际验证

| 层面 | 结果 |
|---|---|
| 最终 HAP 构建 | 成功，无构建警告；两个 ABI 都包含解码器 |
| 原生自动回归 | 42 项通过，涵盖普通/加密 ZIP/7z、中文及空格密码、错误密码、取消、路径/链接/数量/大小限制 |
| 密码排序策略 | 6 项通过，包含原文去重、优先级、空值及历史快照 |
| RAR4/5 原生样本 | 正确密码输出成功，错误密码被拒绝 |
| 模拟器端到端 | AES ZIP 导入→错误密码→正确解压→历史自动匹配→逐字节核对→系统导出通过 |
| 删除 | 系统不支持带业务标签调用删除；已修复为先核对当前账户归属，再按别名删除，并实测成功 |
| 最终安装 | 移除临时清理代码后重建、覆盖安装并打开解压页面 |

输出为 31 字节，SHA-256：`b2c8508ce5597b409022ef7176b06dd36af85ce459c5fac1487637f2e7d633c4`。详细构建、包摘要和测试计数见 `build.log`、`native-tests.json`、`acceptance.json`。截图见 `simulator-export.jpeg`、`simulator-final.jpeg`。

## 与完整方案的差异与未验收项

- 已实现文件列表选择；文件夹树选择、空目录保留、批量目录导出、直接打开结果目录尚未实现。结果先保存在 APP 私有目录，再通过系统选择器逐文件导出。
- 同名冲突当前明确拒绝，不自动重命名。分卷和递归嵌套包不支持；GZIP/TAR 包装按专用流程处理。
- solid 包按文件解压，可能重复解码。超大 solid 包、严格峰值内存限制、存储满、权限撤销、进程强杀及混合密码 ZIP 全链路仍待专项验收。
- 真机安装、PIN 查看密码和后台取消交互尚未完成真机验收。本轮仅连接模拟器，不将两种 ABI 构建通过等同于真机验收。
