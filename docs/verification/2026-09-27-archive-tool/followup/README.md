# 解压工具续实现验收

2026-09-27。承接首期，补齐目录选择及批量导出。后续取消时序修复及 98 项异常回归见 [2026-09-28 验收记录](../../2026-09-28-archive-resilience/README.md)。最终 HAP 安装到现有 CopilotPerf0912 模拟器，未连接真机。

## 实现内容

- 文件列表改为可展开的目录树，补齐压缩包中未显式登记的父目录。支持整夹选择/取消选择、子项已选数量、搜索命中项及祖先路径。搜索时选择文件夹作用于完整分支。
- 空目录作为结果元数据保留，选择仅含目录的压缩包也能发布任务记录。支持目录导出的设备可重建空目录。
- 批量文件导出：一次系统保存授权导出全部普通文件，文件名加唯一序号，避免不同目录中的同名文件互相覆盖。显示完成数量，可取消；中断时如实报告已完成数，提示检查目标位置，不删除用户已有文件。
- 目录导出：在支持的 2in1 设备上提供保留结构导出，创建唯一新目录，出错只回滚本次目录。该分支通过编译，尚未完成对应设备实测。
- 手机模拟器的 canIUse 虽返回目录能力，但实际选择器无法选中目录；因此额外按设备类型控制入口，手机不显示无效目录导出按钮。手机批量导出为平铺文件，界面明确说明不保留层级。
- 修复密码库标签的选中颜色。导出过程中隐藏长结果列表，使进度和取消操作可见。
