# 小视频分类阈值修正

规则：小于 104857600 字节（100 MiB）的视频归图片分类；恰好达到该值及以上归视频分类。媒体的真实 MIME 不变，图片页中的视频仍可播放。

媒体库列表、总数、标签和目录统计共用分类条件，历史文件立即遵循新规则，无须移动或重新下载文件。

下载归档使用新不可变版本 download_publish_file 1.2.0、download_storage_object 1.1.0；V168 由 Flyway 应用。旧版本保留。部署期间发现旧 systemd 配置覆盖本次调度器及执行器配置，已调整覆盖顺序并通过实际进程启动参数确认新脚本根目录生效。

验证：Java 25 项测试通过；新脚本包 17 项测试通过，涵盖 50 MiB、100 MiB 少一字节、恰好 100 MiB、多一字节。正式环境用户最新下载的视频在图片目录查询返回 1 条，在视频目录查询返回 0 条。三服务 active，媒体库与调度器健康 UP，见 production.json。

本次未新增生产测试媒体，未删除用户文件。临时诊断脚本已清理。真机未连接；分类由后端生效，现有 APP 刷新后可读取新分类。此前删除空响应修复包仍待真机连接后安装。

旧单体手工视频归档默认阈值同步改为 100 MiB；本轮未重发旧单体服务，当前下载工具使用上述独立服务链路。
