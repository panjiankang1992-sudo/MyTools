# 书架缓存打开：虚拟机验证

执行日期：2026-09-28 至 2026-09-29。设备：Pura 90 HarmonyOS 模拟器，目标固定为 `127.0.0.1:5555`。

## 结论

已在真实虚拟机复现并修复缓存命中后仍停留在加载页的问题。修复后的文件型 TXT 连续三次重复打开、覆盖安装后的冷启动打开、强制终止应用后的再次打开均成功。真实断网测试未完成，不能声称离线场景已通过。

## 本次发现与修复

- 缓存键包含日期，导致跨日不再命中：改为按账号、服务、来源、版本持续复用，并迁移旧策略当天仍有效的副本。
- 本地缓存检查前等待远程进度查询：改为优先打开本地文件。
- **虚拟机发现的主要问题**：缓存成功解析后提前返回，没有执行清除加载状态的收尾逻辑，正文被“正在打开图书…”遮挡。实测持续超过 45 秒。
- 缓存和回源路径统一调用 `CompleteReaderOpen()`，并保留打开任务失效检查。
- 修正测试替身：原测试错误地在应用正文时清除了加载状态。新增状态断言先复现失败，修复后通过。

## 实测

样本为约 482.7 KB 的既有远程 TXT，通过正常“加入书架—继续阅读”流程下载，未注入缓存或替换内容。记录仅保留 UI 状态与页码，正文已脱敏。

| 场景 | 结果 | 点击到正文可见的观测时间 |
| --- | --- | --- |
| 首次远程下载 | 通过 | 4.053 秒 |
| 修复前命中缓存 | 失败，加载页遮挡正文 | 45.295 秒仍未显示 |
| 修复后覆盖安装、冷启动、复用磁盘缓存 | 通过 | 0.888 秒 |
| 修复后重复打开 1 | 通过 | 0.899 秒 |
| 修复后重复打开 2 | 通过 | 0.956 秒 |
| 修复后重复打开 3 | 通过 | 0.913 秒 |
| 强制终止应用后重新打开 | 通过 | 0.867 秒 |

时间包含 HDC 点击、布局抓取及文件传输开销，是自动化观测上界，不是精确首帧渲染耗时。首个章节和页码均成功恢复。另对现有规则型书源图书进行两次打开检查，约 0.803 秒和 0.839 秒显示正文。

原始数值：[measurements.json](measurements.json)。

## 边界与未通过项

- 模拟器通过 `eth0` 以太网联网。关闭 Wi-Fi 不能证明断网。
- 尝试临时关闭模拟器网卡时系统返回 `Permission denied`，网卡复核仍为 `UP BROADCAST RUNNING`。未改变主机网络，也未将此项记为离线通过。
- 独立自动测试覆盖六种缓存格式不发起进度查询或票据请求、缓存缺失回源、损坏重试、取消操作、跨日复用和账号/服务/版本隔离。
- 六种格式均有分支测试，但本次虚拟机文件型样本只实测了 TXT，不代表 EPUB/PDF/MOBI 等格式的性能验收。
- 原有 Contract Test 来源返回格式不符；合成 TXT 上传返回 `17 · Http protocol error`。这两项是测试准备时遇到的独立问题，没有计入缓存成功样本。
