# 多媒体图片性能修复验收

2026-11-04。针对 IPv6 直连时缩略图慢、全屏滑动卡顿。

## 原因和改动

- 原缩略图接口会回退到原始图片；六张实际样本为 1080～2048 像素、共 1,455,012 字节。
- 新接口按所有者、媒体标识、内容摘要、尺寸缓存 JPEG。列表最长边 512 像素、最大 192 KiB；全屏高清预览最长边 2048 像素、最大 1 MiB。原文件与分享接口保持原始内容。
- Python Pillow 转换通过固定程序和文件重定向运行，不拼接 shell；最多两个转换进程，输入最大 20 MiB、4000 万像素、转换超时 10 秒。透明图片使用白底，移除输出元数据。
- 全屏先复用列表图片，再复用邻近预览；停止滑动 500 毫秒后才加载高清。同一缓存请求合并，多消费者各自取消，最后一个消费者取消才中止下载。
- 预加载保留最新前后两项窗口、最多两个工作任务；切图不会反复取消正在进行的邻近下载。已删除旧全屏缩略图条的重复请求入口。
- 相邻预览在选图或任务结束时计算，手势每帧只读取缓存字符串；图片异步解码和自动缩放；磁盘清理异步且限频。
- 图片正在加载时，后续纵向滑动可跳到更新目标，旧异步响应通过版本校验丢弃。新版列表缓存使用 v2 文件名，避免继续将旧原图当缩略图。

## 已完成的验证

- Media Library：36 项测试通过，包含实际 Pillow 缩放、持久缓存、内容更新、权限、并发生成和损坏输入清理。
- Gateway：201 项测试通过，新增高清尺寸与可信所有者转发验证。
- App：构建签名包通过；缓存合并、消费者取消、缓存淘汰、前台优先、500 毫秒高清延迟、过期结果、两工作任务和最新滑动意图的行为测试通过。
- 相关图库批次、预加载、缩略图流水线、取消、返回恢复、手势、缓存管理、端点切换回归通过。
- 生产变更只替换 Media Library 四个成员和 Gateway 两个类。替换前原有类的 javap 与当前运行版本一致；其他 JAR 成员逐项校验不变。发布脚本保留既有 systemd 启动参数，失败自动回退。
- 相同六个样本：512 像素缩略图共 **194,615 字节**，减少 **86.6%**。服务端首次请求 64～112 ms，缓存命中 2～4 ms。这是服务端本机耗时，不等于手机网络端到端时间。
- 在线验证通过：内部令牌校验、错误所有者拒绝、非法尺寸拒绝、512/2048 实际尺寸及字节上限。

## 依赖与部署

服务器 `/usr/bin/python3` 可加载 Pillow 12.1.1，已以 `mytools` 服务账户检查。缓存目录 `/opt/yuyutian/mytools/runtime/media-previews-v1` 归该服务账户所有，权限 0700，可通过 `media-library.preview-cache-directory` 配置。需要清理空间时可以删除已生成 JPG，后续按需重建；勿删除正在写入的 `.part` 文件。

发布目录 `/opt/yuyutian/mytools/releases/media-preview-20261104-v1`。对应 SHA256、成员清单和脱敏样本统计见本目录 JSON。回退时移除该发布记录中的两个 `media-preview.conf` 覆盖文件并重启对应服务，上一版本覆盖仍保留。无数据库迁移。

本机后端测试使用 Java 21；macOS Pillow 解释器可通过 `-Dpreview.test.python=/path/to/python` 指定。App 现有 DownloadToolsPage 的 READ_PASTEBOARD 权限提示仍在，本次修改未新增编译提示。

## 真机验收

已重新连接手机并完成覆盖安装，安装包 SHA256 为 `7f7c86f91e498edfd3841108bcbef782a8e0a2bed4012f0794f5c2eff94b9d82`。

- 强制结束并重启 App 后默认进入工具页，仍可访问已登录的媒体图库。
- 图库与返回图库时连接标识均为 IPv6 直连；全屏初次打开为 1 / 6，连续上滑三次到 4 / 6，再上滑两次、下滑两次回到 4 / 6。
- 共八次打开/切图均收到 Image.onComplete。图片地址准备 0～1 ms；首次全屏的完成回调在地址准备之后 100 ms，后续七次为 3～7 ms。该指标仅反映已有缓存到图片完成回调，不等同于手势 FPS 或未缓存图片下载时间。
- 返回图库后六张缩略图仍保持 Image 绑定；继续滚动可见五张图片，未出现加载失败或重新登录提示。
- 本轮冷启动曾发生一次 IPv6 → 公网回退，随后重新验证恢复 IPv6；图片缩小与缓存优化不能消除底层链路波动。

脱敏节点摘要与计时见 `native-acceptance.json`，诊断标记见 `native-markers.json`。未保存用户图片、标题、账户或完整设备界面到仓库。
