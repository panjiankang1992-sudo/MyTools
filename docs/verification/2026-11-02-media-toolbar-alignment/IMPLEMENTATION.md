## 实现

- 顺序改为目录、标签、弹性搜索；筛选宽68、字号13、卡片标签12保持。
- 取消筛选按钮上下6透明留边，筛选可见底板和外层控件均填满公共行高；搜索容器和搜索边框也填满同一高度。
- 默认公共行高48，三个边框圆角均12；字号放大时按搜索行高共同增高。
- 查询、提交/清除、目录/标签打开与选择回调未改。
- 本地评审稿同步顺序和48可见高度；组件数、页面数、已批准状态及既有组件展开修复保留。
