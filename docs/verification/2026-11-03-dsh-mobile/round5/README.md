# DSH 第五轮：加载恢复与原生安装

2026-11-03。网页仍使用已上线的 `20261103a`，本轮没有修改服务端。原生签名包 `20261103-v4` 已安装到当前连接的手机，签名、安装、冷启动和进程存活检查通过。

## 修复内容

原先 App 只根据主文档完成事件结束加载，缺少整体截止时间；认证探测的异步回调也没有隔离旧连接。资源一直不返回时可能持续等待，旧认证结果可能覆盖重连后的状态。

- 票据请求、文档加载和 DSH 页面挂载共用 60 秒截止时间；重定向和重复完成事件不会延长等待。超时显示“重新连接”，停止当前加载并释放连接锁。
- `onPageEnd` 只触发就绪检查，发现当前 DSH 侧栏组件实际挂载后才结束加载。检测依据当前 DSH 0.2.1-rc.2 的 `.hHd-Xa_root`；上游升级后需要复核该标记。
- 网页脚本请求单次执行，每秒最多一次；成功、认证失败、超时、离页或换账号后停止。脚本即使永不返回，独立截止计时仍生效。
- 超时后作废旧票据请求；用户可以立即重连，迟到票据不能加载到新页面。旧认证结果同时受连接版本、账号版本及前台页面约束。
- 退出页面、切换服务地址、退出账号和页面销毁均清理计时器。空白页及旧文档事件不覆盖新连接状态。

此修复提供明确的恢复路径，不代表 Cloudflare 下载延迟已解决，也不判断 DSH 内部所有 WebSocket 或插件运行状态。
