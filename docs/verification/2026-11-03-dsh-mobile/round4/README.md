# DSH 第四轮：终端触控与文件预览

后续状态：网页资源 `20261103a` 已于 2026-11-03 上线，见[部署验证记录](../deployment/README.md)。下文及 `checks.json` 保留本轮发布前的验证状态。

日期：2026-11-03。本轮仅代码和预览，未部署网页资源、未安装 App。当前候选资源版本为 `20261103a`，继续兼容第三版 App，未改动原生代码。

## 本轮改动

- 为聚焦的终端新增可横向滚动的 44px 按键栏：Tab、Esc、Ctrl+C、Ctrl+L、方向键、Home、End。每条工具栏只向所属终端发送事件，不读取输入，不自动回车执行。
- 按事件增强终端，不新增全页 MutationObserver。弹窗打开、目标卸载、输入禁用和桌面尺寸时不发送按键。
- 图片、PDF、DOCX 缩放操作达到 44px；修复 320px 下“100%”换行；底部预留 76px，最后一页不再被工具栏遮挡。
- HTML 取消短屏最小高度，继续使用上游的沙箱。

## 预览环境结论

内置浏览器在最小测试页中也无法呈现 Blob iframe，srcdoc 正常。切到 Chrome 后实际 DSH HTML 页面和交互均通过。因此没有为预览工具移除 sandbox，也没有把此空白误报为手机故障。`06-html-short.png` 是该工具限制的证据，非通过截图。

检查期间 SSH 预览隧道曾被远端关闭，本机代理返回 502；重建带保活的隧道后继续验证。此问题没有通过修改生产服务处理。
