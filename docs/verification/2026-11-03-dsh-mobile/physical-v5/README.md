## 连接诊断与验证边界

通过当前本机 SSH 配置直接连接，先验证 SSH 连通，再只读聚合 Nginx 访问日志。与本次新页面请求时间对应的 User-Agent 分组中，WebSocket `/api/remote.mux` 多次返回 101，多个设置、模型和插件接口返回 200。另一个 User-Agent 分组持续返回 401，不能将不同客户端的失败混为这台真机的认证失败。访问日志是服务端记录，200/101 不保证手机已完整收到或处理数据，也不足以认定 HTTP/3 是根因。

已保存 [脱敏服务端请求汇总](server-request-summary.json)，没有保存请求头、Cookie、令牌、查询参数值或设备序列号。

后续交互曾因手机多次切换到其他阅读页面而中断。用户随后暂停其他操作；无干扰复测仍观察到超过 66.8 秒的加载状态，见 [复测样本](exclusive-recheck.json)，因此定位并修复启动恢复逻辑，详见 v6 报告。自动化任务、键盘与系统返回序列、外部登录回流、录音和文件选择/保存仍待无干扰复测。本轮没有创建 Agent 任务、自动化任务或更改账号配置。
