# 电子书模块能力缺口与补齐计划

更新时间：2026-08-15

## 1. 当前结论

电子书模块并非从零开始：书源导入与搜索、本地文件选择、MyTools/WebDAV/Alist/OPDS远程目录、图书详情、文本/EPUB/PDF/MOBI/漫画阅读、阅读设置、进度与书架同步均已有实现。本轮审计发现的核心问题主要集中在入口数据隔离、添加闭环、格式承诺、元数据质量和界面完成度，而不是缺少整个阅读内核。

本轮已经完成以下P0修复：

- 远程电子书改用独立`remoteBookSources`和`selectedRemoteBookSourceId`，不再与多媒体来源状态耦合。
- MyTools本地目录接口中的`EBOOK`类型会被单独规范化为“MyTools 电子书”，远程页可以看到真实电子书目录。
- MyTools电子书目录支持分页加载，默认每页40项，滚动到底后继续加载。
- 远程文件和OPDS列表项只进入图书详情，不再直接写入书架；只有详情页“加入书架”会持久化。
- 本地`ZIP`按`CBZ`漫画处理；新的`CBR`导入明确拒绝，避免“界面声称支持、阅读器实际打不开”。
- 电子书主入口、空书架、详情和远程列表使用原生系统图标及可访问按钮语义。
- 远程下载请求强制协商`Accept-Encoding: identity`，真实MyTools TXT已从详情成功进入正文，同时保留响应长度、指纹和格式校验。
- 正文中部轻触改为并行手势识别，分页/文本子组件不再吞掉点击；操作栏和阅读设置均已在模拟器验证。
- 远程文件传输名中的`_tags_…_user`字段会被清理，文件名标签与后端标签合并去重后进入列表搜索和详情。
- 横向来源胶囊已改为单一来源入口和底部滚轮选择器，三个真实来源不会再被横向截断。

## 3. 能力缺口

### P0：影响基本闭环

1. **入口数据隔离。** 原实现复用了多媒体来源，后端`EBOOK`目录被过滤。本轮已修复并在虚拟机真实账号状态验证。
2. **详情后再添加。** 原远程/OPDS行点击即加入书架，与产品约定冲突。本轮已改成“列表 → 详情 → 试读/加入书架”。
3. **格式承诺一致性。** CBR依赖RAR解码器，当前内核无法可靠读取。本轮先停止宣传和导入CBR；完整支持列入后续兼容阶段。
4. **真实远程正文打不开。** 服务端压缩响应被安全策略拒绝。本轮通过请求端明确协商未压缩传输修复，仍对意外压缩响应保持失败关闭。
5. **阅读操作栏无法稳定唤起。** 分页/正文子组件消费点击。本轮已改为并行轻触手势，操作栏与设置面板均可操作。

### P1：影响内容发现与长期使用

1. **封面和深层元数据质量不足。** 本轮已补标题清洗、标签、大小、来源和更新时间；仍缺真实封面、规范作者、简介、章节数、字数和最近章节，需要后端元数据接口或客户端受限解析缓存。
2. **OPDS书库管理不足。** 当前支持输入URL和凭据，但缺少保存多个OPDS书库、编辑、排序、最近使用和连接健康状态的管理页。
3. **书架管理不足。** 缺少按最近阅读/加入时间/名称排序、分组、批量移除、批量下载、失败重试和存储占用管理。
4. **书源兼容范围不足。** 目前没有完整执行开源阅读的任意JavaScript规则，复杂动态书源可能只部分可用。应继续采用可审计的声明式规则与受限脚本沙箱，不直接执行不可信任意代码。
5. **AZW3兼容不足。** KF8、Huff/CDIC等内容仍可能无法解码；需要成熟解析器或后端转码能力。
6. **远程离线能力不完整。** 已有按需缓存和下载基础，但缺少显式“下载本书/下载章节”、队列、失败恢复、空间配额和Wi-Fi策略。

### P2：影响界面完成度与阅读体验

1. **首屏动态态与设计稿有差距。** 有书状态需要恢复“正在阅读”卡片、四列封面书架、进度条和远程书库入口；空书架状态可以保留，但视觉密度应与有书状态同一体系。
2. **详情页远程态较弱。** 无封面时仍是大面积通用占位；应使用格式化书封、文件名清洗和来源品牌色，并补充格式、大小、来源健康、缓存状态。
3. **来源候选表达不统一。** 书源搜索图书有多来源健康信息，远程文件和OPDS详情没有同等级的来源状态卡。
4. **漫画沉浸体验仍需加强。** 需要双指缩放、双页/单页适配、长图分段、预取数量可配置和内存压力降级。
5. **阅读动效与反馈不足。** 翻页、目录跳转、主题切换、加载骨架、下载进度和失败重试需统一反馈。
6. **大屏适配未完成。** 手机以外还需验证折叠屏/平板的双栏书架、目录侧栏和横屏阅读。

## 4. 界面审计

### 4.1 电子书首屏

与选定设计稿相比，当前页面已对齐：标题、头像入口、书源/远程/本地三段切换、搜索、书源摘要、书架区域和固定五栏底部导航。搜索框右侧为“搜索”，添加动作已移动到具体图书详情。

仍需补齐：

- 有阅读记录时展示大尺寸“继续阅读”卡，包含封面、章节、进度和主操作。
- 有书架数据时使用四列封面网格；空状态不伪造示例书，但保持设计稿的留白、层级和主色。
- 头像应优先使用后端合法头像；缺失或非法时使用统一姓名首字母头像，不能显示破损图片。

### 4.2 远程书库

当前使用MyTools/WebDAV与OPDS二级切换，并提供单一来源入口和底部滚轮选择器。MyTools后端`EBOOK`、Alist和WebDAV互不覆盖，目录内只展示文件夹和支持的电子书格式。

仍需补齐：

- 来源较多时在现有滚轮选择器上增加输入搜索；当前三个来源已能完整选择。
- 文件行已显示清洗后的书名、格式、大小和标签；仍需增加下载/缓存状态与修改时间。
- 搜索应支持当前目录客户端过滤，并在后端支持后升级为服务端搜索。

### 4.3 图书详情

当前已实现“试读”和“加入书架”固定底栏，目录、来源候选、简介和移出书架确认均有真实交互。远程详情新增来源、大小、更新时间和多标签卡片；远程和OPDS图书会先进入详情，且未加入书架时明确显示状态。

仍需补齐：

- 无封面远程书应生成稳定、可辨识的格式化封面，而不是通用占位。
- MyTools后端应返回标题、作者、封面、简介、章节/页数、字数、标签和更新时间。
- 详情页顶部在小屏长标题场景需要更严格的两至三行截断与布局降级。

### 4.4 阅读器

三个设计状态应视为同一阅读页：正常阅读；点击中部出现操作栏；设置面板覆盖在阅读页之上。当前代码已经按这一状态模型实现，搜索能力只在打开图书后的操作栏出现。本轮真实远程TXT已逐一验证这三个状态。

后续视觉验收必须分别覆盖文本、PDF、EPUB和漫画，不能只用TXT代表所有阅读器。
