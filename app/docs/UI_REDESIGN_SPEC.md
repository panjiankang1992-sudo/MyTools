# MyTools 控件视觉重设计规范（v3 · 鸿蒙玻璃拟态）

> 版本：0.4（设计稿，暂不落地）
> 目标：去除「默认蓝色」与「全宽大块按钮」，参考主流鸿蒙应用设计语言（玻璃拟态 / 沉浸式 / 大圆角 / 弥散光感）。
> 对应设计稿：`app/docs/ui-redesign-mockup.html` / `ui-redesign-mockup.png`

---

## 0. 改造边界（重要）

- **阅读 / 工具 / DSH / 多媒体 四个页面：不改布局，只重设计控件**。Header、搜索框、书架、工具列表、媒体切换、底部导航的**位置与结构全部保持不变**，仅替换控件配色与形态。
- **仅「我的」页允许改布局**（可用玻璃分组卡片重构）。
- 即：落地时只改样式属性（`backgroundColor` / `fontColor` / `borderRadius` / `backdropBlur` / `linearGradient` / 图标尺寸），不改组件树结构、不增删节点。

## 2. 设计语言（参考主流鸿蒙应用）

- **玻璃拟态（毛玻璃）**：导航栏、工具栏、头部切换用 `rgba(255,255,255,.66)` + `backdropBlur(20~22)`，内容在下方透出柔和模糊。
- **沉浸式**：内容延伸到顶部，页面背景叠加 1–2 处柔和彩色光斑（radial-gradient），营造通透感。
- **大圆角**：卡片 18–24vp，按钮/胶囊 999，图标块 16vp。
- **弥散阴影**：`0 2px 6px rgba(20,30,24,.04) + 0 16px 40px rgba(20,30,24,.08)`，柔和有层次。
- **强调色只做点缀**：选中态、链接、进度用青绿渐变，不做大面积实心填充。

| 令牌 | 旧值 | 新值 | 用途 |

| `surface` | `#FFFFFF` | `#FFFFFF` | 卡片/面 |
| `glass`（新增） | — | `rgba(255,255,255,.66)` | 毛玻璃面板（配 `backdropBlur`） |

| `primaryGradient`（新增） | — | `#0DA678 → #34C08F` | 主按钮/进度条渐变（`linearGradient`） |
| `accentSoft`（新增） | — | `#DDF4EA` | 强调色浅底（选中 chip/图标底） |
| `ink`（新增） | — | `#1E2622` | 主文字 + 墨色主按钮 |

## 4. 控件规范

### 4.1 按钮（去全宽大块）

| 类型 | 规范 |
| --- | --- |
| 主按钮（强调） | 青绿渐变胶囊（`primaryGradient` + 白字），高 44vp，圆角 999，宽度自适应 |
| 主按钮（中性） | 墨色渐变胶囊（`#161D18 → #262F29` + 白字） |
| 次按钮 | 描边胶囊（白底 + `#CFD6D1` 1vp 描边）或幽灵（`#EEF2EF` 底） |
| 危险按钮 | `danger-soft` 底 + `danger` 文字，非实心大红 |

### 4.2 分段切换 / 标签 chip（去实心蓝选中块）

- 分段：灰底胶囊容器内，选中项「白底 + 轻阴影」，未选中灰字。
- chip：白底 + 细分隔线；选中项「`accentSoft` 底 + `primary` 文字」。

### 4.3 输入框

- 高 46vp，圆角 16vp，半透明白底（`rgba(255,255,255,.8)`）+ `divider` 描边 + 轻阴影。
- 聚焦：`primary` 细描边 + `rgba(13,166,120,.14)` 3vp 光晕。

### 4.4 列表项 / 卡片

- 列表项：白面 + 底部 `divider` 细分隔线 + 留白，**不卡片套卡片**。
- 卡片：18vp 圆角 + 弥散阴影；头部/导航用毛玻璃面板。

### 4.5 底部导航（毛玻璃悬浮胶囊 · 大图标）

- 毛玻璃悬浮胶囊：`rgba(255,255,255,.66)` + `backdropBlur(22)` + 弥散阴影，`borderRadius 26`。
- **保留大图标**：`TabBarSymbol` 从现状 22vp 放大到 **28vp**，线性图标。
- 选中态：图标 `accentSoft` 圆角块底（约 54×40）+ 图标/文字 `primary` + 顶部 4vp 圆点。
- 不出现实心大色块。

### 4.6 头部切换（书源/远程/本地）

- **位置不变**：仍在 `PageHeader` 行内、头像左侧（`BookModeSelector`），不移动到头部下方、不改为全宽分段。
- 仅改选中态：从「实心蓝底白字」改为「`accentSoft` 底 + `primary` 文字」，容器用毛玻璃胶囊。

### 4.7 进度 / 链接

- 进度条：`#E7ECE8` 底 + `primaryGradient` 填充，6vp 高胶囊。
- 链接/主操作文字：`primary` 文字，非蓝色。
